# 实证结论的维护

状态：active
读取时机：运行真实模型、性能或可靠性实验，或将外部研究用于实现决定时。
验证：相关实验的可复现命令与结果、`bun run check:docs`。

实验结论进入实际拥有该行为的 workspace 文档或跨包契约，说明问题、环境、变量、对照、结果和适用限制。不得用单次结果承诺其他模型、平台或版本行为，不得以文档存在代替真实运行证据。

进行中研究随对应[计划](../plans/README.md)记录。完成后只保留未来开发实际需要的知识；必要原始证据归测试或发布领域，过程由 Git 保存，不另建研究摘要库或完成记录树。

外部来源直接链接到相关结论；未经本地验证的推测须明确标为推测。模型调用、凭据与实验数据遵守[隐私和运维边界](observability-privacy-operations.md)。当前 live 入口以根 package scripts 与 tests 文档为准，不从旧实验记录恢复已删除工具。
