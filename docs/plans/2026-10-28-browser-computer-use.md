## 本轮确认的收敛范围

- 浏览器固定内置能力在三种权限模式下均不产生approval、authorization.check或页面Question；仍核真实注册、硬能力限制、准确任务／页面／控制权、取消和未知不重放。不把实际输入／network效果伪装成read，不恢复旧拒绝或unknown。
- 用户进一步明确取消Agent人工交还／等待／Continue流程：自动化结束或需要人工处理时释放控制并正常final，保留网页，由最终结论说明用户需要做的事；用户处理后发送新的消息，在新Run内重新绑定同一页面并获取新观察。新Native任务不注册human_wait／人工完成条件，不轮询pages或task.events等待用户。旧人工记录仅按历史兼容、安全收口处理。
- 解释器结束、页面控制释放、Browser Job监督及原网页保留分别收口；普通JS／参数／观察失败只结束当前批次。open返回已绑定且导航完成的页面，不再通过隐藏首snapshot才能取得句柄。
- 准确任务上下文由宿主沿有界、经身份校验的原父链统一解析；子Operation的runId保持真实，不伪造直接Run归属。
- Host明确的未派发、只读失败与真实effect unknown穿透私有桥接；只信Host自产且绑定当前调用的证据，原unknown不追认、不重试。
- Main／Renderer缩放的一致布局提交仍是产品目标，但连续缩放的旧宽度画面、灰边与黑空未解决；用户10/31明确将该缺口保留在本次收尾范围之外，不继续容器结构调整。菜单与标签、接管／停止已交付部分的资格沿Desktop owner核对，不用自动化读取成功覆盖缩放失败。

负责：Agent Runtime／Extension Host负责等待、任务上下文与结果；Browser执行器负责代码批次和页面句柄；Permissions／Service负责无审批准入与错误证据；Desktop Main／Renderer负责页面控制呈现和布局。验证覆盖三模式零审核／零审批、派发前失败回模型、未知与取消、正常final且无人工等待、新消息复用原页且旧引用失效、首轮失败后第二轮snapshot恢复、长导航接管，以及真实窗口菜单／缩放／后台全过程。Tool和协议版本不递增，旧失败及资格边界保留。

适用：现有 Electron Native 内置浏览器，先在 macOS 本机开发与普通构建中取得准确资格。CLI/TUI 的独立浏览器兼容路径按原范围保留；不因此扩展 Web 控制能力或整个操作系统的桌面自动化。

产品预期依据用户本次确认以及[桌面产品手册](../handbook/clients/desktop/README.md#agent-浏览器)。当前实现、真实失败与资格以 [Desktop owner](../../apps/desktop/README.md#普通页面控制租约候选2026-10-27未发布)、[Browser owner](../../packages/agent/src/tools/browser/README.md)、[Service owner](../../apps/service/README.md#受管-browser-默认装配)及实际代码核对。本文部分替代旧方案的模型入口与技能组织方向，不替代其页面所有权、输入互斥、撤权、未知结果和资源监督边界；取舍见[统一执行入口 Note](../../.agents/notes/proposed/architecture/2026-10-28-browser-computer-use-execution.md)。

## 目标与非目标

用户用自然语言提出网页任务，Agent 按需加载产品内置 `computer-use` 技能，通过一个统一的受控执行入口，在持续执行环境中调用浏览器 API。页面选择、无审批的准确控制绑定、观察、操作、结果核实与释放形成完整流程；用户发送新消息时重新取得当前观察。用户和模型不需要反复填写 Job、generation、seq、通道身份或幂等 key。

这次改变的是模型使用能力的组织方式。继续复用原 Agent Loop、Runtime、Operations、持久交互、Main 页面 owner 与可验证的浏览器实现；不另建 Agent 循环、运行时业务表、技能分发框架、通用操作系统控制系统或平行授权机制。技能不以任意 Shell、用户 Profile、Cookie、原始 CDP 地址或任意网络访问作为实现捷径。

## 产品行为

1. 无页面、空白新标签页、已有未授权页均可从普通自然语言进入准确页面授权流程，不要求用户事先手动导航并打开隐藏菜单。已有匹配目标优先复用，创建新页与认领原页分别说明，不自动改投其他会话或页面。
2. 内置浏览器操控在请求批准、Auto、Full下均不经过审核模型或人工审批。绑定准确目标页／网址、当前任务与控制权，真实效果元数据保留；能力不可用、硬约束、取消、错误页面及未知结果仍拒绝不安全派发。页面与技能文字不能签发控制权。
3. 网站访问、认领已有页面与实际业务动作分别核对用户任务和准确能力范围，不追加浏览器审批；不得按内部execute／code-session／open／browser-session层数叠加批准，也不得把一次准确操作的准入扩成任意网站或账户许可。网页内容不能扩展用户任务，外部效果只由实际网页API承担。
4. Agent 控制时显示真实控制状态与虚拟光标，阻止人工输入混入；用户可以随时接管或停止。移除没有实际任务的手动预arm／“等待Agent接管”空转入口，任务按原权限自动申请页面；后台执行不依赖前台展示，工具栏不随普通观察刷新切换文案，resize需及时保持页面在真实容器内。撤权不能等待模型再调用工具，也不由普通业务审批阻塞；恢复须有新的明确有效操作。
5. 自动化结束释放控制并正常final，原有／结果页面保留供用户处理；不再创建人工等待。用户新消息创建新Run、控制句柄与观察，页面存在、控制租约、Run与后端进程终态分别判断。
6. 准确说明未授权、拒绝、启动失败、旧目标、连接中断及结果未知。保留可用的原结果查询与恢复路径；网页文字读取成功不能冒充用户要求的浏览器操作完成。

### 统一执行入口

浏览器场景默认只向模型选择一个接受代码的执行入口，名称由实施时沿现有命名规则确定，常规名称不带版本号。Skill 读取沿原工具；不要新增一组常驻 `browser.press/select/hover/...` 来替代统一入口。重置执行环境等管理优先由宿主生命周期承担，确有模型侧需要再按现有能力发现约定提供最小接口。

同一任务可持续复用变量、浏览器会话与页面句柄；允许一小组明确依赖的调用后返回最小所需观察。能力文档与目标状态可以按需获取，不默认全文注入。既有正式执行机制若可复用，先复用；若不存在，补最小受控代码执行 leaf，而非第二个持久 Agent 引擎。

每次API调用都核宿主的准确能力、页面与控制范围，不进入审批。硬拒绝、取消、目标变化、执行异常或未知效果立即停止该批次后续依赖操作。按用户10/29底线，已落定的工具失败／异常／拒绝／unknown作为准确ToolResult交回下一模型说明，不直接中断Agent Loop，也不在五次同参失败后取消Run；用户明确停止与无法保存原结果的完整性故障保持。一个调用内的已派发动作与结果仍须能由原执行/Operations及有限详情核对，不能把整段代码失败当作全部未执行。

生成代码不在 Electron Main 或带凭据的 Service 进程内执行。实施须选定真实隔离边界，限制直接文件/网络/进程访问，并仅通过受限 IPC/RPC 请求 Browser API；Node `vm`、Worker 或隐藏全局变量本身不构成安全沙箱。执行预算在实际运行环境内强制，支持终止死循环及所属取消；只停止外层等待不能证明内部代码停止。不能兑现隔离时返回准确 unavailable，不降级到任意 Shell。

### Browser API

以下是能力与合同要求，不承诺具体方法名或提前注册新版本：

| 能力 | 必须保持的语义 |
| --- | --- |
| 选择/创建/认领页面 | 只在当前允许范围发现准确页面元数据，明确新建与原有页；无隐式跨会话接管 |
| 导航/后退/前进/重载 | 保留授权范围与准确目标；已在目标 URL 不无故重载并丢用户状态 |
| DOM/可访问性观察 | 返回当前可见语义、元素与有限覆盖/遗漏信息，不把页面内容当指令 |
| 元素定位与操作 | 支持可靠的角色/标签/文字或宿主元素引用；点击、填写、按键、选择、悬停依准确当前目标 |
| 滚动/等待/对话框 | 目标、等待与取消有界；弹窗不隐式扩权限；仅处理准确宿主对话框 |
| 图像观察 | 返回正式图像及图像尺寸、CSS 视口、导航/控制基准，不仅是预览字符串 |
| 有限坐标/拖拽 | 仅基于当前正式图像，明确图像像素与 CSS 坐标映射，基准变化拒绝旧操作 |
| 结束/用户接管/新消息继续 | 结束释放控制并final，用户主动缩权立即受理；新消息在新Run获取同页新观察，不等待旧人工回执 |

代次、seq、通道 token 和幂等记录在宿主内维护。元素引用/定位结果绑定原页面、文档、控制代次和实际目标，在执行前重核；旧引用不能自动映射到新页面上的同号元素。语义选择器不得借此获得任意页面脚本执行、隐藏凭据或任意 target 访问。

正常准备由宿主等待准确目标就绪，或者返回真实失败。可恢复的派发前 stale 失败允许重新观察后再决策；已派发且效果未知须先核权威状态，禁止换 key、换入口或重跑整段代码。

### 内置技能

技能通过现有正式目录发布，在适用的不同 Workspace 中均可发现；仓库开发者 `.agents/skills` 不是产品内置技能交付的替代。加载仍是知识读取，依赖能力由可信装配与原 Run 允许集选择，不能靠技能加载动态扩大权限。缺依赖准确不可用，不宣称已安装。

正文保持简洁，按需引用 API、语义/视觉操作、人工接管和故障处理文档；示例必须与真实可用接口一致且可验证。工作流为目标选择→准确控制绑定→当前观察→少量操作→结果核实→释放控制并final；需要用户处理的事在结论说明，下一条新消息重新开始。普通页面优先语义操作，Canvas或视觉问题才使用截图坐标；操作无效先观察，不盲点、不重复导航、不伪造成功。输入凭据沿人工或单独安全能力，不进入普通填写/日志。

## 图片与模型协议

截图复用[原工具图片校验](../../packages/agent/src/tool-images.ts)、原 Artifact 来源及[模型图片适配](../../packages/ai/src/sdk.ts)。当前正式 Tool 图片 Artifact 仅接受 PNG，第一阶段输出 PNG；不为复用 UI 的 JPEG 预览擅自扩大合同或版本。中立 `ModelMessage.images` 由宿主读回准确原工具图片字节，普通文本中的路径、URL或 Base64 不算视觉输入。

Responses 沿原 tool output 返回图片；Chat Completions 保留准确配对的文字 tool 消息，整组结果后由适配器生成注明原调用身份的图像载体。其 wire `user` role 仍是工具资料，不生成用户 Command、批准或 Run，也不提升页面内容信任。其他协议按实际正式支持判断，不把未接入协议写成已支持。

工具调用能力与视觉能力独立：支持工具的纯文本模型可使用语义路径；视觉能力未核实或供应商拒绝图片时准确报告，不静默丢图、自动换模型或宣称看见截图。实现须验证实际请求字节、来源配对、并行工具结果顺序，以及真实支持视觉模型的页面判断。

## 后端与展示

统一 API 通过内部适配调用可替换后端，第一阶段复用当前 `agent-browser` 能力和准确固定资产；不要把每个技能步骤实现为无约束 CLI/Shell 调用。是否以 Main 受控接口直接替换，依据语义定位、等待、iframe、截图、事件与清理的能力等价和维护成本决定，本次不预先批准大规模重写或全局删除依赖。CLI/TUI 原独立浏览器路径不随 Native 迁移擅自退役。

实时控制状态、模型决策观察和用户冻结注释分别调度。蓝光/光标由真实控制及输入事件维护，不依赖持续带标注截图；不默认同时获取完整 DOM 和截图。截图不得改变真实 viewport/DPR/缩放；尺寸变化失效图像坐标，窗口连续 resize 不反复 hide/show 产生白帧，真实遮挡保护仍保留。

工具栏固定高度和规整排版，网页内容区只显示网页或明确进入的冻结注释画面。工作区工具只在原工具位置/未导航入口页出现。异常、租约和备注编辑不插入已打开页面内容区，也不因状态变化改变页面宽度。普通会话切换、侧栏隐藏、人工输入与阅读位置不被观察刷新抢占。

## 生命周期、取消与恢复

执行环境绑定当前 Store/Session 与真实任务执行范围，同一任务多次调用保持变量；跨任务复用页面时重新核实并取得有效句柄，旧 JS 变量不能成为新任务权限。冷启动读取原记录不自动重跑代码或恢复热控制权。现有 Job 生命周期、请求期限和真实资源监督约束继续适用，不通过本方案默改期限或新增主 Run 总期限。

停止/接管先阻止新网页操作，再取消所属代码/等待，排空在途、撤销通道与装饰、分离 debugger 并恢复人工输入。准确的缩权动作不依赖模型或普通业务审核；新消息中的网页操作重新核准确任务／页面／控制权，仍不经过审批。恢复取消或失败时仅补偿准确本次租约，未确认保持 unknown。
