# 各入口能力对照

“有条件”表示需要正确配置、权限、功能开关或可恢复数据；不是打开客户端就自动具备。

| 能力 | TUI | Web | CLI |
| --- | --- | --- | --- |
| 发起任务 | 支持 | 不提供 | 支持 run |
| 继续已有会话 | 支持 | 仅查看 | 支持 resume，需任务与会话标识 |
| 浏览会话与消息 | 支持选择器与历史 | 支持目录、会话链接 | 以指定会话执行和事件输出为主 |
| 删除会话 | 支持确认删除 | 不提供 | 不提供专用公开命令 |
| 手动重命名会话 | 当前无选择器入口 | 不提供 | 不提供专用公开命令 |
| 审批与问题 | 支持交互面板 | 不提供 | 有条件：stdin 交互 |
| 取消执行 | 支持 | 不提供 | 见命令执行及终止方式，不等同于 Web 控制 |
| 计划审核 | 有条件支持 | 不提供 | 有条件：运行中的交互 |
| 恢复点与分叉 | 有条件：/rewind | 只读信息 | 不提供等同 TUI 的恢复选择器 |
| 模型与偏好设置 | 支持相应选择器 | 不提供 | 消费配置，不提供 TUI 选择器 |
| 上下文查看与手动压缩 | 有条件支持 | 查看具体调用上下文 | 不提供等同 TUI 的交互命令 |
| 导出对话 | 支持有限 Markdown 导出 | 不提供独立导出入口 | trace 可转换已有日志 |
| MCP / Skills | 有条件 | 不提供配置与执行 | 有条件：已配置能力与 --skill |
| 诊断日志 | 通过相应运行与数据入口 | 支持日志与上下文检查 | trace / 状态选项 |

操作入口：[TUI](clients/tui/README.md)、[Web](clients/web/README.md)、[CLI](cli/README.md)。服务启动不属于浏览器权限，见[Server](server/README.md)。

能力不同不自动意味着缺陷。发布和平台限制按实际运行环境核对，不能用一套测试结果承诺所有系统和模型。

开发中的[桌面客户端](clients/desktop/README.md)已接入模型配置、任务、历史、审批、问题、计划审核和取消；尚未正式发布，本机 macOS 日常开发闭环已验收，平台与剩余能力按该入口说明，不计入上表的正式客户端承诺。
