# 服务常见问题

| 症状 | 处理 |
| --- | --- |
| web 提示无服务 | 先显式 server start，或源码使用 bun run server |
| 端点不可用 | 检查 status 和明确端点，不把浏览器刷新当作启动进程 |
| 工作区不匹配 | 使用 daemon 绑定的工作区，或停止后按需要重新启动 |
| 版本或协议不匹配 | 当前客户端不能 shutdown 不兼容服务；用协议匹配的旧客户端指向原 profile/endpoint 停止，再以新版本启动 |
| Web 资源缺失 | 使用完整构建启动入口，不仅运行 Vite |
| source 与 installed 会话不同 | 核对 profile 和工作区，不先删除数据 |
| 停止后仍有未知结果 | 核实外部副作用与恢复状态，不直接重复写操作 |

诊断应包含命令、工作区范围、脱敏状态及预期。不要公开本机凭据。涉及真实数据恢复或发布问题，维护者使用[运行手册](../../runbooks/agent-production-incident.md)。

没有匹配客户端时，先用操作系统进程管理工具核实旧 daemon 的进程身份、启动时间和命令；只能终止明确属于该实例的进程，不能凭端口、旧 PID 文件或同名进程猜测。非正常终止可能留下待核实外部结果，应按恢复说明检查；不要删除未知 socket 或数据库来绕过协议错误。
