# 数据与访问范围

会话、历史与执行事实保存在当前 profile 的本机数据中。进程重启或界面切换不等于数据删除；不同 source checkout 与安装环境可能有不同数据范围。

用户配置与会话数据也不是同一个对象。修改主题不迁移会话，删除会话不回滚工作区文件。不要在服务运行中手工编辑或复制数据库来绕过恢复边界。

## 客户端权限

Native TUI/CLI 与浏览器使用不同访问能力。浏览器得到本机只读访问，不持有 Native 执行凭据，不提供审批、取消或配置写入。

浏览器页面内导航保持当前访问；离开文档时尝试清理浏览器会话。该清理不停止 daemon，也不删除产品会话。

Model Context 和对话可能包含敏感项目内容，即使没有 key 也不应未经检查分享。数据诊断见[Web 上下文指南](../clients/web/guides/model-context.md)。
