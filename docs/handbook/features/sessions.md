# 会话与历史

会话将输入、执行与保存的结果组织到同一继续路径。客户端连接、窗口或进程不是会话本身；关闭查看页面不应自动删除会话。

只有已经接受并保存的内容具有相应历史保证。排队输入、光标、展开状态和瞬时进度可能只属于客户端，不承诺换客户端完整恢复。

## 身份与隔离

同一会话的数据按身份组织，不按名称或相同正文猜测归属。两个相同文本的独立输入仍应保留两次；迟到数据不能串入后来选择的会话。

查看历史不应自动重放写操作。切换、删除、继续、恢复与分叉是不同操作，取决于客户端是否提供。

源码与安装版、不同工作区或 profile 可使用不同数据范围。找不到会话时先核对入口和范围，不直接判定丢失。
