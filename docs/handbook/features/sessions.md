# 会话与历史

会话将输入、执行与保存的结果组织到同一继续路径。客户端连接、窗口或进程不是会话本身；关闭查看页面不应自动删除会话。

只有已经接受并保存的内容具有相应历史保证。排队输入、光标、展开状态和瞬时进度可能只属于客户端，不承诺换客户端完整恢复。

## 最近消息时间

会话列表的最新变更时间与最近排序以已保存的对话消息更新为准。查看或切换会话、切换审批模式、处理审批、重命名和单独的运行状态变化都不推进该时间；这些操作之后实际保存了新消息时才更新。空会话及缺少可核实消息时间的历史保持未知，不用当前时间补齐。

## 自动命名

标题生成属于内部模型调用，不创建子 Agent 或 child session，也不计入子 Agent 数量。原会话保留 `session.title` 调用记录；输入和模型结果不作为普通聊天消息插入。

新建的普通会话在首条消息保存后获得可读名称。默认 Service 使用该轮实际选择的 AI 模型概括首条消息主题，生成与输入语言一致的简短单行标题，最多10个Unicode字符。标题作为会话名称保存，不进入对话正文，TUI、CLI、Native 和 Web 目录读取同一保存结果。

首条引用资料或问题也直接进入普通 Agent，必要澄清由它正常提出。原文兜底在普通启动前保存，AI 命名沿首个正常轮次的完成条件执行；没有额外的任务归属判定或“明确关联后”命名阶段。重试、冷读取与手动改名仍保持原边界。

AI 命名在该轮满足正常完成条件后、提交成功终态前尝试一次。生成期间，以及模型不可用、首轮报错或重试、命名超时／失败／结果不可读时，用第一条消息作标题兜底：去掉首尾空白，把连续空格、换行和制表符合并为一个空格，再截取前10个Unicode字符并去掉末尾空格；其余原文保持，不另行提取或改写主题。没有原文或消息全为空白时使用“新会话”，全为空白不调用命名模型。模型配置在 Run 创建前失败时也按同一原文兜底，不需要先成功调用模型。命名失败本身不把主任务判为失败。

空白规整只用于标题兜底和发送给命名模型的内容副本，消息历史和主任务输入保留原文。明确设置的名称、用户后来的手动改名、已有会话和子 Agent 名称保持原意；重新打开历史或继续下一轮不会重复生成。空会话尚无主题时显示客户端的“新对话”等占位。

## 身份与隔离

同一会话的数据按身份组织，不按名称或相同正文猜测归属。两个相同文本的独立输入仍应保留两次；迟到数据不能串入后来选择的会话。

独立 Agent 会话线程属于内部执行，不会作为空间的顶层会话列出，也不会占据搜索、最近会话或分页结果。用户从父 Agent 树或授权详情进入子线程，仍可查看其独立上下文和结果；知道子线程 ID 本身不授予访问权限。新 TUI 和 Native 已有父作用域只读子上下文消费者；同 Loop Task 的实际角色、独立子 Session、列表/等待/显式续轮和停止由[Task owner](../../../packages/agent/src/extensions/task/README.md)与[Service owner](../../../apps/service/README.md)记录。旧 App Server 的受控结果保留在[历史协调方案](../../plans/background-agent-shell-conversation-coordination.md)，不证明新制品或全平台资格。

查看历史不应自动重放写操作。切换、删除、继续、恢复与分叉是不同操作，取决于客户端是否提供。

删除会话或移除空间是数据操作。对应会话正在运行时，服务端先取消执行并继续处理资源收尾，不要求等待收尾完成后才删除。未运行会话的旧工具运行标签、异常历史和恢复状态不阻止删除；移除空间批量删除其中的会话数据，不逐条等待。

新的统一 Agent 接口按观察到的控制修订保存重命名和删除；冲突保留原选择，未知只查原操作。异常重开后仅重命名标题，不会妨碍原任务的安全接续、明确放弃或发送新任务；未知效果与其他恢复约束仍须核验。删除先从正常目录隐藏并关闭整组新工作，受理不等于资源停止。该接口保留准确旧 ID 的历史；通用 PC 已接空间批量移除，一次隐藏全部根与子会话、封锁新工作并请求取消，未知只查原移除。当前显式离线GC可清理超过宽限且任务全部结束的已移除空间历史正文；未结束、未知或待核对执行仍保留证据，原删除边界、回执和未发送草稿也保留。单独删除的会话执行组也可按相同宽限和终态条件清理；存活Fork及其他未清理会话依赖的来源继续保留，最后一个依赖删除并符合条件后可一起清理。删除受理不能当作正文擦除，安装版维护和完整永久删除资格仍需验收；准确范围按[实施进度](../../plans/unified-agent-refactor-v1-progress.md)验证；新 CLI/TUI/Native 已接入相应操作，平台与完整业务资格仍按当前证据分别核对。

Fork 从稳定的当前上下文创建新会话，保留已发生历史和原来源，不继承活动执行或审批授权。原大模型正文按原调用读取；扩展明确选择保留当前已提交快照、按所选边界重建或省略，未登记规则默认省略并说明。复制的业务历史不会成为旧计划或操作的执行许可。查看分支不调用模型或重放旧工具，用户显式继续才产生新的工作。

统一 Agent 的原始记录导出保留所选根会话及其真实子会话的消息、执行和业务原文，包括当前实现不能解释的格式；私有配置、凭据和执行权威不包含在内。读取期间出现可观察提交或正文不完整时，导出明确失败，不把前缀标记为完整。媒体保留原来源引用，完整读取仍按原调用授权。该接口的交付范围见[实施进度](../../plans/unified-agent-refactor-v1-progress.md)；TUI 的已加载对话 Markdown 导出继续遵循其[客户端指南](../clients/tui/guides/history-and-export.md)。

大量详情读取同时发生时，客户端按序排队组装历史；服务端暂时拥塞时，只读分页请求可在时限内等待重试。等待超时不会删除已保存的会话。支持取消的客户端切换目标时会取消不再需要的读取，稍后重新打开可再次读取目标历史。历史不会因累计记录数或字节数超过旧门槛而被拒绝；单页超时和单条消息的解析安全检查仍生效，不会把部分内容伪装为完整历史。

源码与安装版、不同工作区或 profile 可使用不同数据范围。找不到会话时先核对入口和范围，不直接判定丢失。

## 执行轨迹与只读重放

Desktop 右侧栏的“新标签页”在“工具”区提供“执行轨迹”。它作为独立标签页打开，同一会话只保留一页，并与浏览器、变更等标签共用原有容量；重新选择入口会回到已打开的轨迹。轨迹不会替换对话主区域，切换标签不丢失原消息阅读位置、输入草稿或待处理交互。

轨迹围绕一轮对话的用户输入、模型输入准备、模型请求、工具操作、子任务与最终回复组织。主列表按逻辑操作首次出现的记录顺序排列，并行分支可以交错。模型的准确自动重连链保留一条思考行，在系统或思考详情中列出初始请求和各次重连，可选择一次请求读取当时输入／公开输出；首次请求不计作重连。一次 Shell 的启动 Tool、原 Job 和准确 read／wait／stop 观察归同一工作；等待或读取成功不代表命令成功。子 Agent 的委派、承载和结果关联到同一次准确工作，接纳、运行、结束与交付分别表达。同一文本的独立发送、重新运行的相同命令及同一协作者的新工作仍分别保留。自动压缩的摘要生成与采用在一条操作中关联，原失败、尝试、事件、父身份和材料不被删除或改写。默认仅展示有意义的消息、模型、工具与子任务、自动压缩和审批；会话结构不额外占步骤，辅助事件只在“显示全部事件”中读取。已核实的自动审批检查单独归为一条审批记录，可读检查请求、规则和结果，不展开成Agent对话；人工审批卡继续保留。已成功且结果已由准确成功父工具承担的工作树／浏览器内部支撑作业不再单独占默认日志，仍可在“显示全部事件”查看；运行中、失败、取消、结果未知或归属不明确的作业继续显示。

顶部仅保留“时长”切换耗时比例／事件顺序，移除“轮次”“调用”“子调用”三个全局展开按钮。轮次与子Agent行仍可用箭头局部展开，普通阶段没有层级箭头；已有折叠状态保持。筛选菜单仅保留消息、思考、工具、子 Agent、自动压缩与审批六类选项，“工具”与“子 Agent”独立勾选，分别控制普通工具操作与子Agent任务；默认均展示，关闭子Agent仍可能保留命中内部日志所需的淡显祖先。菜单不再提供时长、轮次或层级筛选，旧视图中这三种条件不再生效。重连、轮询与输出分片始终归所属操作，不因全部展开成为重复同级工作。类型条件位于独立“筛选”菜单，与元数据搜索共同按 AND 命中；同类多选为 OR，空选合法。搜索使用已有公开索引，不预读完整输入／回复。清除条件不重置选择、材料版本、阅读位置与折叠；筛选外或被折叠的已选详情保留，命中路径只临时展开。

日志左侧的小圆点表示每次模型请求的开始边界，位于准备／上下文与该次返回内容之间的节点间隙；之后的思考、文本、工具操作按原顺序平铺，不新增请求树节点或另一层Agent loop。一条准确自动重连链只有一个边界点。含准确Model调用的自动压缩也有自己的请求边界，只含采纳或发布记录时不补造模型请求。点间连线是同准确Run中的阅读顺序，不表示耗时、任务已结束或工具因果归属；子范围、业务省略和缺轮次证明处中断，后台命令继续保留原状态和归属。

点击圆点打开独立的“概述、选项、用量、计时”四个Tab，选择的是该请求及其准确尝试；点击思考节点只阅读思考内容，不再混入请求参数、Token指标或请求计时。概述汇总该次状态、实际保存的模型／公开提供方类型、工具请求数量和可定位结果，选项仅展示该次已保存公开配置，用量只取该次原记录且缺失不当成零，计时只取该次原观察边界；不将重连等待、其他请求、工具执行或压缩后估算量混作本次指标。缺字段、未加载、生成前缀和不可读明确区分。重连尝试可准确切换，切换Tab不重置所选原尝试，同一点复选保留当前Tab和观察；结果链接只跳原返回版本。画点不预读正文，用量／计时Tab不读取正文，详情开合保留日志行及阅读位置。

每轮的逻辑统计可在轮次详情查看，主列表不再展示轮次行右侧的操作数量。统计仍分别记录逻辑Agent处理、工具操作、子任务、审批和压缩；一次准确重连链只计一次Agent处理，一条Shell命令及其读取／等待／停止只计一个工具操作，不能将这些数量当成实际网络请求或每次Tool执行次数。用户消息和Agent回复单独统计，不混入执行操作数。子任务内部只计入其准确子轮次，加载子范围或切换展开形态不会增加主轮次计数；筛选后的摘要是当前命中集合的小计。默认不重复展示匹配数，启用筛选后只在日志头显示一次结果数量；固定上界和事实覆盖核验状态可从“轨迹信息”查看，上下文祖先数量不占默认阅读区；时间轴不常驻显示右侧解释句，实际读取失败与旧格式材料缺失说明继续显示。

执行概览以输入／回复、思考、工具／子任务、压缩／审批四条泳道显示，可在“观测时间”和“事件顺序”之间切换，点击标记定位对应日志。思考条和主行的“请求”时长表示原模型请求跨度，包含重连，工具执行另列；系统、思考等内容切片不增加标记。消息是时间点，确证区间为条，并行区间分轨；时间刻度和网格只采用已记录、可比较的同来源观察，不表示模型服务的纯执行耗时。进行中仅说明已经观察到的跨度，不持续计时。缺少时间或边界、时钟倒退和跨来源记录保持未知或分域展示；全量辅助事件另列定位区。事件顺序的等距间隔不代表耗时，切换坐标与定位均不移动历史游标。

主过程以“Agent loop”展示，直接对应原有执行轮次，不再新增一层loop。每轮的系统准备、用户消息、思考、工具、审批、压缩和回复按原发生顺序同级平铺，不展示决策包装层；只有子Agent阶段可展开其内部Agent loop，内部也同样平铺。自动重连归所属思考，在思考或系统详情中切换准确尝试，不增加主行。展开后可直接看系统提示词、用户输入上下文、思考、工具和本次输出；点击对应内容行即可阅读原文。系统提示词只取原请求中 `role=system` 的消息，不兼容为其他角色新增系统指令分类。系统提示词以一个默认展开的无边框Accordion条目展示，多条system消息的正文按原顺序完整呈现，不再拆分编号折叠项。请求用户上下文和消息正文仍按原消息组织无边框Accordion，首条默认展开，其余逐条展开；所有详情去掉额外的来源文案与Tab下重复标题，条目标题和正文业务分组保留。Tab栏仅在必要时横向滚动，正文使用紧凑间距。展开折叠不增加材料读取，切换准确请求版本后按新版本重建条目。已有独立用户消息或已确证的Agent回复优先保留，不再生成重复消息行。旧记录没有消息事实时，只把准确模型请求中的用户内容标为“本次请求上下文”，不补造消息事件、发送时间或归属。本次请求上下文省略已确证为系统自动附加的会话文件清单和本轮运行／计划状态，以及没有文字、图片或工具请求的空项；用户自己粘贴的同形JSON、历史中的同文输入和图片消息仍保留。旧材料来源不明确或读取不完整时保留原内容，不猜测来源。工具前的正文是Agent说明，不因模型输出完成就称整个对话已结束。未保存可展示思考时明确说明，不从回复猜测思考。没有相应封存材料时，不再生成系统、输入和输出的空阶段；思考行仍保留执行状态和缺失说明，旧尝试确实保存过材料时继续提供准确入口。项目指令、方案和压缩摘要等有效内容仍作为请求上下文保留，不统称为当前用户的新消息。

只有工具调用、没有回复正文的成功输出不再单独占一条输出消息，实际工具操作继续展示；这一判断取原输出封存的正文存在性和调用数量，不等正文加载后再删除行。空输出、正文未加载与生成中分别表达：已完成且没有正文也没有工具调用时说明“已完成，无正文”；有正文但尚未读取时保留输出入口和加载状态；生成中尚无正文由思考行承载进度，开始产生正文后保留其输出。旧记录没有准确证明、读取失败、执行失败／取消或结果未知时不推断为空；纯空白正文也不作为空输出删除。重连前曾有正文或状态不明的输出继续从“历史输出”选择准确尝试。材料加载及详情开合不增删日志行，真实新记录仍沿固定历史上界与“返回最新”切换。

模型名称取当次封存的实际提供商名称；旧记录可沿已读取的准确请求metadata显示同一名称，缺失时写“模型名称未保存”，内部绑定ID只保留在底层原记录，不在节点详情中展示。系统指令、对话与工具结果、工具目录和来源都取原请求，不读当前配置或文件重建历史。当前视口最多四个原模型请求按准确引用读取输入／输出，移出、折叠、切换或断线取消对应读取；不预读全部历史。工具目标和消息摘要仍优先使用原owner的有界公开字段，Shell命令全文仍在准确参数材料中。

同一原执行轮次内，相邻两次逻辑请求的系统准备可作保守提示：只有两份当次输入材料都已获准完整读取、系统指令与公开工具目录完全一致时，后一行显示“沿用系统准备”；确认不同时显示“系统准备已更新”。缺少任一准确材料、读取不完整或内容过大无法比较时保留普通系统准备，不猜测相同。提示不隐藏内容行、不改变38px行高，点击仍打开该次准确系统提示词和工具快照；不会为比较预读整段历史或额外缓存正文及其指纹。

子调用展开时，在线客户端仅按已核实的直接子 Session、准确 Run 和原 carrier 另读内部轨迹，固定在父轨迹当前 cursor；不读取任意最新工作、不混入父材料权限。折叠、切范围与断线取消所属读取，已读同源元数据可保留阅读锚点，正文仍待重新准入。离线文件未包含的子范围明确缺失，不联网补齐。

子 Agent 已有可读的终态结果时，默认预览直接展示原任务与最终结果，较早进度仍可按原观察读取。审批等待期间可查看原命令及请求范围，回答后查看准确决定；公开上下文和审批的有限预览不显示为“仍在生成”。同一回复的流式记录接管后，思考仍排在自己的回复之前，不额外插入工具独占输出的空回复行。

日志行高为 38px，使用彩色类型标签、细层级连接、轮次分组和行尾观测时长／状态；选中行用蓝色背景和左强调线区分。长日志在自身区域滚动。选中节点后打开详情，宽容器默认占工作区 40%，可拖动分隔调整并保留阅读位置；是否使用覆盖式详情取决于轨迹容器的可用宽度，右侧栏较窄时同样使用覆盖层。关闭覆盖详情后回到原选中行与列表位置。

详情按阶段组织。系统准备提供“系统提示词／工具”，工具页只列当次实际工具目录，支持名称和说明搜索，展开后阅读说明及参数定义，不借今天的注册表。用户上下文和回复使用“内容”，思考只使用“思考”，模型请求的选项、Token与计时从请求圆点进入。所有节点均无“原始内容”或生命周期Tab，也不列来源文案、父级和内部绑定ID。无边框Accordion首条默认展开，Tab下不重复主标题。公开思考使用独立强调阅读区，长内容可局部展开；正常回复保持原Markdown。真实工具为“概述／参数／结果”，参数完整保留原公开JSON，结果按文件、Shell、网页、计划、MCP等类型展示；计划与步骤状态用对应含义，明确保存的空列表和未提供列表分开。Shell／Job保留标准输出、标准错误、原序号范围、截断和丢弃字节，空检查点不冒充完整无输出或任务完成。独有错误直接可读，结构化null／false／0与空白内容保留。子Agent参数先提供准确委派任务、名称和预设角色，再列原JSON；受理、工作和交付仍分别表达。压缩展示采用状态、同口径本地估算的前后容量、实际摘要及已封存的保留消息范围；触发实测基线、估算分量和阈值按需展开，消息序号不冒充事件游标。审批／问答只读原问题、选项、决定、反馈与按准确问题标识匹配的答案，未答、空答案、取消和没有封存内容分开，不提供再次审批或回答动作。

自动压缩区分摘要生成与结果采用。只有原发布事实才能说明摘要已采用；模型成功但未发布仍是候选摘要。压前／压后 Token 仅在本次已保存、同口径的计数可用时比较，并显示计数口径；压缩调用自身的输入／输出用量另列。缺值显示未记录，失败、取消或未采用不会伪造成压后 0 Token。摘要正文沿原模型材料读取，不从今天的上下文重建。

消息正文后按原顺序展示附件名称、类型及已保存的精确字节数（包括0），重复附件不去重；仅有附件的消息不插入空正文占位。描述性附件不构造图片或读取路径。请求上下文中的图片只使用该次已获准输入材料内保存的PNG／JPEG／WebP／GIF字节显示缩略图，格式或解码失败明确说明，不重新访问URL、当前文件或相邻请求。

底层继续完整保存规范事件、原父关系和获准公开材料，现有轨迹导出及“导出含证据”能力保持；节点详情不再提供原事件JSON或公开字节查看入口。明确选择原观察后，阶段详情始终只读取所选准确版本。不公开私有请求封装、未获准的思考内容、凭据或执行权限。普通Agent loop已保存且获准公开的思考内容仍在思考详情中直接可读；压缩预览不呈现思考内容。参数为空对象、null、没有封存和不可读分别说明；旧参数不能从当前执行或相邻模型补齐。文件、网页、图片和附件只沿原材料读取，不按参数路径或 URL 重取；文件窗口、网页截断、输出预览、缺口和未完成回复都保留原完整性说明。轨迹中的审批和问答仅供阅读，不重新批准或回答。

首次读取固定历史上界。新记录只在顶部工具栏提示并提供“返回最新”，不插入额外提示行顶动日志；显式“返回最新”才刷新范围；播放和跳转只浏览已保存事实。隐藏、关闭或切换会话会取消未决读取并释放材料，迟到结果不能串入后来选择，原会话状态仍可恢复。轨迹格式启用前的日志在全量模式以“旧记录 · 原事件类型”显示，缺失关系或材料无法追溯补齐；当前会话后续新执行可继续保存新格式记录。

可导出固定范围的轨迹文件，默认含事件及其中封存的有限公开展示摘要，不含完整消息、参数或结果材料；“导出含证据”另复制当次获准的公开材料。打开 `.kite-trajectory` 使用独立的离线只读窗口，不连接模型、启动 Runtime 或导入原 Store；包内缺少材料保持缺失。该能力当前面向 Electron Native，TUI／Web 不因此新增敏感读取或导出入口；本机过程、验收范围和安装／平台限制归 [Desktop owner](../../../apps/desktop/README.md#执行轨迹离线窗口与-trace-设置)。
