# 模型与配置

模型选择包括 Provider 与具体模型，相同名称不代表同一请求目标。工具调用、推理深度和上下文能力取决于模型与配置。

## 配置范围

用户级和项目级 `kite-code.jsonc` 可提供配置。配置项各有合并规则，不能把一般的项目覆盖规则用于凭据、内容日志或权限上限等受限项。

客户端的语言、主题等偏好与服务的模型配置分开维护。修改 TUI 语言不承诺 Web 同步改变，修改模型也不改变已经开始的模型请求。

Provider 凭据通过实际支持的配置和认证入口维护，不在手册示例中填写真实 key。配置错误会阻止相应操作，不能静默切到另一个模型冒充成功。

未提供用户或项目模型配置时，内置 DeepSeek 路由默认使用官方 API 当前公布的 `deepseek-flash`。官方 route identity 只适用于该模型与 `https://api.deepseek.com[/v1]` 的精确组合；同名自定义 endpoint 仍按自定义路由隔离，不能继承官方执行资格。

桌面设置页可为已发现的模型启用或禁用，并从已启用且可用的模型中选择默认模型。当前默认模型不能直接禁用，需先选择另一默认模型；禁用的模型不应出现在任务输入区的可选列表，也不能作为新执行的路由。禁用一个模型不影响同一提供商中其他已启用模型的配置可用性。

## 生效与限制

活动执行使用开始时确定的配置，保存新的期望配置供后续执行使用。功能开关启用不替代授权和平台支持；默认关闭的扩展不能凭旧文档推断可运行。

`resources.maxConcurrentSubagents` 可在用户级或项目级 `kite-code.jsonc` 中设置为 1–28 的整数；项目配置覆盖用户配置。超过该配置范围的数值会在加载时被拒绝；这项上限限制同一父 Run 可同时运行的子 Agent 数量。未设置时，一个 Run 最多同时运行 3 个子 Agent。该数值在 Run 开始时写入预算并告知模型，修改配置不会改变已开始的 Run。

CLI 当前拒绝 `--feature` 等已退役覆盖选项。设置操作见[TUI 设置](../clients/tui/reference/settings.md)，命令支持见[CLI 参考](../cli/commands.md)。
