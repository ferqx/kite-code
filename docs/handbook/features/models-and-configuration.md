# 模型与配置

模型选择包括 Provider 与具体模型，相同名称不代表同一请求目标。工具调用、推理深度和上下文能力取决于模型与配置。

## 配置范围

通用 Agent 的用户配置位于选定 Profile 的 `config.jsonc`，项目配置为实际 Workspace 下的 `kite-agent.jsonc`。配置项各有合并规则，不能把一般的项目覆盖规则用于凭据、内容日志或权限上限等受限项。

客户端的语言、主题等偏好与服务的模型配置分开维护。修改 TUI 语言不承诺 Web 同步改变，修改模型也不改变已经开始的模型请求。

Provider 凭据通过实际支持的配置和认证入口维护，不在手册示例中填写真实 key。配置错误会阻止相应操作，不能静默切到另一个模型冒充成功。

通用 Agent 入口需要在所选新 profile 配置可用模型，不读取旧正式配置。旧入口的内置 DeepSeek 默认路由与资格是历史行为，不能据此为新 Run 猜测 Provider、endpoint 或凭据。相同模型名称和自定义 endpoint 仍须按实际路由身份核对，不能继承其他路由的执行资格。

桌面设置页可为已发现的模型启用或禁用，并从已启用且可用的模型中选择默认模型。当前默认模型不能直接禁用，需先选择另一默认模型；禁用的模型不应出现在任务输入区的可选列表，也不能作为新执行的路由。禁用一个模型不影响同一提供商中其他已启用模型的配置可用性。

## 生效与限制

活动执行使用开始时确定的配置，保存新的期望配置供后续执行使用。功能开关启用不替代授权和平台支持；默认关闭的扩展不能凭旧文档推断可运行。

当前 Runtime 的可信配置 `maxConcurrentSubagents` 范围为 1–28，缺省为 3，限制真实同时运行的子任务；活动 Run 保留已选择配置。旧 JSONC 的 `resources.maxConcurrentSubagents` 和预算保存格式不自动成为新 Service 的用户配置项，实际支持的文件字段见[配置 owner](../../../packages/agent/src/config/README.md)。并发槽、取消和等待策略不构成整个 Run 的累计额度。

[V1.3 D17](../../plans/unified-agent-refactor-v1.md)明确退役旧隐式累计预算与隐藏子任务总步数。新 Run 不因累计 turn、模型请求、token、工具调用或产物字节超过旧门槛提前停止；实际 Provider 窗口、并发与明确运行策略仍约束执行。旧 Release Profile/活动 Run 的兼容转换属于历史实现，当前新数据基线不自动迁移旧用户数据。

项目 `CLAUDE.md`／`AGENTS.md` 的适用内容会完整进入模型上下文，不因旧单文件、合计字节或 token 额度静默遗漏；相关文件新增、修改或删除后，待执行的副作用需要先刷新指令。上下文压缩保留完整的自定义说明，只有真实模型上下文窗口和输出能力限制摘要请求；不再使用固定 6000 token 摘要、4096 字符说明、至少节省 1024 token 或固定次数／冷却作为本地门禁。自动压缩失败会保留原上下文并继续执行；同一未变化的上下文不会立即无限重试，新增上下文或手动压缩可再次尝试。若完整请求确实超过 Provider 能力，Provider 仍可能拒绝。

通用 Native 的提供商设置支持 OpenAI、DeepSeek、OpenAI-compatible 和 Ollama 的明确连接与模型名称。手动填写模型名称时直接保存；留空时，只有这次显式保存才查询该连接的模型列表。新加入模型默认禁用，需在模型页启用后才能选择。相同提供商可保留不同连接；保存不会删除其他连接或项目模型。API key 由选定 Profile 的系统凭据库保存，配置只保存引用，提交后清空表单密钥。配置可用不代表远端账户或模型已经验证成功。

输入区从已启用且配置可用的模型中选择下一次运行的路由，选择按 Session 隔离，不修改全局默认或其他会话。新 Session 在首条输入前不绑定模型；首次输入保存实际选择，已有会话在下一次新运行采用其选择。活动运行保持原模型，运行中的普通发送仍是文本引导。

服务声明支持的 OpenAI／OpenAI-compatible 模型可临时选择推理强度；未选择时沿用配置或提供商默认值。临时档位按当前页面中的会话保留，切换模型或刷新页面后重置。它随原始开始／后继输入冻结到实际请求，不写全局配置，不改变活动运行；子任务仍按自己的角色配置选择。

设置保存分别显示凭据保存与配置发布结果。配置已发布但刷新失败时可重新读取；凭据已存而配置未发布时保留各自事实。结果未知只允许显式查询原提交，关闭面板或刷新不解除等待，不会自动重发或回滚。冲突需重新读取配置后提交新的明确意图。

统一 Agent 开发链路可在兼容模型 options 中设置推理强度，并为每个执行保存实际采用值；已开始的执行保留原选择，后续执行采用新配置。可传输的选项不保证远端模型接受，拒绝会如实显示失败。完整模型发现、输入区选择和设置界面范围仍按[实施进度](../../plans/unified-agent-refactor-v1-progress.md)逐项验证。

新的统一 Agent 压缩保存实际摘要模型请求、覆盖范围和来源，保留原历史。摘要在后续输入中作为低权限历史数据使用，不授予工具或审批权限；压缩命令已受理不表示摘要已发布。重置前需确认完整展开输入可安全采用，缺少准确预检或预检拒绝时保留当前压缩点，不调用模型。开发 Native 与 TUI 的具体入口及已验证范围见[实施进度](../../plans/unified-agent-refactor-v1-progress.md)，正式入口和真实模型窗口资格单独验证。

CLI 当前拒绝 `--feature` 等已退役覆盖选项。设置操作见[TUI 设置](../clients/tui/reference/settings.md)，命令支持见[CLI 参考](../cli/commands.md)。
