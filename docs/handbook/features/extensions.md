# MCP 与 Skills 扩展

MCP 离线、未登录或尚未批准，不阻止无需该能力的普通对话。实际使用工具时仍检查认证、项目批准和权限；继续普通对话不会记录用户豁免。旧 `required` 配置仅保留为兼容元数据，不再生成会话门禁。

MCP Server 可提供工具、资源和提示。Skills 可提供可发现指导与工作流。它们需要正确配置、发现和必要权限，不会因为仓库里出现一个文件就自动成为可执行能力。

MCP 连接成功不等于所有工具已披露给模型，也不等于写操作获准。工具可能按需加载；认证、项目 Server 确认和配置范围分别处理。

Skill Activation 和 Skill Workflow 默认受开关限制。手册不承诺默认安装即可使用所有 Skill 工作流。某个模型不支持工具调用时，扩展的使用方式也受限制。

[TUI 扩展指南](../clients/tui/guides/mcp-and-skills.md)说明管理与动态命令；CLI 可通过支持的 `--skill` 请求已可用的 Skill。Web 当前不配置或执行这些扩展。

外部系统返回内容仍需核对，不能把工具描述或外部文档视为项目授权。
