# 核心产品概念

| 概念 | 含义 | 不等同于 |
| --- | --- | --- |
| 工作区 | 本次任务访问的项目范围 | 浏览器页面、进程或会话名称 |
| 会话 | 可继续的对话与执行历史 | 一次模型调用或一个客户端窗口 |
| 用户消息 | 用户提交的一次输入 | 仅显示在输入队列中的候选 |
| 一次执行 | 围绕输入推进模型、工具和交互，直到终态 | 一段正文开始或结束显示 |
| 工具调用 | 读取、命令、修改或外部能力请求 | 已获批准、已成功执行 |
| 审批 | 对具体操作作出授权决定 | 工作区信任、永久授权全部操作 |
| 计划 | 对目标、步骤和验收的组织 | 已执行完成的证明 |
| 历史 | 已保存的消息和运行事实 | 终端滚动内容或全部瞬时思考 |
| 恢复点 | 可用于相应恢复操作的边界 | 任意一行消息都能回滚 |
| 分叉 | 从已有历史建立新的继续路径 | 在原会话里覆盖历史 |

例如：在 TUI 提交任务会开始一次执行，期间可能多次调用模型并运行多个工具；切到另一会话只是改变前台。Web 可以查看这份会话数据，但不能因能看到审批就代为批准。

正文完整显示时，工具和执行可能仍在收尾。判断完成需要阅读最终结果与状态；取消也不能撤销已经发生的外部作用。

[能力对照](capabilities.md)说明各入口如何使用这些概念，客户端指南说明具体交互。
