# 桌面客户端（开发中）

Tauri 桌面客户端已完成首轮本机接入与原生验收，尚未作为正式入口发布。[首版计划](../../../plans/desktop-client.md)保留完整目标；当前不能据首版范围推导所有功能已可用。

开发版可选择本地项目、确认工作区信任、配置 Provider 和选择模型、新建和查看最近会话、提交任务、读取文本与工具过程并取消执行。安装与运行方法见[开发入口](../../../../apps/kite-desktop/README.md)。

打开项目不等于信任项目；确认面板显示工作区及关联外部只读目录。会话内容按所属会话展示，输入草稿在当前进程按项目与会话保留；退出后的草稿恢复尚未提供。

关闭窗口保留应用与任务，再次激活显示原窗口；明确退出或断开项目会停止自有服务中的执行，已有修改不撤销。当前退出确认覆盖整个服务连接，尚未根据活动任务省略空闲提示。异常收尾会提示检查结果，不自动重发请求。连接断开后不能使用旧的就绪状态提交操作；回执丢失时显示“操作提交结果未知”，应明确重连并检查会话及实际文件后再决定继续。

工具审批会显示具体命令与说明，可以选择“仅批准这一次”或拒绝；结果仍由服务核实。补充问题支持选项、允许的自由回答及明确取消。取消回答会把取消结果交给模型，模型仍可继续；结束整个执行应使用“停止任务”。计划面板显示正文与步骤，支持 Accept Edits/Auto 批准、修改要求及取消；正文缺失或超过显示上限时不能批准。扩展或验证交互仍显示限制，用户可取消。高级恢复尚未交付。

展开“会话变更记录”可阅读成功文件工具保存的差异或写入内容；这不是当前工作区 Git diff，也不覆盖 Shell/MCP 等工具未报告的逐文件修改。输出可能截断，空列表不代表磁盘没有变化。可选择 VS Code、Zed 或 TextEdit 打开当前项目内仍存在的文件；打开的是当前磁盘内容，编辑器需已安装。本机 macOS 已确认 VS Code 实际打开对应文件；TextEdit 仅确认启动分发，Zed 未安装验证。

已有会话加载时显示进度，长历史分批读取后完整展示，超时提供错误提示；明确重连会恢复所选会话与进程内草稿，不重发任务。目录从服务最近最多 1,000 条会话中展示当前项目的会话。切换项目先确认停止旧连接任务，等待清理后打开目录选择器；取消选择后可重连原项目。工具取消或拒绝后的历史不再显示为进行中。

展开“模型与 Provider 设置”可保存 OpenAI、DeepSeek、OpenAI-compatible 或 Ollama 配置。API key 随本机用户 kite-code.jsonc 保存，输入在提交后清空；保存会替换同一 Provider 的配置。模型名称留空时查询模型列表，手动填写时直接保存，是否可执行仍需实际任务验证。保存后点击模型，即使它已选中，也会刷新后续执行使用的配置。提交结果未知时应检查最新配置，不自动重试。

本机 macOS 已完成配置、问题/计划、项目与会话草稿、修改与测试、结果阅读、VS Code 跳转和重启后继续的原生验收；真实外部 Provider 的服务执行另行验证。另已验证长会话阅读、与 TUI 的同会话写入保护、服务制品损坏提示，以及手动替换应用后的会话和数据保留。桌面端仍是开发版本；正式签名、公证、下载分发与签名包升级、其他平台尚未完成资格验证。包内 Service 已验证自身 MCP OAuth 凭据的原生保存和重启恢复；从其他程序导入已有凭据的系统授权行为未完成验收，不承诺无提示迁移。
