# Kite 桌面客户端（开发中）

当前窗口中新出现的会话在首条消息保存前直接显示在所属空间列表顶部，目录刷新不会先把它放到底部；消息时间到齐后按最近消息时间排序。空会话不补造消息时间，冷打开的历史仍保持原有未知时间。

Windows 客户端启动后会在任务栏通知区域创建 Kite 托盘图标。双击图标可显示并聚焦主窗口，最小化时先恢复窗口；右键菜单提供“打开 Kite”和“退出”。关闭窗口后客户端继续在后台运行，可从托盘重新打开；选择“退出”立即关闭可见界面，最多5秒结束进程。

Windows 启动时先检查所选数据根、Profile 协调目录和主要数据库文件的权限；异常时在启动服务、打开数据库及创建主窗口前显示受影响路径，默认选择“退出”。“重新检查”只检查权限，不提交修复。正式版沿独立的 `~/.kite-code/unified-agent` 数据根使用 `default` Profile，开发入口仍使用 `~/.kite-code` 下的 `development`；测试应使用自己的独立数据根。

当对象仍属于当前用户、原有私有权限完整，仅多出读取／执行授权时，可明确选择“备份并修复权限”。Kite 先把原权限保存为数据根内独立的 `permissions-backup-*.txt` 私有文件，再仅移除已确认对象上的额外授权；不递归修改子项、不删除数据、不自动重新执行历史任务。修复后重新检查，全部通过才继续启动；如还有其他异常对象，会分别显示并等待明确选择。原权限备份保留，不自动恢复可能不安全的旧授权。

目录被占用、备份失败、身份或权限发生变化时，修复停止；关闭使用该数据根的其他 Kite 客户端后可重新检查。存在其他用户可写、所有者不符、链接、未受保护的目录或无法核实的对象时，不提供内置修复；需要核对权限及数据完整性，必要时联系管理员。修改结果未核实时保留备份并停止启动，不自动重试修改。实现和当前验证范围见 [Desktop owner](../../../../apps/desktop/README.md#windows-数据权限预检与恢复)。

已知工具在处理过程中始终使用可读名称，如“查找文件”“搜索内容”；工具名称不附加版本号，升级版本也不会使已知名称退回内部 ID。遇到尚未支持的结果格式时仍可阅读原始记录，名称本身不表示执行成功或取得操作权限。

已支持的文件读取、写入和修改在逐项工具行显示目标路径，查找／搜索显示匹配条件及明确指定的范围，列目录显示目录；MCP 搜索、资源／提示词、计划与 Skill 中有明确目标的操作显示相应查询、资源、计划或引用。排队、执行中与完成后的记录沿用原目标，子 Agent 详情同样可读；长目标沿原单行布局省略，悬停可查看完整展示目标。输入无法核实或版本未知时不猜目标，目标文字本身不授予文件打开或其他操作权限。

“浏览器操作”的工具行会显示这次调用的简短执行说明，例如“读取北京天气”，说明最多10字，沿原单行布局省略并可悬停查看。“加载技能”只显示真实技能名称，例如“加载技能 computer-use”，不附调用目的；“读取技能资料”只显示技能名称和资源路径，不附执行描述。排队、执行中及历史阅读保留同一次调用的说明；它不表示执行成功，失败、取消与结果未知仍按真实状态展示。旧记录没有说明时保留可读工具名和已有技能引用，不从代码或结果猜写说明。

浏览器正常操作只显示工具行、执行说明和真实状态，不提供原始 JSON、页面快照或脚本输出的展开入口。失败、拒绝与结果未知仍可展开阅读原错误详情；完整执行记录继续保留。

具体工具消息只在该条的完整展示元数据到齐后一次显示，不先显示只有“读取”等名称的半条消息再补路径；完整一条显示一条，不等待其他工具，也不等工具执行结束。普通刷新及回执核验可保留同一工具此前已核实的完整展示，来源冲突则撤下，不拼接半成品字段。返回缓存中的会话时，同一工具保留已核实的图标，不先变成通用图标再切回；相关读取与操作仍等待当前会话核实。

已有执行结果的工具用“已读取”“已写入”“已修改”等完成式名称；Shell 执行后保留“已运行”和原命令。失败行用红色表达，摘要不再额外添加“运行失败”，文字保持常规字重，具体错误在展开后阅读。“已”描述这次操作已有结果，不代表成功；排队、执行中、未执行和结果未知保留各自状态。

Git 工作树失败的展开详情区分“进程启动失败”“权限拒绝”和“Git 命令失败”，显示已核实的错误码或退出码及下一步核对方向。进程启动的 `EPERM/EACCES` 不写成用户拒绝；旧记录无分类时保留原因未分类。原调用、错误及部分作用／结果未知／清理未确认的恢复说明继续可读，不提供重新执行工作树操作的按钮。

工具组及展开后的工具行在普通刷新、加入子 Agent 操作和回执接管时保留原节点与展开选择，仍在执行的扫光继续当前进度。同一连续工具块中已观察的工具位置不因完成回执先后改变；新的说明正文、引导或轮次仍保留各自边界。扫光样式与正常循环保持，真实结束及执行权无法核实时按原状态停止活动显示。聚合中的工具行采用更紧凑的上下留白，展开正文的行距保持；连续点击开合时，动画从当前高度反向过渡。

Agent 流式回复按元素更新，未变化的段落、列表项、表格和代码块保留已有展示。新追加的普通正文按可见字符依次渐显，中文和组合 emoji 均保持完整；单字渐显约240ms，较大批次会缩短字间间隔，整批最多约420ms，已经可见的文字不重新播放。历史加载、正文纠正与缓存返回直接显示内容，系统开启“减少动态效果”时直接显示新增文字。Markdown语法补全时，受影响的元素继续更新，例如后补链接定义或闭合强调标记。

渐显只改变新增文字的绘制颜色，正文始终按连续文本排版；不为每个字符创建行内节点，也不在结束时换成另一种字距或字体。相同正文在流式与完成后保持相同换行。浏览器不支持所需绘制接口时直接显示新增文字。

正常流式输出按已保存消息的变更增量更新，不因每批文字重新读取全部历史。首次打开、重开、断线重连或历史变更凭据失效时重新核对完整历史；核对期间保留已读正文，相关操作等待恢复。消息按原身份更新，独立发送的相同文字仍是两条消息。同步连续时发送前不额外全量重读；消息保存、发送准入和任务执行仍各自核实。

从侧栏切换普通会话时，标题和选中项立即跟随目标；命中完整页面缓存时，目标会话的原正文、阅读位置、草稿、模型和审核方式一起立即恢复，无须等待后台选择确认。后台核实完成前输入区暂时只读，复制、正文读取和提交仍须等待当前会话核实。窗口内最多保留8个非当前正文页面，并受缓存容量限制；内容仍在更新、尚未完成缓存准备、缺少配套输入区状态或已经被回收的页面，返回时显示统一加载状态，准备好后同时显示消息和输入区。不在目标标题下临时显示上一会话的消息、模型、审核方式或草稿。已离开页面的模型读取取消或晚到结果不在目标会话下显示目录错误；真实读取失败仍显示错误并暂停发送，重新进入会话且目录核实成功后恢复，不自动替换所选模型。快速连续切换时，迟到结果不能覆盖后来选择的会话。

从定时任务返回会话，包括返回同一会话，也遵循上述缓存规则：有完整缓存立即恢复目标整页并后台核实，没有完整缓存才等待统一加载。当前选择、模型、权限与草稿准备完成后一起接管；准备失败时保持只读或未就绪，后台通知不会提前发布半套状态。重新进入或读取恢复后完成交接，不重新发送原任务。普通刷新继续保留已经可见的消息与输入区。

等待整页准备时，输入框内的模型、思考档位、权限图标／文字和附件等子控件一起隐藏，切换过渡中不留下上一页的控件残影；就绪后整套恢复。命中完整缓存仍立即显示目标会话。

尚未选择模型、尚无审核方式标签的会话，也保留已经核实的页面缓存；返回时恢复其原有空态，操作仍等待当前核实。直接切换到未缓存会话后，如果选择确认或草稿读取失败，继续显示目标标题及加载状态，读取恢复后接管，不退回上一会话的标题、消息或输入状态。

后台重读历史时，权限标签沿用该会话已核实的显示或缺席，不因消息读取而临时补出“审核方式”；首次权限读取尚未完成时仍保留原静态提示，真实权限变化和失败按当前事实更新。

首次打开未缓存的主会话时，不超过100条可见消息分组完整显示；超过100条先显示末尾40条，向上滚动接近顶部时每次补入20条较早消息，保持原阅读位置，也可点击“加载更早消息”。折叠轮次中的工具记录不各算一条。每条回复仍完整显示，特别长的单条回复可能需要更长准备时间。Ctrl/Cmd+A只全选当前已加载内容。缓存返回保留已加载消息和阅读位置；页面回收后按原阅读锚点恢复附近消息，向前／向后滚动继续补入。会话持续更新跨过100条时不突然移除已加载内容；“回到最新消息”恢复尾部阅读。默认折叠的工具过程和聚合明细在展开时才准备内部内容，展开／关闭、读取和操作规则保持。具体本机性能与适用范围见[Desktop owner](../../../../apps/desktop/README.md#大会话首次构建)。

会话页面内的消息、工具明细与输出、文件差异、侧栏和选择弹层均使用较细的原生滚动条。嵌套区域触及边界后由浏览器继续滚动外层，保留原生滚动惯性。会话正文与底部输入区居中显示，最大宽度为 740px；窄窗口下随可用空间缩小。新对话与已有会话共用相同的水平留白和滚动条预留，往返切换时输入区不横移或变宽，已有消息区与输入区保持对齐。向上阅读时，“回到最新消息”以带浅阴影的圆形图标按钮显示在正文区域底部中央，位于消息内容之上，并随环境信息占位和窗口宽度保持对齐；会话进行中显示依次跳动的三个点，静态时显示向下箭头。手动滚动接近底部时保持阅读位置，实际滚到底部才恢复跟随；点击按钮则立即回到最新消息并恢复跟随；减少动态效果模式下三个点静止。

全局原生滚动条的滑块随深浅主题使用半透明的前景色，轨道保持透明，降低静止时的视觉存在感；悬停和拖动时略增强，仍保持低透明度。系统强制颜色模式沿系统配色。

界面标题与设置名称通过字重区别于普通正文。Markdown 消息正文中的斜体均可辨认，中文同样保留倾斜效果；行内代码、代码块、Shell 输出和等宽配置输入使用一致的等宽字体。

图标按钮统一采用以下尺寸，按用途选择；普通图标按钮沿公共按钮规范使用8px圆角。提示词输入框内的按钮采用两端圆滑的胶囊形，发送／停止、附件移除和回到最新消息保留各自的圆形轮廓。

侧栏的会话标题与所属项目名称左缘对齐，选中背景覆盖整行。会话的运行中图标采用14px，与空间行的编辑、更多等操作图标保持相同大小；运行中和等待执行时每2.4秒匀速旋转一圈。

会话通过 `git_worktree` 成功创建工作树并保存确认记录后，该会话项右侧显示 Git 分支图标，提示“已创建 Git 工作树”；运行中、待输入和未读回复提示仍可同时显示。标记保留在创建它的会话，刷新和重开后仍显示，子 Agent 的创建不标记父会话，Fork 不继承。它记录已发生的创建，移除工作树后仍保留；不表示目标目录当前存在，也不改变会话工作目录。失败、取消、结果未知和仅列出工作树不会产生标记。

要在新工作树中执行任务，从“新对话”的项目菜单选择“添加项目…”，选中真实 worktree 目录，再在该项目中创建会话。原会话继续绑定来源项目；已有会话的点击只切换阅读，不迁移执行目录。分支菜单用于当前项目的分支，不用于选择其他 worktree。目标不能嵌套在来源 checkout 或其他已登记 worktree 内；位于当前授权工作区之外的目标，以及 linked worktree 根目录外的共享 Git 元数据写入，仍须取得相应权限，创建成功不自动授予后续操作。

工作树项目能核实唯一创建来源时，标题栏显示“退出工作树”，点击只返回来源会话；工作树目录、原任务和各会话的未发送草稿保留。输入独立的“退出工作树”“退出 Git 工作树”“退出 worktree”“返回来源项目”“返回来源会话”或 `exit worktree`／`leave worktree` 也只在客户端导航，不发送模型任务。输入含附件、图片、浏览器注释，或是解释、引用、代码和复合要求时，仍作为普通聊天。创建来源会话本身未因创建切换目录，独立退出命令只说明该事实；来源缺失、歧义、不可见或旧服务未提供关系时保留草稿并提示从侧栏选择，不让模型猜成删除。Auto 模式下准确工作树工具及其内部步骤免审批，删除仍须有明确目标和删除意图，并通过原保护检查。

手动删除或移走 worktree 不会删除应用保存的会话和历史，也不会自动重建目录或将原会话改绑到其他项目。来源项目仍存在时，创建历史图标继续保留；如果被移走的目录本身已作为项目使用，该项目历史仍应可读，依赖目录的新执行和权限操作需等待目录恢复并重新核实。将新目录重新放到同一路径不等于恢复原有信任。

会话最新一轮结束且尚未查看时，列表项右侧显示带微光的蓝色圆点；成功、失败和取消等终态均可触发。打开该会话、窗口可见且历史和本轮状态读取完成后，将已读记录保存到本机数据库，成功后圆点消失。已在可见窗口正常阅读当前会话时，本轮结束及已读保存期间不先短暂显示圆点。切换中、读取失败、保存失败或窗口隐藏时，未完成保存的提醒仍保留或恢复；已读后下一轮结束会再次提醒，运行中仍使用原转圈图标。查看记录按数据源与会话保存在本机，完整退出后重新进入、开发启动地址或安装目录变化均不会使已读圆点重新出现；不跨客户端同步。

消息复制按钮悬停或键盘聚焦消息时显示，复制成功和失败仍在原按钮反馈。消息工具栏内的复制按钮与时间文本间距统一4px；用户消息气泡或 Agent 正文到下方工具栏保留2px，工具栏与下一条消息至少间隔8px。

本轮执行期间，处理过程保持展开，标题不提供折叠操作；排队、等待、停止中或暂时无法确认状态时也不会提前收起。正常完成或主动停止后默认收起并允许手动展开。若因失败或异常中断而没有最终回复，处理过程默认展开，外层不设高度上限，全部内容随会话滚动阅读；手动收起的选择仍可保留。单个工具的错误详情仍可独立展开或收起。

“正在回复…”与完成后的“复制、时间”使用同一信息行位置，行高统一28px，距正文2px；回复完成时仅替换行内内容，正文与下一条消息不因信息行切换而上下跳动。“正在思考…”沿用相同行高。处理过程中的中间正文仍不显示复制与时间。

用户消息与 Agent 正文在同一信息栏显示记录时间，随消息悬停或键盘聚焦一起出现。用户消息按“时间、复制”靠右排列，Agent 正文按“复制、时间”靠左排列；时间不进入消息复制或聊天全选文本。

“处理过程”里的 Agent 阶段说明、流式中间正文和普通 Agent 邮件不显示消息复制、记录时间或其占位留白。最终回复移到过程外后显示原信息栏；用户输入、用户引导及过程外独立消息保留各自原有操作。复制仍须满足完整正文资格。

悬停时间可查看含年份、秒和 UTC 偏移的完整日期；再次悬停或聚焦消息会按当时日期更新“昨天”等显示。时间取自消息首次保存，流式追加、复制、刷新和重开不重置；原输入由业务消息接替时保留原输入时间。未取得可核实时间的旧历史或投递占位显示“时间未知”，不使用打开页面的时间补齐。

## 提示词与附件

模型使用 `view_images` 一次读取最多10张本地图片后，原工具消息显示“已查看 N 张图像”和圆角缩略图，默认展开，可通过标题折叠；多图按原顺序自动换行。读取中、失败和取消保留实际状态；成功数量来自已核实的图像结果。预览加载失败时可重试读取同一保存结果，折叠或切换不会重新调用图片工具或模型。本地保存及权限范围见[工具手册](../../features/tools-and-approvals.md)。

首次进入客户端或尚无模型选择时，输入区只显示“选择模型”，不会自动填入配置中的默认模型；明确选择后才可发送首条消息或新的运行。当前会话已保存的模型选择继续恢复，失效时要求重新选择；新对话准备页不借用旁边会话的选择，但可恢复同一数据源中已明确记住且仍可用的模型与思考档位，完整退出重开后继续保留，开发客户端更换启动端口也不影响；没有记忆或记忆模型失效、禁用时仍显示“选择模型”。正在运行的任务继续使用原模型，普通文本引导不要求重新选择。

已保存的会话输出可以在对应处理过程里展开“查看本次交付的文件”，阅读当次交付的内容。后续修改不会改变旧版本；“打开当前文件”另行打开最新工作文件。较长历史正文可继续读取下一段。PDF 按页读取生成的页图显示在原工具过程下，源文件删除或重开会话后继续读取已保存的原件与历史页图。

附件原件、输出文件和当前方案均持久保存。本文说明当前操作行为；已验证的操作过程与完整安装资格见 [Desktop owner](../../../../apps/desktop/README.md)，PDF 读取与实际模型范围见 [Files owner](../../../../packages/agent/src/tools/files/README.md#会话文件与-pdf)。

普通回复与历史正文直接完整显示，不附“回复预览”“完整回复”标题或查看／收起按钮。读取期间保留已有正文，核实完整内容后即可复制；核实原输出已终止且仍不完整时明确提示“回复未完成”，正常生成中的流式前缀和读取中间状态不插入这条提示。当前原回复的正常追加或完成切换，不应误报完整回复读取失败或插入瞬时错误造成阅读跳动。真实读取失败保留原文并说明失败，回复内不提供“重新读取”按钮，不重新发送任务，也不展示内部错误代码。

提示词输入框是普通多行文本框，直接编辑Markdown源文，不在输入时渲染。发送后，用户消息与Agent回复采用相同的Markdown规则与排版，支持GFM表格、强调、列表、引用、代码、链接、公式和图表。表格使用竖线与分隔行写法并保留左右／居中对齐。输入和复制保留原文；Enter发送、Shift+Enter换行，中文输入法确认候选不会触发发送。

桌面正文中的粗体和斜体支持中文标点与后续正文紧邻的写法，例如`**说明：**后续正文`会正确加粗“说明：”，不显示星号。流式补齐和历史重开使用相同规则；代码及转义星号仍显示原文，保存与复制的Markdown源码不被改写。

| 内容 | 写法与阅读方式 |
| --- | --- |
| Mermaid 图表 | 使用 `mermaid` 代码围栏，支持 `graph`／`flowchart` 流程图、时序图、类图、状态图和 ER 图。图表可切换到源码，复制仍复制原始代码。 |
| 代码高亮与 diff | 围栏填写 `typescript`、`python`、`json`、`sql`、`bash`、`diff` 等语言标记；diff 用文字颜色区分增删，不加行级色块。未知语言或较大的代码块保留原文。 |
| 提示块 | 引用以 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 或 `[!CAUTION]` 开头，显示对应类型的中文标题、图标和低饱和底色。 |
| 公式 | 行内使用 `$E=mc^2$`；独立公式放在上下各一行的 `$$` 中。较宽公式可横向阅读，错误公式保留可读内容。 |
| 标题与脚注跳转 | `[跳转](#标题)` 跳到当前消息的对应标题；脚注支持 `[^名称]` 引用、`[^名称]: 说明` 定义和返回正文。相同标题依次使用 `标题`、`标题-1` 等目标。 |

图表围栏尚未闭合时先显示源码，闭合后绘制；错误修正后重新绘制。图表使用透明底与细线，节点边框、箭头、生命线、分组和注释沿主题前景与次级灰色区分层级，随深浅主题调整；文字保持正文颜色。闭合图表使用预留的稳定阅读区域，源码、绘制等待、结果与错误回退不改变区域尺寸；图像保留自然尺寸，较宽或较高时在区域内滚动。包含自定义配置／样式、HTML、图片、点击行为、不支持类型或超出绘图限额的内容显示源码，正文不被截断。Markdown图片仍只显示描述，附件图片沿原附件流程展示。上述新增展示适用于桌面客户端；独立Web与TUI不因此取得相同支持。

主内容区与右侧栏共用中性灰配色，采用更暗的中性灰背景层次；发送按钮、选中态与焦点使用灰色，链接沿正文颜色并显示下划线。深色正文使用接近白色的 `#ededed`，次级文字使用较亮的 `#c6c6c6`，与深灰背景拉开明度差。一级、二级Markdown标题在后面有内容时带细分隔线，末尾标题不保留分隔线和额外留白；消息首末元素及引用、列表项和表格单元格边缘不叠加外边距；普通引用使用浅于正文的底色和左侧竖线；代码块使用小圆角、细边框和语法高亮，保留语言与复制入口；表格使用透明表头和横向分隔线，不再绘制外框与纵线。行内代码使用等宽文字、轻底色和小圆角，提示块继续按原类型显示图标、中文标题及语义色。浅色模式保留原有浅色配色，并采用相同的内容排版。

文字与底色按深浅模式成对配置，正文、次级文字和可用控件的文字按至少4.5:1核对；hover、选中与按下使用随当前前景变化的半透明叠层，核对叠加后的实际底色。必要的键盘焦点和状态图形按至少3:1核对相邻底色。主内容保留不透明背景，左侧玻璃的壁纸色不参与正文底色；新增主题颜色时沿用相同的配色与核对方式。

这些字体与排版只用于会话主内容区；左侧空间／会话列表的布局、字体与控件、右侧栏的字体与控件布局、全屏设置字号与排版和窗口顶栏保留原有样式；会话与设置的主区、右栏由共同内容面板统一配色。左侧栏背景使用下文说明的灰色玻璃材质。主内容区字体沿 VS Code 的平台默认分工：Windows 的界面与普通正文使用 Segoe UI，代码与命令使用 Consolas；macOS 使用系统界面字体和 Menlo／Monaco，Linux 使用系统界面字体和 Droid Sans Mono 回退。中文继续沿对应系统字体回退。主内容区正文和提示词输入为13px；普通会话正文和列表使用500字重，标题与强调保留原有层级，提示词输入和代码保持400字重。最终字面粗细由系统可用字体匹配。普通正文行高30px、内容块间距20px；围栏代码使用13px等宽文字。

正文与输入区的链接始终显示下划线，键盘聚焦仍保留可见提示；没有打开资格的路径仍显示普通文字。点击正文中的 HTTP／HTTPS 网页链接，或聚焦后按 Enter，在系统默认浏览器打开对应页面，聊天窗口保留原消息；浏览器启动失败时显示“无法打开链接”，可检查默认浏览器设置后再次点击。输入框中的代码、引用和链接采用相同的视觉语言，编辑时链接仍不导航。

主内容区以外的界面继续优先使用 Geist 字体，中文按系统界面字体回退；默认字号固定为14px，普通正文、表单、按钮与列表主标签共用这一基准，宽窄窗口不切换字号。标题、Markdown 内容层级、代码、徽标与辅助说明按各自用途保留字号差异。普通文字使用常规字重，界面标题使用中等字重，减少厚重感。设置页的字段名、分组名、模型／连接名称、表单标签、说明与当前值统一为400；页面和右栏标题为500。公共按钮、选择器、菜单、标签页与徽标中的文字和图标垂直居中；左侧主要导航与空间名称采用相同的图文间距和文字起点，并按实际字面校正视觉高度；选择器触发区域的长名称在可用空间内截断，前后图标保持完整。

状态色与中性灰主题统一：错误和危险操作使用暖红，警告、权限与注意提醒使用偏红的暖橙色，成功使用柔绿，信息提示和未读提醒使用柔蓝，重要提示使用淡紫。文字、图标、边框和浅底色按同一类别配套，深浅主题分别适配；危险按钮的默认、悬停、按下及键盘焦点使用独立的红色阶，错误表单保留清晰的红色边框与焦点。成功提示、文件增删、Markdown提示、浏览器标注与子Agent彩色图标沿这套配色协调展示。

普通问答、方案审核、通用操作与浏览器注释表单采用统一的输入、选择和按钮外观，背景、边框及键盘焦点随深浅主题保持一致。清空选择不会自动改选其他项；必填内容未完成时不能提交，提交失败继续保留原输入。

主内容区输入框默认使用13px字号；提示词输入框内的模型、思考档位和审批方式选择器使用 13px，项目／分支选择器、模型列表及选择菜单统一使用13px；项目／分支菜单的单行选项为28px高、18px行高，上下内边距4px，长名称换行时自然增高；上下文浮层保持14px；模型双栏浮层默认宽320px，其中提供商列为128px，窄窗口下仍限制在可用宽度内；模型列表的提供商与模型名称使用常规字重，列表项高度与输入框内选择器一致，均为28px，上下内边距为4px；项间距及列表上下留白保持2px，两列外层留白统一为4px，标题上下内边距为6px，与审批方式菜单一致；标题与条目文字沿相同的8px左右内边距对齐，保留原默认高度。未选中模型与未选中提供商使用相同的弱化文字色，当前模型使用正常文字色并显示勾选图标；提供商和模型项只在鼠标悬停时显示底色，移开后恢复透明背景，键盘导航保留焦点提示；输入框内选择器的图标与上下文状态圆环为 14px，缓存率文字为13px，文字区域至少70px宽并居中，可随内容增宽，与圆环相隔4px；项目／分支与模型选择入口的图标为14px，附件、发送／停止和展开菜单的操作图标同为14px。底部工具栏按 32px 高居中对齐，选择器为 28px 高、上下 4px／左右 6px 内边距：附件、模型和审批方式放左侧，缓存率与上下文圆环放右侧，与发送／停止按钮留出间距。空间不足时，右侧状态和发送／停止按钮整体换到下一行并保持右对齐，模型名称可省略显示；权限弹层宽度随标题、名称和说明自适应，达到窗口可用宽度时自然换行。弹层采用更紧凑的排版：标题与名称为 13px、说明为 11px，均保持常规字重；常规宽度下标题区单行排列，弹层、标题、选项和分隔线的内外边距遵循组件库默认规范，较窄区域的说明自然换行。输入框以普通文字显示Markdown源文，发送后在消息中渲染。Enter 发送，Shift+Enter 换行，中文输入法确认候选不会发送；发送时去掉正文末尾连续的换行符（包括多个 LF／CRLF），保留正文中的换行、缩进和尾部空格；不同会话的草稿独立保存，切换后不会撤销出其他会话的内容。发送等待时按钮显示loading并阻止重复发送，输入框保持可编辑，不因发送变暗、禁用或变为只读。等待期间继续输入或清空的草稿不会被原回执覆盖；新会话首发接管时带入新创建的会话。消息受理、任务运行且输入为空时，原发送位置显示实心方块停止图标；任务结束后恢复发送箭头。

切换会话后，迟到的已保存草稿不会覆盖你刚输入或清空的内容。确认受理的提示词会从原会话草稿中清除，切回或完全重启客户端后不会再次填入；提交失败、拒绝或结果未知时保留原文。结果未知的原提交后来被确认受理时，也会清除当时提交的草稿，不覆盖后续编辑。

同一段提示词在发送中的用户消息、保存后的用户消息及Agent回复中保持相同的Markdown解析与排版规则。发送时立即显示已排版正文，受理和历史接管不重新构建气泡或切换透明度；图表使用稳定阅读区域，绘制完成、缓存返回及重开不改变区域尺寸。消息按各自可用宽度换行；输入框始终显示原始文本。真实发送失败或结果未知时保留原文与恢复提示。

用户消息的正文气泡默认最多约360px高，矮窗口按约半个视口缩小。超出后默认收起，底部以泡内渐隐和内阴影承托“展开”按钮；展开后显示全文，底部可再次收起。短消息不显示此按钮；附件、发送失败和结果未知提示始终位于裁切区域之外，全文复制仍复制完整Markdown。手动展开状态在受理、历史接管和缓存返回时保留，冷重开默认收起。键盘进入被隐藏的链接或代码操作时会展开并定位。

同一次输入经过内部关联判定后，正文仍只显示一条用户消息，并保持在这次输入所产生的回复之前；首次发送的临时消息在原输入被核实保存后由历史消息接替，刷新或重开不会重复显示或把回复移到用户消息上方。用户明确提交两次相同文字仍保留两条，各自在对应回复之前，队列取出编辑后重新提交也保留其新的输入身份。尚未形成业务消息的输入及真实澄清继续可读。

首条消息已受理后，客户端会继续核实任务是否实际启动。启动准备失败时在原会话显示简洁的“回复失败”说明；即使尚未形成消息历史，重新打开也保留失败提示，不显示为空白欢迎页。原文尚在当前窗口且没有后续编辑时可恢复到输入框；重新发送由用户明确操作，切换、刷新和重新打开均不会自动重发。

模型请求或传输失败时，除明确认证／权限拒绝（HTTP 401／403）外默认重连，未识别原因的网络异常和其他HTTP错误同样适用。后端重连时，重连与工具记录一起显示在原轮次的“处理过程”中；进行中的过程固定展开，轮次结束后可随过程展开、收起。同一串故障最多重连5次，原行显示当前次数和上限；首次模型请求不计入重连次数。收到输出后显示“已重新连接模型服务”，不额外添加恢复正文；停止时按实际连接与取消结果收尾。5次重连均失败后，该行显示“重连失败”，可以展开阅读具体原因及处理建议，例如连接超时、地址无法解析、服务拒绝连接、请求频率受限或回复传输中断，不展示内部错误码、地址、日志和调用栈。失败详情仍属于原 Turn 的处理过程，不另生成失败正文卡片。其他非重连的会话异常，包括任务启动、上下文读取和底层逻辑异常，统一使用Alert说明已核实的原因及处理建议；无法确认原因时明确说明现有记录不足，不猜具体故障。已有消息和执行结果继续保留，切换、重开不自动重发。

重连过程行的图标、标题、次数和展开后的错误说明统一使用红色；进行中、成功、失败和停止后均保持该颜色，悬停或展开不会改变文字颜色。标题与“第 2/5 次重连”这样的次数文字直接相连、不加间距，字号一致。进行中的活动动画继续保留。

异常提示通过Alert保留在所属轮次的“处理过程”中，只显示圆形信息图标和详细说明，不显示标题；容器使用中性文字、细边框和圆角，不作为用户、Agent正文或伪造工具消息。已知错误显示具体说明；未知原因显示记录不足的说明及检查建议，重新发送前应先核对本轮工具执行结果。没有最终回复的失败或异常中断轮次默认展开，外层高度不受限，仍可手动收起；轮次结束后只显示“用时”和已确认的耗时，不附“本轮失败”“已停止”“已中断”等状态文字，摘要不使用状态颜色；无法核实耗时时显示“用时未知”，不在过程外重复显示失败正文。尚未创建轮次的发送拒绝仍保留原输入的未启动提示。

执行记录已确认必要完成条件尚未满足时，明确提示完成条件未满足，保留已保存的回复和工具执行结果。它不表示模型连接失败，也不表示已成功的文件写入或其他工具需要重做；先核对尚未完成的要求与实际结果，再决定如何继续。切换和重新打开会话后仍按同一原记录显示。

运行中通过排队条目旁“引导发送”发送的补充消息，保留在对应 Turn 的同一段处理过程中，按原顺序与该轮说明和工具结果一起阅读。收起“处理过程”或完成后的“用时”面板时，引导正文一起收起；展开后显示完整正文和原 Markdown。首条任务输入与最终回复仍在过程外，多次引导不把原 Turn 拆成多段。引导待接收时保留在队列中，应用后由持久原消息进入过程；原后继申请的有意撤下不显示启动失败，完成、切回和冷重开不重复正文或耗时；提交失败与结果未知继续保留原文和原恢复提示。

子 Agent 向父 Agent 发送的普通消息采用同类输入气泡，正文上方显示“〔名称〕Agent 发送”，可据此区分用户输入和不同子 Agent 的来信。气泡内距与用户／引导消息一致，过程内不保留信息栏的额外空白。消息仍保留在实际接收轮次的处理过程中，收起、展开及重开会话时沿原位置阅读，不额外拆分轮次或重复正文。已核实成功的发送工具回执不另显示“发送成功”或排队 JSON；失败、取消、拒绝和结果未知保留实际提示，Agent 自己的回复仍正常显示。

点击 `+`，在输入框上方打开与输入框等宽的“添加”列表，只有一个带图标的“添加文件”入口，保持 12px 字号；同一次选择可混选图片、PDF 及其他文件，系统自动区分处理。附件统一显示在横向列表，可单独移除；移除按钮常显，采用深色圆底、白色叉号和浅色描边，在不同缩略图上保持清晰。数量较多时横向滚动，不把文件名、路径或图片编码插入输入正文。

发送后的图片和普通文件在文字气泡上方的独立附件区并排显示，整体靠右，与正文间隔8px；图片显示缩略图和文件名，普通文件显示图标和文件名。卡片宽148px、预览区高80px、圆角12px，卡片间隔8px。放不下时保持单行与卡片尺寸，在附件区内横向滚动；出现附件总数、左右翻动按钮和滚动条，边缘渐隐提示还有内容。可用触控板、触屏、滚动条或按钮查看，键盘聚焦按钮后可翻动；到达两端时对应按钮禁用。文字气泡不随附件横向移动。仅有附件时不显示空文字气泡；整条消息仍共用一套时间与复制，复制只取正文。发送占位保留文件名和固定大小的图片占位，保存后接替为历史附件；图片预览失败仍在原卡片内重试。

新添加的普通文件先复制完整字节，准备期间显示“正在保存附件…”并可“取消添加”；取消保留输入草稿，迟到结果不再加入附件，之后可重新选择。源文件在复制中变化或保存失败会提示重试，不显示为已准备成功。准备完成后再随发送绑定独立原件；原路径随后被删除、移动或修改，不改变已发送附件。最多 128 个普通附件，单文件和窗口准备总字节上限均为 256 MiB。未发送草稿不承诺跨窗口重载恢复。旧历史中只有名称和 URI 的附件仍是路径引用，需要用户重新添加才能取得独立原件。

Agent 通过现有文件工具按需读取附件。文本支持严格 UTF-8／BOM 和行范围；PDF 默认读取物理第 1 页的文字，可指定页码范围或页面图片，每次最多 20 页文字或 4 张页图。文件类型与读取选项不匹配时明确失败并给出纠正方法。没有提取到文字不表示页面空白；没有本地 OCR，复杂排版的阅读顺序可能需要结合页图核对。已识别的字体损坏或解析错误会明确失败，不将替代字体生成的降级内容当作准确读取结果。PDF 页图进入模型需要模型本身支持视觉，远端限制仍可能使请求失败。

会话独立输出和当前 Plan 保存为可编辑文件，后续对话可继续读取和修改；历史交付保留原快照。会话输出支持“优化方案.md”等中文文件名及内部空格，保留单个文件名、长度和保留字符限制，不静默改名。打开文件入口只开放当前会话已登记的准确文件。Plan 修改形成新版本，旧批准不能授权新内容，方案保存和批准是两个步骤；普通输出文档保存不自动批准计划实施。备份包含最新工作文件，包括未再次交付的修改；解析缓存可以重建，不代替原件或交付记录。

若提示“文件选择功能尚未加载”或“图片附件功能尚未加载”，请从应用菜单完全退出后重新启动。开发热更新可能已经更新输入界面，但刷新页面或关闭窗口不会加载新的主进程附件接口。

通过“添加文件”选择、直接粘贴或拖入的 PNG、JPEG、WebP、GIF 自动作为图片发送并显示缩略图。每条消息最多 10 张，每张最多 16 MiB；窗口内所有会话的待发送图片合计最多 128 张、64 MiB。数量按已有附件与本次新增累加，超限在读取和编码前提示，移除后释放对应名额；本次超限选择不开始编码。图片按顺序异步准备，移除会取消准备。图片准备完成后可单独发送，也可附带文字，实际图片以 Base64 内联进入模型请求，不依赖公网图片存储。Base64 大约增加三分之一体积，本地上限不代表 Provider 一定接受，实际模型的大小、格式和图片能力限制仍可能使请求失败。待发送附件只保留在当前窗口，重载或退出前请先发送；成功受理的附件随历史保存，后续轮次和 Fork 可继续使用。历史图片接近可见区域后自动显示缩略图，无须点击查看；流式回复和普通刷新保留当前可见的图片，远离可见区域或隐藏窗口时释放预览；切换会话取消未完成的读取，预算内已核验的缩略图随正文保留，缓存淘汰时释放。读取失败时可在卡片内重试。

输入区和消息中的图片使用独立的小尺寸预览，保持比例、长边最多512像素，GIF显示静态首帧；保存和发送给模型的仍是原图。首次预览在后台按序生成，同图在当前窗口的缓存预算内复用，刷新、切换和重新选择时避免重复转换。预算不足时回收较早使用的缩略图，连接／存储范围变化或退出窗口清空；预览固定占位，准备时不挤动正文。输入框显示“预览不可用”时仍可发送已准备好的原图；历史预览失败可在卡片内重试。

中性操作控件采用随深浅主题变化的半透明高亮，叠加在当前实色或系统材质背景上；左侧栏按钮的悬停与按下使用相同底色，覆盖空间与会话列表、导航项、用户按钮和设置左侧分类；悬停效果立即变化，不添加过渡动画；当前会话与页面导航项保留和悬停相同的底色，鼠标移开后仍显示，不额外改变文字颜色或字重；进入新对话时，已选项目则高亮对应空间整行，不再高亮“新对话”；未选项目时高亮“新对话”。点击“新对话”时直接显示目标项目，不先闪回“选择项目”或“新对话”高亮；同一项目重进期间保留已知分支展示，重新读取完成前不能发送，读取失败后须重试核实成功才恢复发送。切换项目时高亮同步转移，折叠空间仍保留选中底色；进入定时任务时高亮“定时任务”，这些页面不同时高亮旧会话。当前设置分类持续保留与悬停相同的底色，鼠标移开后仍显示；切换分类后只高亮新项，键盘操作保留可见焦点，按下不额外加深。其他中性按钮保留分级的按下反馈。主要操作与危险操作保留各自的配色，键盘焦点提示独立保留。

切换会话时，旧会话立即退出选中状态；读取目标会话期间不会重新选中其他会话，确认后才标记目标。普通刷新保留当前会话的选中状态；选中语义不增加视觉高亮。最近查看的最多 8 个非当前会话会保留正文 DOM；配套输入区状态仍有效时，切回直接一起显示目标的原内容、滚动、展开、草稿、模型与审核方式，同时后台校准。校准完成前输入区只读，不恢复旧操作资格；恢复不重播展开动画，手动开合照常。缓存按内容体积和节点数提前回收，超限长会话仍完整显示，离开后可能重新构建；重载窗口会清空 DOM 缓存。命中缓存时，已核验图片、复制反馈和组件高亮保持原有显示，不因临时禁用而闪现或变淡；复制反馈仍按原到期时间恢复。显示缓存不授予新的读取或操作资格。审核方式、模型和发送／停止控件在普通校准期间保留当前会话的已知标签、图标、透明度和悬停显示，相关操作仍按当前读取结果开放。真实权限或观察失败继续显示不可用状态；尚未读到审核方式时显示静态“审核方式”标签。无完整缓存时先准备目标模型名、思考档位、草稿与正文布局，再同时显示消息和输入区，避免分次出现而抖动。模型读取失败仍进入目标历史并显示实际错误，不借其他会话或全局默认模型代替目标选择。

首次打开或切换到未缓存的已有会话时，目标确认、输入区状态、历史及首次轮次／工具分组准备完成后，一起显示消息和输入区，并在显示前确定输入区占位，避免先后出现、再收起处理过程或合并工具而挤动阅读位置；等待期间不显示欢迎页或空会话提示，只有确认没有历史消息后才显示空状态。图片、完整大正文和用量信息继续按原方式读取，不延迟这次整页显示。已显示内容、缓存返回和新发送的消息继续即时更新；读取失败仍保留可读原文并按原方式恢复。

临时断线或目录读取失败后，客户端在原会话后台重新核对目录及审批事实，恢复后自动开放当前审批卡；保留正文、草稿和阅读位置。已提交审批的结果未知时只查询原答复，不重新发送答案或执行工具。

鼠标操作按钮、输入框、菜单、滑块或调宽分隔条后，不遗留焦点外框；菜单和弹窗关闭后回到原控件也遵循这一规则。键盘导航保留可见焦点提示。空间标题旁的添加按钮与空间行内编辑按钮保持相同的交互反馈：悬停时图标变色，按钮背景保持透明。

开发模式使用 `npm run desktop:dev`：页面、组件和样式保存后自动更新；Service 源码变更会自动构建并重启本应用的配套服务，在同一窗口重载页面。Service 重启会停止本应用当前开发任务并等待收尾，不自动重发任务；历史、配置与显式保存的草稿保留，未保存的页面状态可能重置。编译失败时旧服务继续运行，修正后再次保存会重试。Main／preload 和 Worker 资产变更仍需完全退出并重新启动。准备步骤与失败处理见[本地开发](../../../development/local-development.md)，正式发行入口按原固定候选运行。

开发启动遇到不兼容的旧 development 数据时，会在终端说明备份位置并询问是否备份后新建；只有明确输入 `y`／`yes` 才将原目录完整保留为同一数据根下的 `development-backup-*`，然后用新的 development 数据继续启动。回车、拒绝、取消或非交互终端均不处理原数据。旧历史和附件仍在备份中，新环境保留全局模型配置；兼容数据直接启动，无须确认。若其他客户端还在使用该数据或备份失败，启动会停止；先关闭使用同一 development 数据的客户端再重试。此行为仅用于开发入口，不迁移旧记录或改变正式客户端的数据兼容规则。

Windows 开发启动会自动检查当前安装的 Electron 运行资源，缺少沙箱所需的读取／执行权限时就地补齐；重新安装依赖后也会重新检查。修复只作用于 Electron 的物理运行目录，保留沙箱和项目、用户数据权限；遇到链接或明确拒绝权限时停止启动并提示原因。

通用 PC 客户端现在复用原桌面的项目侧栏、对话区、输入框、可调整宽度的右侧栏，以及主题、字体与样式。左下角“个人工作区”的用户菜单打开设置，以原有全屏双栏布局配置模型、提供商、MCP 与 Skills；“返回应用”回到当前会话。Windows 设置左栏位于菜单栏下方，仅保留紧凑上边距，不再重复预留标题栏空白。

普通新对话的首条消息按[自动命名](../../features/sessions.md#自动命名)生成可读 AI 标题。发送前和名称尚未保存时显示“新对话”占位；生成后侧栏和当前会话标题随原目录／视图刷新更新。

会话输入区的审批方式菜单只提供工作区内修改、自动审核和完全访问，不再显示“当前会话授权”入口。

普通界面切换审批方式时，提交过程由原审批控件提示忙碌状态，发送按钮保留原图标，只有实际发送消息时才转圈。会话正文与阅读位置保持，不临时插入“选择已保存”或“正在提交”提示。失败和结果未知由后台核对原权限选择，会话外不追加状态说明或查询按钮；不能重复提交。

任务运行时可通过输入区修改所属根会话的审批方式，主 Agent 与已经运行的子孙 Agent 后续进入审批层的工具读取最新已应用方式；已经待批但尚未派发的工具也按最新方式重新判断，已派发的工具继续原执行。普通工具待批时保留提示词输入框与权限选择器，切到 Auto 或 Full 后原待批工具重新判断，无须逐项手动批准。其他客户端的模式修改也会自动同步；查看子会话时同步继承的根模式。子会话不单独保存模式，切换会话后的迟到读取不会覆盖新会话。根会话自己的问答、计划答复和 MCP 来源／凭据授权仍沿各自交互隐藏输入区。

普通工具审批以独立浮卡显示在整个输入组件上方，高度不超过默认输入框。多项审批在右上角通过“‹ 1/3 ›”逐项切换；主 Agent 不显示名称，子 Agent 名称紧跟“需要批准”，前置固定图标池分配的彩色图标。同一子 Agent 在翻页、重新打开和后续轮次中保持图标与颜色；名称无法核实时显示“子 Agent”。工具类型与具体指令分层，长指令单行省略，悬停或键盘聚焦查看全文，不另设详情入口。默认“批准一次”，原审批提供相同命令授权时，右侧菜单可选“本次会话批准”，范围仍仅为本次及本会话相同命令，不批准其他工具或其他会话。完整附件核对完成前不能批准。

运行中的排队消息属于提示词输入组件，显示在同一外框的输入框上方，可收起或展开。每条以 Markdown 单行展示，超出省略，悬停或键盘聚焦查看完整 Markdown；没有数字序号或额外状态串。使用左侧手柄拖拽调序，也可在手柄上按 Alt+↑／↓；右侧可明确“引导发送”、编辑或删除。Enter／主发送按钮只把消息排队，不自动引导。引导绑定原活动轮次；原轮次已结束、队列项已消费、执行权未确认或回执未知时不改投其他轮次。包含新计划／Skill 选择的输入保留为后继任务，不能转成改变当前轮次配置的引导。附件随引导保留。引导等待原整批前台工具（含待批、排队与资源等待）收尾，再由模型先回应并继续必要工作；后台 Shell／子 Agent 可继续独立运行。编辑先从真实队列移除原消息，核实成功后将完整原文放入普通输入框，由用户自行修改并手动重新提交；没有编辑模式、取消编辑或自动放回。原消息带附件等不能无损转入普通输入框时禁用编辑，删除和调序仍可用。

删除或编辑只撤回尚未消费的原输入，不停止正在执行的任务。竞争中消息已被接收时刷新队列，不把旧文字回填为可撤回成功。操作结果未知时保留原操作，由后台查询原 ID；编辑确认已移除后把原文交付输入框，不覆盖后来输入，会话外不追加核对提示或临时按钮。关闭页面或重开不会自动重发、恢复排队或覆盖新草稿。实现与验证归[Desktop owner](../../../../apps/desktop/README.md#原审批面板与授权观察)。

同一会话正常校准权限和后台信息时，空间列表保留上次核实的运行标记，环境信息保留已有文字、按钮位置和阅读布局。空间行内操作仍按悬停或行内聚焦显示，不因临时禁用而出现；触屏保持常显。校准期间相关操作仍禁用；初次读取仅保留忙碌状态，会话读取失败和结果未知由后台自动重新核对，保留已读内容，不追加会话外状态文字。

首次打开包含运行中处理过程的会话时，正文直接按已有展开高度显示；恢复历史也不重播展开动画，后续手动开合照常。流式回复时，消息列表在原来位于底部时继续跟随新内容，“正在回复…”状态文字完整显示；用户主动上翻后保持阅读位置，可用“回到最新消息”恢复跟随。自动滚动产生的延迟通知不会被当作用户上翻，图片加载及普通历史校准保持附件位置的高度。

“正在回复…”的字号、字体和文字颜色与工具消息一致，默认14px，并随当前主题使用相同的辅助文字颜色。状态行与上方内容沿用会话的正文／工具间距，不与过程区底部留白叠加；尚无正文或收起处理过程时也保留相同节奏的留白。

子 Agent 工具消息以紧凑单行保留原操作：稳定彩色图标、子会话名称与“创建子 Agent”“继续子 Agent”等工具标题。成功受理后的原操作是静态历史，不随子任务完成、失败、中断或后续工作改成“已完成工作”“已停止工作”等状态，也不因子任务仍在运行而播放运行动画。工具调用本身真实失败、取消或结果未知时仍显示该次调用的结果。点击整行直接打开准确子任务的右侧详情标签，不提供折叠箭头或独立“查看详情”按钮，也不在父会话中展开受理回执；旧的展开记录不会显示原始 JSON。准确详情目标暂不可用时仅暂停点击。普通目录刷新保留已有名称、原操作和详情目标；子任务当前状态仍在现有环境信息及详情中查看。详情自动更新，不显示“刷新子日志”按钮和“子 Agent 会话仅供查看”提示；子会话仍仅供阅读。

活动轮次的展开入口使用固定的“处理过程”标签；思考阶段集中在底部回复状态行显示“正在思考…”，其余活动阶段显示“正在回复…”，状态文字后不附运行时长。思考／回复文字带流光效果；系统启用减少动态效果时使用静态文字。尚无可展开内容时只显示底部状态行。真实等待、停止与恢复结果，以及终态与最终耗时继续保留；连接或执行权观察失败不追加“上次确认状态”“执行状态待核实”等通用异常文案。

底部回复状态行属于整轮 Turn：从轮次受理到真实终态期间，始终在该轮底部显示一次，包括尚无助手正文、思考、阶段说明、工具调用、等待审批或子任务，以及停止请求尚未结束轮次的阶段。单段文本或工具完成不移除状态行，思考／回复切换和收起处理过程仍保持同一位置。轮次真实完成、失败、取消或中断后移除；普通读取暂时失败时保留上次已确认轮次的展示并后台重读，不追加会话外状态未核实说明，也不从旧显示恢复操作资格。原执行者已释放或执行权无法核实时，回复状态行停止，具体恢复展示见下文。

会话中的连续工具紧凑等距排列，文本与工具之间保留适中留白；连续文本片段与正文段落保持一致的节奏。处理过程衔接最终回复时按相邻内容统一留白，不叠加两层间距；底部不显示分隔线，展开的工具列表沿用同一节奏。正文标题前后留白按正文尺寸保持层级，列表中的代码前后间距一致，不因源文是否留空行而忽松忽紧；复制操作与下一轮消息保留明确分隔。

打开会话、子 Agent、定时任务或设置，以及读取日志、文件差异和图片预览时，不显示“正在读取”“加载中”等临时文案。附件准备保留忙碌图标与取消入口，不显示“正在保存附件”等过程文字。环境信息无已知名称时显示“Shell”或“子 Agent”，不显示内部执行标识；定时任务的运行记录使用中文状态，区分失败与结果未知。已有内容和控件标签保持，等待期间相关操作仍暂停；读取完成后才显示相应空状态。真实执行失败和未知结果保留在所属消息中；会话观察异常和原提交回执核对在后台处理，消息区外不追加异常文字或临时操作。

环境信息卡、消息、审批区域与右侧子详情标签使用同一个子 Agent 的图标和颜色。同一个子 Agent 在重命名、任务状态变化、刷新及打开不同任务标签后保持相同外观；图标不改变原详情导航或停止权限。

## 配置编辑交互

新增 MCP 时先填写名称和类型。STDIO 支持启动命令、按顺序增删的参数、环境变量键值、从系统额外传递的变量名称和可选工作目录；命令与参数分开填写，例如 `npx` 配合 `-y`、`@modelcontextprotocol/server-memory` 两个参数。流式 HTTP 支持 URL、Bearer 令牌环境变量、普通标头与来自环境变量的标头。令牌和敏感值通过变量名引用，连接时读取；变量缺失时给出可重试提示。两种类型分别保留未提交草稿，保存期间所有字段锁定，仍可取消原新增操作。

Windows 下新增时可填写已安装的命令名称或可执行文件完整路径，保存时解析为准确的启动程序。`npx`／`npm` 使用已安装 Node 与对应 CLI 脚本，不把 npm 包名当作可执行文件，也不直接执行任意 `.cmd`／`.bat`。工作目录支持完整路径和 `~/`；保存不启动服务或下载包，明确连接后才启动。首次启动可能需要安装依赖，STDIO 初始化最多等待60秒，期间可以取消。

模型、提供商、MCP 和 Skills 设置只展示名称、配置、相关状态与必要操作，不显示内部提交记录、Store／Session／提交标识、原始状态枚举、调试 JSON 或实现机制底注。保存期间由原控件表达忙碌，不额外插入保存过程文字；保存或删除成功后直接更新列表和编辑面板，不保留成功提示。保存结果未确认时，保留简短提示和“查看结果”；MCP 已受理的进行中操作自动核对，不展示独立操作记录卡或“查看结果”按钮；登录、连接及新增的取消沿原操作控件提供，其他进行中操作的取消在服务“更多”中。已确认失败的提示可关闭。查看结果只核对这次操作，不重新保存或执行。

Kite 的通用交互约定是：配置的新增和编辑从应用最右侧面板打开，沿用定时任务编辑的交互；主区保留列表或当前上下文，不把表单塞入主内容分栏或另开模态弹窗。

提供商与模型使用单列列表展示连接，以分隔线区分各行。每行保留提供商名称、连接信息、状态、模型数量和管理入口；编辑、删除操作位于所属连接行，窄窗口内自动换行。

MCP 与 Skills 目录共用单列列表行规范：名称和说明左对齐，状态与尾部操作按固定区域排列，窄窗口自动换行；列表行保持透明，选中只用左侧短线标记，不铺整行底色；键盘焦点独立显示细描边，每行只保留一条分隔线。MCP 的启用开关与详情入口独立，切换开关不打开详情。工具展开行只在条目底部使用分隔线，不重复为工具标题加线。

MCP 失败提示放在侧栏主要内容下方、底部操作区之前，不将服务名称和连接操作向下推移。关闭服务侧栏后不把错误转移到列表；重新打开同一服务可继续查看或关闭提示。提示根据实际 HTTP 状态码说明已知原因和下一步：接口不存在、权限不足、请求过于频繁与服务端错误分别给出对应说明，不根据域名猜测失败原因；未收到 HTTP 响应时按已知网络错误提示，原因未知时保留通用连接说明。同一服务的确认失败合并展示，关闭后不再逐条露出旧失败；确认成功后不保留过期提示。结果未知仍按原操作分别核对，不与普通失败合并。普通连接失败只提供重试，不显示“断开连接”；已连接／连接中可以断开，停止待确认、配置失效或仍有旧资源时使用“清理连接”。

表单内容和底部操作区沿用右栏本身的背景，不额外铺设背景色。输入框、下拉框和多行文本框统一使用控件填充背景、边框和常规小圆角，不使用胶囊圆角。

定时任务、提供商、MCP、Skills 的右栏表单宽度统一固定为420px，不提供拖拽或键盘调宽。空间不足时统一使用覆盖布局，并限制在内容外框的可用宽度内。重复点击同一个新增入口保留当前表单、已输入草稿和阅读位置；关闭后再次新增才打开空白表单。

所有右侧栏统一与主内容区顶部、底部对齐，覆盖会话工具、文件变更、定时任务编辑以及提供商、MCP、Skills 设置面板。并排展示时，两者直接相连，接缝没有外边距或圆角，只保留分隔／调宽线。右侧栏开合时主区同步调整宽度，避免动画期间左侧导航短暂伸缩；拖拽调宽继续直接跟随操作。窄窗口的设置继续使用右侧覆盖面板，并保持相同的上下边界。

会话阅读区与右侧工具、设置主区与配置右栏分别共用一个内容外框，右栏从外框内部的右侧展开，收起时也在框内消失。外框到应用右边缘的留白始终固定，主区随右栏开合同步平滑调整宽度；开合途中外框边缘持续可见，内容不进入外侧留白，主区不出现额外滚动条。定时任务、提供商、MCP、Skills 的右栏统一保留顶部标题和底部操作区，中间内容独立滚动；长表单和窄窗口不把保存、取消等操作挤出可视区域。

左栏与各类右栏的显示、隐藏统一采用180毫秒缓出动画，环境信息、窄窗导航和设置编辑面板也保持同一节奏；两种方向均平滑过渡，不直接跳到显示或隐藏的终态。首次进入页面时，正文与输入框直接使用环境信息的最终占位，不从宽列动画缩窄；随后环境内容到达不会改变阅读列，手动开合及窗口调宽仍沿原动画。拖拽调宽继续紧跟指针，系统启用减少动态效果时遵循系统设置。

新对话的环境信息仅在正文与输入区右侧留白足以完整容纳卡片时自动展开，不为自动展开挤窄或移动输入区；空间不足时默认收起，仍可通过标题栏按钮手动打开浮层。

环境信息从会话区域右侧滑入，隐藏时向右滑出；滑动期间保持原尺寸，超出会话右边界的部分隐藏。连续开合从当前位置反向过渡。

会话右侧栏收起时不保留可拖出的空栏。把已打开的右栏拖拽或用键盘调宽至收起时，同步关闭当前面板并释放它的详情读取，主区回收空间，随后可以正常重新打开。

窗口缩窄使已打开的右栏暂时收起时，保留展开选择，拉宽后恢复显示；环境信息因空间不足自动收起后，也会在宽度足够时重新停靠。手动关闭的右栏和环境信息保持关闭，窗口缩放不会重新打开。

原生客户端窗口最小宽度为800px，缩放窗口时不能继续向下缩小。主内容header及底部“个人工作区”的内边距不随窗口宽度切换。

左侧栏只通过顶部按钮展开或收起。缩小窗口不会自动折叠，也不会切换为导航浮层；拖动分隔线只调整宽度，选择会话、新建对话或按 Escape 均不收起左栏。窄窗口按可用空间调整侧栏宽度，拉宽后恢复保存的宽度；手动收起后，窗口缩放仍保持收起。左栏展开时只在左栏内显示收起按钮，收起时只在会话标题旁显示展开按钮，按钮与实际可点击区域保持一致。开合过程中使用同一个按钮连续移动，避免裁切、短暂重复和焦点丢失；标题与按钮占位同步过渡，减少动画时同步直接切换。

设置页左侧导航固定为200px，与主页面侧栏的最小宽度一致。常规、提供商与模型、MCP和Skills共用居中的880px最大内容宽度、48px上下留白和32px左右留白；600px及以下窗口的左右留白为20px。标题、说明与操作区保持相同间距，打开右侧面板后仍沿用这些规则。设置按钮、输入框、多行输入、下拉选择及模型开关统一使用公共组件，深浅主题与键盘焦点保持一致。双击表单项、选中文字或开合下拉菜单不会退出设置；可通过“返回应用”或Escape返回，打开菜单或编辑栏时Escape先关闭当前层。

左栏开合时，已打开的网页随实际分栏尺寸连续调整，不等动画结束才跳到新宽度；原网页及已有输入保留，阅读位置随页面自身的重排与滚动锚点保持。

当前提供商配置已采用该规则：点击提供商卡片打开最右侧编辑面板，连接、协议、凭据和模型表单在面板内独立滚动，底部保留取消与保存。关闭、取消或第一次 Escape 收起编辑面板并返回原卡片；再次 Escape 才返回应用。确认保存并成功刷新后回到列表，验证或保存错误保留当前表单；API key 在提交时仍立即清空，保存结果未知时仍需查询原提交。窄窗将面板贴到应用右边缘，主列表不变成表单。切换设置分类或返回应用会清理未提交字段，不发送模型任务。

MCP 与 Skills 采用同一列表、状态标签、标题与留白。MCP 的“新增 MCP”、连接管理、来源管理、准确操作复核和工具详情在应用最右侧面板中处理；已有来源没有直接更新地址的后台接口，界面不提供虚假的编辑保存。Skills 列出内置和个人技能，详情依次展示名称、简介、可滚动的Markdown正文及来源；来源明确区分内置技能与个人配置位置。全局目录不判断具体任务的执行可用性，不显示“可用／不可用”及“所需功能”；禁用及配置、读取异常仍明确提示。缺少运行功能时仍可阅读说明，实际执行按所属任务检查；关闭详情回到原条目。Skills 不提供手动新增、编辑、安装或启停写入。关闭或第一次 Escape 收起当前详情／操作面板并返回入口，切换设置分类清理未提交字段；查看和关闭不授予执行权限，也不取消业务执行。模型与常规设置仍有直接编辑控件，尚未完成同轮迁移。实现和验证分别见 [Native 提供商](../../../../apps/desktop/README.md#native-provider-与下一次模型选择)、[MCP](../../../../apps/desktop/README.md#native-mcp-完整设置)及 [Skills](../../../../apps/desktop/README.md#native-skills-只读目录)。

进入设置的“提供商与模型”即自动读取 `~/.kite-code/kite-code.jsonc`，在同一页管理连接及其模型启用状态；空闲时关闭重开会重新读取，保存未完成时重开会接回原队列。连接以响应式栅格卡片并排展示，窄窗口自动减为单列，卡片摘要显示模型总数与已启用数；点击“管理模型”在按钮旁打开浮层，直接显示模型列表及启停开关。浮层与“管理模型”触发区域同宽，不撑高卡片，按窗口边缘自动调整位置；点击外部关闭，Esc仅关闭当前浮层并将焦点返回入口。模型列表最多320px高，超出后在列表内滚动。模型按准确 ID 归到连接下，只显示一次；未归属连接的旧模型仍在“其他模型”中用相同浮层管理。模型行不显示“默认”标识。顶部不展示独立的默认模型卡片，提供商栅格直接接在页面标题之后。打开、关闭与滚动浮层均不保存配置，也不发送模型任务。模型统一使用用户配置，不提供项目范围选择。页面自动读取及保存后核对连接和模型配置，不提供刷新或重新读取按钮；临时读取或后台同步异常由页面自动退避重试，取得有效配置后恢复操作，不需要手动重读或关闭重开。远端发现仍按[提供商保存规则](../../features/models-and-configuration.md)显式触发。模型开关立即响应，正常保存和后台核对期间可以继续切换，同一模型尚未提交的修改合并为最后选择，不影响其他模型。实际保存按顺序进行，关闭设置后继续在后台保存已接受的修改；同一作用域重开接回原队列；期间切到常规查看默认模型也不打断后台保存。连接保存与模型队列互斥。已保存后的临时网络读取失败会继续核对同一保存结果，核对一致后接着保存已接受修改。明确失败或配置冲突时丢弃尚未提交的旧修改，后台重读恢复后接受新操作；结果未知时自动查询原提交，确认终态后再恢复，不重新发送保存。当前数据源中从上次启动保留的未决配置也只按原ID核对，不取得旧操作的重发资格。刷新不会让已打开的旧连接草稿获得新的保存资格，需重新打开编辑。所有模型都可启停，包括配置默认模型，也可全部关闭。启停不自动替换默认引用；禁用正在运行的模型不取消或改换该运行的模型，同一任务的后续模型请求仍用原配置，后续新运行不能使用已禁用模型。打开、读取和关闭设置均不发送任务，返回后保留原会话与草稿。实现和验证见[设置 owner](../../../../apps/desktop/README.md#native-提供商与模型设置)。

左侧玻璃栏、主内容和右栏共用一圈细的半透明外边框，最外层统一圆角和柔和阴影；Windows Mica下四周保留6px留白。主内容区不再单独增加圆角、周围间距或外沿描边，右栏与主区使用同一主题底色，内部仅保留细分隔线。开合或调宽侧栏时，最外层边界保持完整，玻璃背景仍保留透明度。

应用准备中、启动失败和重新尝试时，启动页占满内容区，顶部 header 和菜单在进入主界面后显示。原错误提示、保存诊断和重试入口仍可使用。

进入应用后，macOS 的原生红黄绿窗口按钮与侧栏、会话标题共用顶部52px的一行，侧栏顶部不再重复显示 kite 标题，也不另占一行空白顶栏。收起侧栏后，展开按钮和会话标题自动避开窗口按钮；设置页的“返回应用”和窄窗口侧栏也保留这一安全间距。Windows／Linux 继续采用独立一行的32px沉浸式窗口顶栏，右侧保留最小化、最大化／还原和关闭，业务页面从顶栏下方开始。按钮外观跟随应用主题，顶栏空白处可拖动窗口、双击缩放，业务控件仍可正常点击。关闭窗口仍沿原隐藏行为，不等同于退出应用。

Windows 顶栏左侧提供“文件、编辑、视图、帮助”四个菜单，文字与悬停背景跟随主题，下拉项使用原生菜单；打开设置后仍可使用顶栏菜单。“文件”可进入新对话、添加空间、打开设置、隐藏窗口或退出；进入新对话保留原草稿，添加空间沿原目录选择，退出按下文单次确认、立即关闭界面与后台收尾执行。“编辑”对当前编辑区执行撤销、重做、剪切、复制、粘贴、删除与全选；“视图”可调整缩放、恢复实际大小或切换全屏；“帮助”显示关于 kite。准备中或提交操作期间，文件菜单的前三项暂不可用。可用 F10 聚焦菜单，左右键切换、下键打开，或用 Alt+F／E／V／H 直接打开；Ctrl+N、Ctrl+O、Ctrl+, 分别进入新对话、添加空间与设置。

Windows 11 22H2及以上在左侧导航与最上方独立窗口顶栏使用原生 Mica 云母背景，跟随应用深浅主题；左侧导航在材质上叠加半透明的主题灰色，背景保持磨砂通透，窗口顶栏直接显示原生材质；右侧栏与主内容共用 Dark Modern 实色配色，控件与卡片保留各自的明度层级；“新对话”等会话标题栏、聊天正文、输入区和卡片保留实色背景。最外层以整体圆角、四周6px留白和淡边框衔接 Mica，左右侧栏与主内容之间使用轻淡的单条分隔线，窄窗口的编辑右栏也不重复叠线，调宽把手在悬浮或键盘聚焦时提示，拖拽和键盘调宽仍可用。设置页的分类导航和返回区域采用相同的灰色玻璃背景，设置主内容和编辑右栏共用同一实色主题。打开设置时主页面保留会话、草稿和阅读状态，但退出绘制与交互，玻璃区域不叠出下层聊天页面；返回或 Escape 恢复原页面。任何窗口宽度下，返回设置前的页面都保留左侧栏原有的展开或收起状态。Mica 的具体外观由 Windows 管理；系统关闭透明效果、启用高对比度或节电等情形下可能显示实色。Windows 10、较早的 Windows 11、Linux 及无法核实材质的窗口保留原实色背景，不需要用户额外配置。[实现与验证](../../../../apps/desktop/README.md#windows-原生-mica)说明当前范围。

普通会话的滚动条从标题栏下边缘一直延伸到主面板最底部，覆盖在右侧，不挤压标题栏宽度。内容滚动区域仍从标题栏顶边开始，保留标题栏的玻璃效果。正文从固定的磨砂标题栏后方经过，输入框悬浮在滚动区底部；标题和按钮保持清晰，底部分隔线与右侧标签栏对齐。首尾消息分别预留标题栏和输入区空间，输入区增高时留白同步更新，环境信息卡保持原位。实际可见的顶部提示、读取错误和其他页面保留正常布局；空提示容器不影响全高滚动。

项目默认展开，点击名称独立展开或收起；空项目显示“暂无聊天”。上下键移动当前项目列表焦点，确认后打开原历史。侧栏先显示五个会话，可点“展开更多”继续查看已读目录。新建等待仍可阅读其他会话，迟到结果不覆盖后来选择和草稿。未进入本次项目目录的原会话仍保留在“项目待读取的会话”，可重新读取目录更新归属。目录按真实更新时间从新到旧排序，“展开更多”每次再显示十条；悬浮会话可查看状态和本地时间。未打开的会话也显示实际运行或待用户输入，等待必需后台结果显示通用活动指示。断线或读取失败保留原目录和时间，标为“上次确认状态”及“目录状态待核实”，仍可阅读；刷新成功恢复当前状态。未记录的时间不补造，未声明目录状态能力的服务保持待读取。空间批量移除与离线历史清理的当前范围见下段；单会话清理已接同一显式离线维护，macOS 安装版常用维护已有有限验证，其余维护恢复和剩余旧页面行为仍在迁移中。

代码回滚只切换版本，保留现有数据。旧客户端不能识别私有存储格式时，草稿与原申请操作提示存储不可用；兼容的会话历史仍可阅读。切回支持该格式的版本后，继续查询原操作，不自动重做或恢复旧备份。macOS 当前已验证的代码组合见[Native owner](../../../../apps/desktop/docs/native-release.md#真实代码升级与冷回退)。

已登记 Native 的独立 Terminal 正常卸载后，Native 自带入口仍可使用，后续 Native 升级不要求重装 Terminal。升级不会重建已卸载的前门或自动重新登记；需要独立前门时，先安装 Terminal，再明确登记 Native。

Windows x64 的正式安装和 `kite-desktop.exe` 启动链已实现源码接线：在窗口与业务数据打开前核完整候选和可信创建链，运行中的窗口固定原版本，切换只影响后续启动。缺交接或身份不符仍拒绝启动；实际 Windows 窗口、版本切换和维护恢复尚未验收，不能据本机验证宣布可用资格。操作与限制见[Native owner](../../../../apps/desktop/docs/native-release.md#windows-managed-native-当前实现)。

在“会话工具”的 Context 中读取当前所选上下文后，可对已结束且被排除的 Job 使用“Include this exact historical result”。候选来自完整历史目录，原 Job 不会因后续轮次超过最近执行窗口而消失；目录显示总数和当前范围，可点击“读取下一页历史任务结果”继续读取同一次固定目录。明确备份恢复为新 Store 后仍可纳入准确原结果，结果保留原出处；这是一次新的上下文选择操作，原任务不重新执行。空闲时只保存来源，须再明确发送新轮次才进入模型；活动时必须绑定按钮标明的准确轮次，排队后等待该轮次检查点确认。回复丢失只查询原上下文命令，不重发；切换会话或当前选择变化后须重新读取。纳入不恢复旧任务的停止、继续或自动交付权限。当前已验范围与剩余平台资格见[Native owner](../../../../apps/desktop/README.md)。

同一会话的活动压缩卡可点击“查看此压缩的原模型输入”，再确认读取敏感内容，查看这次准确调用保存的完整输入与原元数据。明确备份恢复为新 Store 后，压缩卡保留原 Store、会话、Model 与 Run，入口仍可使用。读取完成核对全文后才展示，不用当前配置重建原请求；关闭检查器清除正文，切换会话取消所属读取，冷重开须再次确认。跨会话封存压缩卡不提供这个快捷入口。查看不调用模型或恢复旧任务权限，实际范围见[Native owner](../../../../apps/desktop/README.md)。

手动压缩或重置后，可在 Context 面板点击“查询原压缩命令与执行”，核实窗口已保存申请的原结果。后续轮次增多不会让原执行从查询入口消失；命令受理和执行完成分别显示。查询失败保留已确认结果并提示本次失败，不自动重做压缩或重置。该入口的窗口内记录与当前已验范围见[Native owner](../../../../apps/desktop/README.md)。

通用 Native 的左栏「定时任务」支持保存、编辑、暂停／启用、删除、立即运行和最近运行记录。任务填写名称、说明、已登记项目、已配置启用模型，以及每日／工作日／每周的运行时间；统一以本地服务宿主的系统时间为准，不提供时区选项。当前只支持本地项目，独立工作树禁用。保存失败保留输入；缺项目或模型不能保存。模型目录读取失败时保留错误并自动重试，任务列表刷新或其他操作成功不会清除该错误；读取恢复后可继续使用原表单。每次运行在对应项目下创建独立会话，运行记录可打开原会话查看结果或处理审批；沿用普通会话的权限，不自动同意工具调用。定时任务不自行授予项目读取信任；尚未准备项目访问时，文件读取仍会拒绝，可在原会话明确发送来准备访问。运行记录的“已完成”表示会话运行正常结束，具体业务是否达成仍须查看回复正文。

定时任务页可按全部、已启用和已暂停筛选，三项采用统一的页签样式并显示数量，外层容器与内部选中项都采用胶囊圆角，支持方向键与Home／End切换；搜索任务名称、说明或所属项目，并与当前状态筛选共同生效；没有匹配项时可清除筛选。任务卡片采用紧凑布局，名称与说明单行预览，悬停可读全文；编辑、立即运行与更多菜单放在标题行，项目、时间安排和下次运行合并展示在下方。暂停／启用和删除收在更多菜单，弹出层文字默认采用13px、18px行高和28px选项高度，删除仍须明确确认。已有运行记录时才显示展开入口，区分各次状态、起止时间和原因；主动停止只显示“已停止”，具体失败与未知结果保留原因。搜索框使用统一的输入框背景、边框和焦点提示，搜索图标位于框内。筛选位于工具栏左侧，搜索与新建按钮成组位于右侧并保持同高同行；窄区中筛选可换行，搜索与新建不拆行。页面不重复显示标题、正常状态、操作解释或常驻运行条件说明。顶栏不再提供返回按钮，使用左栏“新对话”或原会话切换；原草稿和在途首条提交仍保留，不重复发送。

已被后续列表刷新或任务操作取代的旧响应和旧读取错误，不再覆盖当前任务列表；模型目录错误仍独立保留并按上述规则恢复。

新建和编辑始终在应用最右侧栏打开，主区保留任务列表和当前筛选；主区宽度不足时，编辑栏覆盖在列表右侧，拉宽后恢复并排，未保存输入继续保留。表单采用分组卡片、左侧标签和右侧控件；名称不单独显示标签或预留标签空间，空白时在框内提示“名称”，输入与光标从整行输入区左端开始。名称仅保留输入框自身边框，聚焦时使用统一焦点提示；名称、说明、时间和其他设置卡片使用相同的控件填充背景、边框和小圆角。说明为独立输入区，重复与时间同组，重复通过菜单选择，每周展开具体星期。时间行直接编辑时分，例如“09:00”，无需展开浮层；支持键盘输入，清空时间会禁用保存，其他字段继续保留。高级设置默认展开，项目、模型和思考程度各占一行并保留标签，可收起再展开且保留输入，不附带安排摘要或环境说明。项目选择沿用新对话的项目菜单；模型行直接打开原提供商／模型双栏，选中后关闭；思考程度行单独打开原宝石滑块，支持键盘操作。切换模型时显示新模型的配置档位，调整思考程度不改变模型。保存会保留当前显示的思考程度，每次运行使用该次任务的保存值，编辑后来任务不改变旧运行快照；未调整时采用模型配置，缺省为中；保存时包含该具体值。不支持的档位不能保存，也不会静默替换。当前只在本地项目运行，不提供可选的独立工作树环境。底部取消与创建／保存固定可见，表单内容独立滚动；保存失败保留输入。关闭或 Escape 返回列表，沿用原侧栏开合和焦点恢复规则。

保存回执无法确认后，在原表单修改字段并再次保存，会先核实原任务；已经保存的任务继续更新，不重复创建。核实失败时保留输入，待用户重试；明确打开新建表单仍是新的创建。运行重新核实为正常或完成后，不再把旧网络读取错误显示为当前失败；失败与未知结果仍保留所属状态和详情。已有活动运行、未知结果或本次运行已经登记时，点击“立即运行”会明确提示本次未新建运行，可从已有运行记录继续查看。暂停只停止自动调度，仍可明确立即运行。修改目标项目只影响新运行，旧记录仍打开各自原项目下的会话。操作提示和运行历史各占独立行，长提示完整换行；长任务说明按可用宽度省略，避免撑出窗口而裁切操作。

定时任务只在桌面应用运行时触发。关闭窗口隐藏应用，继续调度；真正退出时停止新调度并沿原流程收尾。已有任务也按本地服务的系统时间运行；旧任务采用不同时区，或宿主系统时区改变时，按新本地时间计算下一次未来发生，不追补转换前的时间。时区未改变时，重新打开或机器睡眠恢复，错过的时间最多补最近一次；同一任务已有运行／待审批／未知结果时不叠加执行。夏令时不存在的时间跳过，重复时间仅触发第一次。暂停不取消正在执行的会话；运行未结束或未知时不能删除任务。最近记录显示全局最多128次、每任务最多20次；大记录按响应大小减少展示条数，原会话结果仍保留。回执未知只核实原申请，不自动重新发送；创建与启动之间发生中断时也可能保持未知。备份恢复为新 Store 后原任务保持旧身份，不自动执行；需明确编辑保存到当前 Store 后才可重新启用。旧 Store 的运行记录保留为只读历史，不阻止明确重新绑定后的新 Store 运行或删除任务；同一 Store 的未知结果仍阻止后继运行。保存中的编辑器关闭后再打开其他任务，旧保存结果不会收起新面板。

新对话的项目选择菜单只显示项目名称与当前选中标记，不显示项目 ID；菜单宽度随名称自适应，长名称在窗口范围内换行。

从全局“新对话”进入时，按左栏顺序默认选择第一个空间；没有当前会话的首次进入也使用这一默认值。从某个空间行内新建时选择该空间。手动切换后，普通刷新保留当前选择；重新从全局入口进入时按最新列表顺序选择首项。没有空间时仍可编辑草稿，添加空间后才能发送。

通用 Native 的全局与项目「新对话」现在沿用原准备页，尚无项目也可写需求；首页只保留欢迎标题和输入区，直接填写需求。进入页面或切换项目不会创建空会话。已有会话与准备页草稿分别保留，项目／分支选择保留模型、思考档位与权限选择。首次发送才创建原会话、应用所选权限并提交输入，立即清空准备框并显示首条消息，创建成功后自动进入该会话，真实消息到达后接管；正常过程不增加提交提示或手动打开步骤。失败保留已创建会话与原文；结果未知由后台查询原首次提交；若仅完成创建或权限准备，保留原文供用户明确继续，不重复创建或自动重发任务。普通发送使用会话已绑定的项目，不再额外要求确认项目读取范围。发送前由主进程准备当前项目与宿主声明的读取授权，保留所选审批模式和工具硬限制；打开历史本身不授予读取范围或重发任务。准备失败保留原文，结果未知由后台查询原权限申请，不继续发送；期间切换会话或范围变化使旧观察失效。独立空间、Git 与分支管理操作的失败显示通俗临时消息；设置内的失败保留原位说明。

通用 Native 准备时只读取已登记项目的真实 Git 分支；普通目录或缺 Git 不影响准备。未选另一分支时按发送时实际环境执行，只有明确选择另一分支才在首次创建前受控切换。任何空间仍有活动任务、项目有未提交改动或目标与客户端私有数据／制品目录交叠时，切换明确失败并保留草稿，不自动停止任务。新 Run 读取并冻结该项目配置，客户端无需重启 Service；现行手册中的旧配套服务重启描述只属于原 kite-desktop 路径。

通用 Native 的当前会话在原轮次区域显示进度和终态；普通 dev 与 prod 不显示“后台状态：…项未结束，…项未知”汇总、原始轮次状态列表或子日志的内部读取序号和轮次 ID，这些信息仅在显式测试诊断中显示。实际后台任务仍从「环境信息」查看，准确停止和完整输出沿原任务入口操作；主轮次完成不表示后台任务已经结束。真实执行失败和结果未知保留在所属消息中，会话外不追加恢复提示或临时核对操作；不能仅凭计数或轮次终态判断实际进程已经退出。

通用 Native 的当前会话已接入原「环境信息」卡，按 Shell 与子 Agent 分组，保留宽窗口停靠、窄窗口浮层和手动开关。可准确停止正在运行的任务；受理后仍等待真实状态，结果未知须从原申请核实。子 Agent 名称来自原子会话，点击详情在最右侧栏打开对应任务的标签页，查看完整子日志；同一任务重复打开会切回已有标签，同一协作者的不同任务分别保留。首次从子 Agent 消息打开时只创建对应详情标签，不附带空白网页；已有网页标签保留。已核实准确子任务的首次打开不等待后续整份后台目录刷新，加载期间保留已知名称。详情只读，主会话正文、草稿、输入区和父轮次提示继续显示，父轮等待子 Agent 时也可同时阅读。切换标签、关闭详情标签或收起侧栏会结束该详情读取，原任务继续执行。工具、轮次或文件信息尚未核实只影响相应条目，不遮住整段父正文；父元数据刷新也不阻塞同一会话的已保存历史读取，发送、停止与权限操作继续等待新资格。目录失效或读取失败保留上次名称与状态，停止入口等待重新核实；切换会话不停止任务。恢复历史保持只读，终态不表示进程清理已确认。

通用 Native 的「后台总览」通过“打开后台总览”读取当前连接下的完整后台目录，按原会话展示 Job、子 Agent／task 和子会话中的 Job，切换主阅读会话仍可查看原任务。父轮次是否等待必需结果、原子轮次状态和结果接纳分别显示；较新的子轮次不会替换原 task 身份。可读取完整已保存输出或完整子日志，全部固定上界内容读取成功后才发布。新链路备份恢复为新 Store 后，历史条目保留原 Store、原任务与原输出，并显示“恢复历史，只读”；旧任务不提供停止入口，新 Store 明确创建的任务仍可正常控制。刷新失败保留上次完整事实并停用停止入口；“关闭后台总览”只结束读取。停止只针对按钮标明的准确原执行，请求受理后仍等待实际终态。关闭、会话切换与冷重新打开均不重新发起任务。实际恢复读取、默认 Shell 和平台范围见[Native owner](../../../../apps/desktop/README.md#native-跨会话后台总览)。

当前根正式入口已使用通用 Agent V1.3 候选，旧参数、State/stdio 拓扑及旧桌面截图只作历史参考；新入口的实际参数与行为以本页“通用”段落和[当前进度](../../../plans/unified-agent-refactor-v1-progress.md)为准，未实现能力不能借旧描述启用。发行、安装与跨平台仍有未取得资格，详见[发布边界](../../../active/release-control.md)。

正式 Native 的 Runtime logs「已保存执行」中，展开准确 Job 后可主动读取完整已保存输出、刷新或关闭。页面保留 stdout/stderr/progress 的原文与已记录缺口，读完固定上界才展示完整内容；新输出需显式刷新。完整范围包括已保存内容和缺口，无法恢复丢失的字节；缺口字节数无法确定时明确说明。同一 Job 刷新失败保留上次完整内容并标未更新，空输出与读取失败分别显示。关闭输出、折叠详情、切换会话或冷重开只读历史，不取消或重新运行 Job。精确停止仍是独立明确操作，不能从读取完成判断执行成功或实际停止。macOS 正式默认宿主 Shell 已验证从页面新建后台 Job、完整保存输出、准确停止、所属 Main/Service 意外退出后的清理，以及同原身份的冷读零重放。Service 来不及保存停止结果时，历史记录仍保留未完成事实，读取完成不能把它判为已停止。当前 macOS 范围与剩余资格见[Native owner](../../../../apps/desktop/README.md#native-job-完整已保存输出)。

设置以全屏双栏页面呈现，沿用桌面主界面的当前主题与基础字号；宽窗口下设置侧栏固定为 236 px，不随主页面侧栏拖拽变化。左侧直接切换“常规”“提供商与模型”“MCP”“Skills”，分别以齿轮、链接、插头和书本图标区分；所有导航图标统一14px、图文间距10px，宽窄窗口均与“返回应用”的图标和文字列对齐，不提供设置搜索。“返回应用”位于同一设置导航列表的首项，紧邻“常规”等分类，左侧带14px返回箭头，沿主侧栏“新对话”的32px单行按钮尺寸和悬停、聚焦交互。顶部空白统一保留窗口操作空间，返回按钮随列表排列，不再单独放在窗口按钮旁或增加横向避让缩进。“常规”显示默认文件打开应用和当前模型；编辑器选择只在当前页面进程内保留。返回应用关闭设置页，不修改任务或会话。参考图中的权限、语言及窗口行为等开关尚无对应设置能力，页面不提供这些控件。

明确退出客户端时立即关闭可见界面，不等待活动工作检查、服务状态或确认对话框。任务正在运行、状态无法核实、服务启动或开发热重载尚未完成，都不阻止退出；正常清理最多等待4秒，仍未完成就终止本应用拥有的服务并结束主进程，整个退出不超过5秒；重复退出不会增加提示或重复清理。普通关闭窗口仍只隐藏客户端，不等同于退出。

明确退出后，界面立即隐藏，macOS同时隐藏应用与Dock图标，激活不会重新打开界面。正常清理在最多4秒内沿原owner取消轮次、工具与子Agent，保存终态并释放资源；成功后立即结束主进程。到期仍未完成或清理失败，则强制终止本应用拥有的服务并结束主进程，不再等待或追加提示，整个退出不超过5秒。原窗口和网页在正常清理期间保留到准确释放后销毁；强制退出不保证任务终态或外部副作用已确认，下次打开按原会话记录核实。

侧栏空间行只显示名称；会话行显示标题，并在最右侧用旋转图形表示 Run 仍在进行（包括受管等待必需子 Agent），用高亮圆角文字“待用户输入”表示等待回答、审批等交互，待输入优先于运行图形。空闲和正常完成不显示行内状态。会话悬浮提示只显示完整名称和最近更新时间，无可用时间时仅显示名称；空间悬浮提示显示名称和会话数量。浮层首次悬停 500 毫秒后出现；浮层出现后快速移到其他列表项会立即切换详情，移开一段时间再返回则重新等待。首次等待期间移开不会弹出。键盘聚焦也可查看，Escape 关闭。会话顶栏右上角的环境信息按钮控制“环境信息”卡片显隐，卡片默认展开，CSS 宽 300 px（2 倍显示比例的截图约为 600 像素），按 Shell／子智能体分组；卡片内文案使用常规字重。没有任务时，两组各占一行，在右侧分别显示“空闲”和“暂无”，不再重复显示数字0和整行空状态；有记录时显示数量与任务列表。环境状态自动更新，读取失败时保留已核实内容并在后台重读，不追加异常文案或临时重试按钮。子智能体展示名称、状态和只读详情入口；Shell 与子智能体仅在当前目录已核实新鲜、仍可停止的准确任务时提供停止操作。状态旧、未知或读取失败时停止不可用，重新核实后才能操作；停止绑定按钮所示原任务，不转向同一协作者后来一轮。卡片停靠展开时优先利用右侧已有留白；留白足够时，消息文本和输入区保持原位置与宽度。留白不足时才同步让出必要空间，消息阅读列和输入区最大宽度仍为 844 px，并随可用空间收窄；会话滚动条始终保持在中栏最右侧。会话实际可用宽度不足 1092 px 时，停靠卡自动收起；宽度恢复后自动重新停靠；手动关闭则保持关闭。宽度不足时用户仍可点击按钮，以不压缩会话区域的右上角浮层查看；浮层打开期间宽度恢复则自动转为停靠卡。手动隐藏与自动收起均以短暂淡出、向右缩合和会话区域同步扩展完成；从其他主会话或子详情返回时直接显示卡片，不重新播放入场动画；系统启用减少动态效果时立即切换。除用户主动打开的窄宽浮层外，卡片不覆盖消息、工具输出或输入区。Shell 分组只显示后台启动且仍在运行或正在停止的命令；前台执行的命令不会出现，无法核实启动来源的历史记录也不会作为后台 Shell 显示；同一连接内返回已读主会话、正在核对新状态时，卡片暂时保留上次已确认的 Shell 和子智能体行，相关操作等待新资格，不追加正常校准文案。首次读取或没有可复用展示快照时，子智能体组保留已验证的任务子会话，自动命名会话产生的内部任务不在此处显示；名单已到但后台状态尚未匹配时保留详情入口并标记“状态待确认”。新鲜后台状态明确报告不可用时才标记“不可用”。有公开名称时只显示名称与状态，不附加执行 ID；旧记录缺少名称时才回退显示执行 ID。后台 service 与诊断字段不在该卡片中展示；上次状态只用于阅读，实时订阅与操作权限仍须重新核对。任一分组没有项目时显示对应空状态。

重新选中会话或连接恢复时，桌面会向服务端核实整个主／子 Agent 执行组，并保存原执行者丢失后的中断、未执行或结果未知状态。未派发的子任务不再挂在排队中，未被接纳的审批结束等待；已有答案、结果和历史保留，重开不会自动重试。核实成功后按持久状态显示，移除运行转圈、回复／思考、工具等待动画与停止按钮。检查失败或证据不足时在后台继续核实，不在消息区外显示“执行状态待核实”；已中断轮次不会被旧目录缓存重新标为活动。仍持有执行权的共享服务继续原工作。接续与副作用边界见[恢复说明](../../features/recovery.md#重开会话时核实执行状态)。

required 后台子 Agent 尚未终态时，Runtime 保持同一 Run 的受管等待及准确 task 关联；Desktop 侧栏保留通用活动标记；所选父会话的历史已加载、投影身份匹配且 Run 确认因 required 子 Agent 等待时，在消息阅读列末尾显示“正在等待子 Agent 结果”。这是随 Run 状态出现和消失的临时提示，不写入会话消息，也不把先前一段模型正文标为最终回复；最终回复只在 Turn 完成后确认。侧栏不另设等待徽标，输入框上方不设状态行，也不延续模型思考动画。子 Agent 的实时状态由环境信息卡片展示。此时输入框保持可发送；同工作补充在原活动 Run 的安全边界接收，不取消 child；独立新工作先保存选择并排队，待原工作安全收束后交接；关联不明确时先澄清。切换会话或刷新重接后，内部等待原因及关联 task 由持久投影恢复，不靠客户端轮询补正。普通协作结果按[工作选择与结果接纳](../../features/execution.md#运行中引导与后台执行)处理：父空闲且同工作资格成立时可创建后续普通轮。旧 `human_start_preferred` 抑制记录只说明当时的接纳决定，不因后来刷新改写，也不代表结果已注入当前活动 Run。

桌面与 Web 共用会话主页面；可用操作按各端权限提供。桌面保留本地项目、任务输入、审批与执行控制，Web 当前只读。输入框底部左侧放置附件与权限选择器，权限入口保留图标和名称，点击打开菜单，不显示展开箭头；同一会话在Agent运行、消息更新和后台核对时，已打开的权限、模型和附件弹层保持，核对未完成时仍暂缓相关操作；切换会话、主动关闭或进入人机交互时按原输入区切换规则关闭；右侧同一行放置上下文圆环、模型选择器和发送／停止按钮，模型入口与圆环紧邻。模型弹层默认在入口上方居中打开，靠近窗口边界时自动避让。缓存命中率不再单独显示在工具栏，悬停或键盘聚焦上下文圆环可在提示中查看累计缓存命中率及命中／总量；没有样本时明确显示暂无缓存用量数据，不将其当作真实0%。普通后台校准和新一轮等待保留已核实的累计值，切换会话只恢复目标自己的指标。新对话尚无上下文用量数据时不显示圆环和提示浮层；收到实际用量后显示，真实0%仍保留。已有会话首次读取期间保留空圆环，读取结束后更新，不阻塞输入或停止任务。圆环为无点击操作的状态图标，独立表示当前上下文输入估算除以对应模型完整窗口容量的占用比例；提示分为“上下文占用”和“缓存命中率”两块：标题右侧分别显示百分比，下方显示估算／总量及累计命中／输入tokens；上下文配占用条，较大数字统一按1024简写为大写K／M，缓存数量同样按1024换算为大写K／M。未知状态明确标注，Escape可关闭。已保存的普通回复即使没有调用工具，也可基于原请求统计估算当前上下文；仅创建会话尚无模型请求时仍可能未知。暂时读取失败时后台退避重试，恢复后更新；历史网页及其他工具结果沿既有原请求和来源只读估算，不重新执行工具；相同事实在重启前后保持同一统计口径。容量或估算确实不可用时显示空环和未知，不补0%；已有会话在历史加载、会话切换及读取失败时仍保留圆环。会话消息正文和工具消息文字使用14px。会话输入框的占位提示为“输入新的想法”。估算按最近已保存的当前模型请求及当前选中历史计算，不计入未发送草稿，也不能代替实际账单或Provider容量证明；切换会话、上下文或已选模型不沿用旧比例。macOS 窗口采用沉浸式标题栏：同一个顶部 header 横跨侧栏和会话区，左段在原生玻璃导航上放置侧栏收起图标，右段只显示会话标题和操作，并在会话页 header 底部显示分隔线，不重复显示所属空间；会话标题最多显示 10 个字符，超出时以省略号收尾，悬停仍可查看完整标题。侧边栏使用上文的系统 Vibrancy，内容面板保留实色背景并延伸到窗口顶边，原生交通灯、窗口拖拽及双击 header 缩放保持可用。

新Native候选沿用原输入框的累计缓存命中率显示，缺少缓存用量的模型记录不算作0%样本；指标读取失败时可重新读取。当前接入和首次／重启后读取的验收范围见[Native owner](../../../../apps/desktop/README.md#原输入区累计缓存命中率)，不代表完整桌面迁移已完成。

桌面客户端产品名为 **Kite**，**kite-code** 为 TUI 名称；两栏界面、Electron 窗口与当前开发包均使用 Kite 展示名。通用日常工作、shadcn/ui 界面及覆盖空间、会话、交互、结果、子代理、设置和恢复的整体目标稿见[界面与协作体验](../../../plans/kite-client-experience.md)，不据设计稿宣称这些能力已交付。

[工具消息结构与状态](../../../plans/kite-client-experience.md#会话消息与工具渲染)按 Runtime 提供的展示分类呈现：同一准确 Turn 内相邻且各有明确分组 ID 的探索工具可跨批次视觉聚合，原始分组与每项结果保留；正文、独立工具、不同 Turn 和缺失分组构成边界，缺少准确 Turn 时只合并同组探索；有明确子 Agent 归属的内部工具及异常只进入所属子 Agent 容器，归属随工具 queued 和 terminal 生命周期保留，因此只恢复终态时也不会产生顶层重复；缺少归属的旧异常仍保留独立入口，子 Agent 结果不会丢失。queued、running、waiting、completed、failed、rejected、cancelled 与 unknown 使用不同文字状态。Shell 的 stdout/stderr、退出码及输出限制按真实字段放入可展开输出，文件修改显示工具报告的差异；缺失信息时不补造。当前可读内容和交互限制仍以下文为准。

一轮 Agent 回复以准确的 Turn 身份组织：运行中的过程默认展开，按发生顺序显示阶段说明和工具活动；轮次完成、失败、取消或中断后，过程整体默认折叠，已确认的最终回复独立可见。中断前已生成但未确认完成的正文仍保留在可展开过程中，不冒充最终回复。即使本轮直接给出最终回复、没有可展开过程，也保留状态行；可靠终态耗时显示“用时 …”，缺少可靠时间时显示“已完成”。可展开的状态行只显示常规字重的状态或可靠耗时，以及始终可见、紧邻文字的箭头；高度与工具消息标题一致，悬停不填充背景，不使用前置状态图标，不汇总工具拒绝等结果，也不显示“展开过程／收起过程”文案；用户手动展开和收起沿用工具消息的动画；轮次进入终态时直接收起过程，最终回复出现后不会再短暂绘制旧过程文字。具体异常仍在工具消息内查看。状态分隔线到下方首条可见消息均留 16 px（展开时为过程消息，折叠时为最终回复）；运行中的过程末尾不绘制分隔线，只有过程下方有已确认最终回复时才绘制；用户可重新展开过程，手动展开或收起的选择在当前会话阅读状态中保留。失败、取消、中断、等待与需要恢复仍显示明确状态。连续工具在执行中即组成默认折叠的聚合，不等工具完成才收成一组；执行回执逐项到达、展示信息仍在核对时，原聚合及用户手动选择保持。聚合不继承此前单条工具详情的展开选择，标题按实际动作组合更新；排队、等待不计入“正在执行”数量，标题变化会向辅助技术播报；进度和结束都不自动改变展开状态。原始模型思考正文不进入消息列表；活动 Turn 没有正在执行的工具且确有思考活动时，底部回复状态行显示“正在思考…”，其余活动阶段显示“正在回复…”，状态文字带流光且不附运行时长。上方普通活动入口使用“处理过程”，等待等必要状态继续明确显示。成功结束且终点可靠时在过程摘要显示“用时 …”，秒、分、小时、天按时长切换；失败、停止或中断保留明确状态并附可靠用时，旧历史缺少可靠时间时不补造。

只有思考、尚无正文的阶段，底部回复状态行仅显示“正在思考…”，不创建空的助手回复、空过程展开入口或正文读取控件。正文首段到达即开始流式展示，后续思考片段不会使已有正文退回思考状态。纯思考期间取消或中断，仍在原轮次位置显示准确终态。

进入会话时，历史消息及其轮次、工具信息核对结束后一次呈现，等待期间显示正常聊天加载，避免压缩状态和工具核对占位先后闪现、重新聚合造成抖动。首次显示后，持续更新和同一会话的历史校准不反复遮挡正文；真实读取失败保留原记录、错误提示及重试入口。

重复点击当前正在查看的会话不会重新加载消息，草稿、滚动位置和展开状态保持；同一会话尚在打开时再次点击，会继续等待原打开过程。选择其他会话，或从子会话详情、新对话准备页、定时任务页返回，仍正常切换页面。

当前 Run 需要恢复时，其当前轮尚未结算的工具在页面上显示“需要恢复”，不继续显示“正在工作”。这是对 Run 状态的临时展示，不写入或伪造工具终态；Run 状态更新后以真实工具事件为准。

开发版在当前父会话的“环境信息 → 子智能体”和对应的子 Agent 工具消息中提供详情入口；子会话创建并进入父作用域列表后，无需手动刷新即可打开只读详情，重新打开已完成的父会话也会自动恢复完整子会话列表，没有匹配子会话的旧后台记录只显示状态。切到其他会话后返回时，先保留此前已核对的子会话详情入口，再静默更新名单；同连接重新核对或当前页断线重接时保留上次已确认的环境状态并标明正在核对，期间不能停止执行；已有条目不额外显示读取提示。没有可复用展示摘要时，名单先显示“状态待确认”；新鲜快照到达后更新真实状态与操作资格。父会话读取明确被拒绝或身份核对失败时，立即移除其暂存的子会话入口和环境展示；子详情明确返回不存在或无权读取时，从父会话名单移除该入口。详情复用主会话的消息与工具渲染，先显示独立历史，再持续显示子 Agent 的实时过程；进入子详情时脱离父页面的实时订阅，返回后重新校准父页面，期间服务端任务继续运行。同一连接内再次打开父会话时，保留有容量限制的已读正文及阅读状态，待本次轮次、工具展示信息核对结束后恢复显示；核对期间使用正常聊天加载，失败时保留原内容和重试入口。子详情再次打开时仍立即显示已读正文，空历史不重复显示整页加载；后台继续核对最新历史与实时订阅。非当前页缓存淘汰后按首次读取处理；临时断线期间，已读主会话可从有界缓存继续阅读，切回时仍核对会话与空间身份，连接恢复后必须重新读取历史并校准。子详情的非当前页缓存随断线清除；当前子详情只保留已读内容供等待核对。缓存不赋予发送或子会话读取权限。断线重连期间保留正在阅读的子详情和已读子名单，不先显示空的父页面；名单待核对时不授予子详情读取资格。核对父子身份后才恢复该详情；用户明确返回父会话或切换其他会话时取消自动恢复，迟到结果不能再跳回子详情。子线程不进入侧栏顶层会话目录。环境信息中的子 Agent 列表自动更新，读取失败时可在原处重试。详情读取和订阅按准确父子血缘授权，面板内不能对子线程发送、停止或修改。此入口的正式运行验收仍见[后台 Agent 协调方案](../../../plans/background-agent-shell-conversation-coordination.md)。

首次打开子 Agent 详情，尚未完整读取历史时保持正常聊天加载；首次读取失败后的后台重试也保持该状态，不显示新对话欢迎页。成功确认空历史后才显示空态。已有完整正文时，刷新失败继续保留原内容，后台恢复不会重新执行子 Agent。

Agent 邮箱状态依据当前会话的持久事件显示为独立状态行：发送方的“已受理，等待目标读取”不表示子 Agent 已读；接收方的“已准备进入目标模型输入”表示输入已绑定；续轮结果结算另有终态提示。重复历史记录更新同一消息状态，私有消息正文不出现在状态行中。

开发版可选择本地项目、确认工作区信任、配置 Provider 和选择模型、新建和查看最近会话、提交任务、读取文本与工具过程并取消执行。安装与运行方法见[开发入口](../../../../apps/desktop/README.md)。

左栏默认以 200 px 最小宽度展开，可拖拽至 420 px；窗口缩放时保持当前像素宽度，由中间栏及已展开的右栏适应剩余空间；空间不足时仍受面板最小宽度约束。调整后的宽度在本机保存并于重启后恢复。拖拽分隔线把左栏收起后，顶栏显示展开按钮，点击可重新展开左栏。左栏保留已添加的项目，所有空间默认展开并自动读取会话列表；新添加的空间进入列表首位，之后切换执行空间只改变当前选择，不调整已有空间顺序。展开或收起只改变显示，不切换项目。工作台入口暂时隐藏；会话继续按空间出现在左栏，点击直接进入原会话，不创建副本或改变执行状态。各空间的会话可展开或收起，不提供会话标题搜索。点击会话直接加载消息，无需二次确认；上下键移动列表焦点，Enter 打开会话。切换会话不停止当前任务，也不会发出新消息；首次发送正在创建会话时，已有空间和会话导航也不整体禁用，用户切换阅读目标不会改变该消息所属的新会话。目录在连接和新建时自动读取；侧栏中已有会话的运行与待输入状态随会话索引更新，包括切到新对话、定时任务等非会话页面后完成的后台 Run，不依赖当前阅读页的订阅。各空间内会话按最新更新时间倒序排列，单纯点击阅读不更新时间；侧栏不再显示“切换项目”、“断开项目”和刷新按钮。返回已连接窗口只更新本地目录是否存在，不重新加载会话列表。其他端新建且尚未进入本地目录的会话仍需下一次目录读取才显示。

已加载且没有会话的空间在项目名称下方显示“暂无聊天”，并与项目名称的文字左边缘对齐。

“空间”标题右侧的 `+` 打开系统目录选择器，选中一个本地目录后将其登记为空间并进入该目录的新对话准备页；取消选择不创建空间。标题的添加按钮和空间行的新对话、更多按钮仅在各自行悬停或获得键盘焦点时显示；触屏设备上常显。空间行的两个操作按钮紧邻排列，不额外添加按钮间隙；图标为14px，点击区域为24×32px。新对话入口使用编辑图标，添加空间仍使用加号；操作按钮平时为次级文字色，鼠标移到按钮或键盘聚焦时高亮。点击空间行的更多按钮可打开操作菜单，弹层左边缘对齐更多按钮，“移除空间”使用正常文字色；空间更多与“个人工作区”菜单统一使用13px字号、18px行高及28px选项高度，沿项目选择器的紧凑排版，个人工作区弹层同样左对齐用户按钮。移除空间收在更多菜单中；打开更多菜单时立即收起空间名称与会话数提示，菜单打开期间不同时显示空间提示；鼠标或Esc关闭菜单时，鼠标已离开空间行就直接隐藏两个按钮并取消自动焦点回归；鼠标仍在行内时保持按钮可见；关闭菜单后提示继续隐藏，鼠标移开该空间行再悬停才恢复，焦点回到按钮不会立即弹出；打开或取消菜单不移除空间。选择“移除空间”后先显示原生二次确认，明确提示会停止该空间正在运行的会话、永久删除相关会话历史及本机项目登记，工作目录文件不受删除操作影响。默认选择保留空间；移除期间相关操作暂时禁用，当前页面保持原有内容，不插入“正在移除”过程文字；成功后直接更新空间列表。空间和会话删除是数据删除：对应会话正在运行时由服务端发出取消，后续资源收尾由服务端处理，不要求用户先停止任务、恢复会话或等待历史工具变为终态。空间内全部会话及子会话批量删除，不逐条处理，也不要求额外收尾确认。成功后移除本机登记及对应页面；失败显示可信结果，缺少可信回执时保持结果未知。迟到任务结果和刷新不会重新带回已删数据。工作目录文件不属于删除范围。

左栏提供“定时任务”入口；点击创建或编辑后，表单在页面最右侧的通用侧栏中打开，主区域继续显示任务页。任务由 Native 本地保存和调度；具体操作、运行记录及应用退出后的边界以上文通用 Native 的定时任务说明为准。

已登记 Git 仓库在连接准备时直接授权 Agent 访问空间，不展示“信任此项目”或重试授权提示；用户主动添加或选择的普通目录同样视为访问授权，具体工具继续遵循执行授权。授权由 Service 保存。需要访问工作区外的关联目录时，仍单独展示确切路径并确认；授权失败时保留输入，不伪造成功。窗口调整、添加或移除空间等独立操作失败通过 Toast 临时弹出，不插入会话正文；可手动关闭，也会自动消失。会话执行失败保留在所属消息中。会话内容按所属会话展示，输入草稿、阅读位置和过程展开状态在当前进程按项目与会话保留；退出后的恢复尚未提供。会话切换不取消原会话执行。

助手正文支持 Markdown 标题、段落、列表、引用、代码块、任务清单、表格和脚注，正文固定为14px、行高1.8，宽窄窗口保持同一字号；标题、代码、表格与脚注按正文比例保留层级，工具标题、过程摘要和压缩状态同步使用14px。步骤之间、步骤内段落和子列表分别留白，代码块前后的间距保持一致。引用使用透明底和侧边线；行内代码与代码块使用等宽字体，代码保留原始缩进和换行。表格保留完整细边框和单元格网格线，表头下边框与其他分隔线同色同宽，宽表格和长代码在各自区域内滚动；表格可通过键盘聚焦后用方向键横向阅读，流式追加表格内容时保留横向阅读位置。深浅主题保持清晰的文字和边界。正文不增加内边距或独立限宽，与消息阅读列同宽。

连续工具统一聚合为轻量摘要，从第一项起默认折叠，摘要只显示动作短句、图标与展开箭头，后面不追加数量、状态或异常文本；展开后以统一图标轨道和单行“动作＋目标”排列，不显示重复的完成徽标。聚合展开后的整体高度最高 400 px，超出部分在内部滚动；读取不展开文件内容，Shell 可展开有界输出、修改可展开工具报告的差异。运行、等待与异常状态保留在各工具行；执行失败或审批未通过的完整原因，仅点击对应工具展开后显示。自动审批未通过以14px警告色盾牌图标表示，与已批准的盾牌勾共用悬停及键盘焦点提示；提示仅说明审批状态，不显示具体拒绝原因。主会话只显示子 Agent 入口；子 Agent 的工具消息与步骤仅在该入口的过程容器内展示，列表最大高 320 px，超出时在容器内滚动，不常驻过程正文或结果段落；展开过程时不重复显示完成状态，失败工具的完整提示通过该工具行展开查看；子 Agent 已结束而工具缺少终态时显示“结果未知”，不继续播放运行中动画；有明确可见父工具时在该 task 展开区的子 Agent 容器查看，完成后仍保留；缺少可见父工具时保留子 Agent 容器入口，内部工具不进入主消息列表。独立子会话的只读详情从当前父会话的环境信息卡片打开，不能作为平级会话直接进入。

已提交任务执行失败时，会话中保留一条“本轮回复失败”提示，即使模型尚未生成任何回复。模型服务认证失败会明确提示检查当前提供商的凭据和账号权限；已分类的模型重试耗尽、服务不可用、会话存储不可用和工具纠错耗尽显示对应原因。缺少可靠分类时只提示检查会话失败详情和任务状态，不将后台任务、工具或 Runtime 错误推断为模型服务故障。模型给出的工具参数不符合当前格式时，该工具显示脱敏的参数错误，不展示原始模型响应。重新打开会话仍可查看失败记录。用户主动取消不显示为执行失败，读取历史不会重新发送任务。模型切换仍按会话保存的提供商和模型执行，不要求与设置中的默认模型一致。

发送与停止共用输入框右下角同一个 `26×26` 圆形主控位：消息准备与发送期间显示 loading 并禁止重复提交；失败或发送结果待确认时停止旋转。任务运行且草稿为空或正在停止时显示停止；输入新消息后切换为排队发送，引导操作位于队列条目旁；两个动作不得同时出现。

任务运行或内部受管等待后台结果时，普通输入框继续可编辑，发送运行中输入和停止操作按当前准入保持可用。Native 普通工具审批也保留输入区和权限选择器；根会话的补充问题和计划审核隐藏主输入框，但原权限工具栏、Full 确认和停止任务仍可用；切换权限不回答或替换原业务卡。MCP 特殊授权继续遵循原回答区域独占规则。已发送输入由真实输入和工作选择链决定所属任务，尚未消费的排队消息按上方规则编辑、删除和调序。切换会话后，已保存为展开的工具详情直接恢复完整内容，不再播放一次展开动画；用户在当前会话中主动展开或收起时仍保留短暂过渡。

Ctrl+A／Cmd+A 在会话页面只全选消息内容，在输入框中只全选当前输入。会话消息支持原生选词、拖选与复制，段落和列表行选区限制在内容范围。侧栏、标题、按钮、提示等非消息展示文字不可选中复制；输入框保留正常的选择、复制与编辑能力。会话消息和左栏分别滚动；工具消息中可独立滚动的输出和文件差异在还有内容可滚动的边缘显示渐隐提示。首次进入显示最新消息；向上阅读后不再被流式更新拉到底部，可点击“回到最新消息”。输入框上方不展示独立状态信息，也不保留状态行空白；输入框底部工具栏集中展示按 Provider 分组的已配置模型，以及带有审批方式说明、图标和简短行为描述的权限模式菜单；模式名称与说明按系统语言显示中文或英文，不展示快捷键教学；权限入口不显示下拉箭头，点击名称或图标仍打开菜单。点击左下角“本地用户”按钮打开选项浮层，可进入设置，或在主题区域选择“暗”“亮”“跟随系统”。默认跟随系统；选择立即应用到主界面、设置与原生表单控件，并在本机保存，重启后恢复。跟随系统时，系统外观变化会自动更新界面；固定暗色或亮色时不受系统切换影响。三个审批模式分别使用举手、盾牌终端和盾牌警告图标。完全访问在菜单中的图标、名称、说明、选中勾及底部当前模式入口统一采用橙色警示，随深浅主题调整对比度。Native的完全访问确认使用属于主窗口的系统对话框，浏览器原页面保持可见，系统阻止背景人工输入；取消是默认操作，Esc取消。说明与两条风险保持，外观由操作系统呈现。Web／共享界面的确认仍采用“清晰分行”排版：警告图标与标题同用中性文字色，简短说明下方以两条列表突出文件覆盖／删除和敏感数据外泄及难以撤销的风险，按钮靠右并以留白区分操作区。公共危险操作按钮在深浅主题下均采用醒目的实色红底与白字，悬停／按下逐级加深，不使用淡红透明底；桌面客户端每次从其他权限切换到 Full 前，说明 Full 允许代理无需逐项征得同意，在当前环境允许的范围内运行命令、读取或修改文件、访问互联网；提示文件被覆盖或删除、敏感数据传输及难以撤销的损失风险；取消不更改权限，明确确认后才继续；点击当前已选中的权限不重复提示或提交。切换会话后，模型选择器先显示目录中该会话的模型，投影加载后再按最新状态更新；已有会话选择并确认权限后立即显示目标模式，保留权限图标和名称，后台确认期间暂时禁用重复选择，输入框内的草稿和占位文字保持原有显示，不因短暂禁用变淡闪烁；桌面按钮、表单、菜单选项、开关和滑块也不以变灰或禁用光标表示等待，重复操作仍由原有内部请求锁与准入条件阻止；服务端确认后落定，失败时恢复已确认模式。权限命令提交给该会话，按该会话所属工作区核对信任；即使当前正在查看其他项目或尚未选择执行项目，也不需要切换执行项目，不停止其他会话任务。修改历史会话权限不要求先恢复任务，也不依赖该会话原模型配置仍可用；修改成功不会启动任务或解除其恢复要求。若当前服务丢失执行权后仍保留旧会话 Runtime，需要重新启动服务后再修改，不会自动接管。另一服务进程持有该会话执行权时仍会拒绝修改，版本冲突需要读取最新状态后重新选择。若会话在修改期间被其他进程删除，本次修改明确失败，不按未知结果处理。工作区未信任或不可用时不修改权限；新对话的选择在创建会话后、发送首条消息前生效。没有活动人机交互时，输入框位于下方，Enter 发送、Shift+Enter 换行；空白输入和加载期间不能发送。任务运行但未等待交互时，输入框继续可编辑，Enter 把纯文本作为定向引导追加到同一 Run，不取消当前请求、不新建 Run；目标在提交前结束时保留草稿，不改投新任务。停止仍由独立按钮发起；提交后显示等待收尾，只有服务终态才显示已停止，已有修改保留。审批、补充问题、计划审核或其他等待交互出现时，主输入区隐藏，避免与当前交互争夺操作；交互结束后恢复原草稿。这不是新 Run 的后继队列。会话侧边显示后台 Shell、service 和子 Agent 的准确身份与状态；只有当前连接代次中新鲜且仍运行的项显示停止入口，断线后的旧运行项不可操作。

左栏品牌下方的“新对话”是与空间区域同级的全局入口；工作台入口暂时隐藏；尚未打开项目也可以进入并写下需求。欢迎区只显示标题，需求直接在输入框编辑；首次发送时才创建会话并进入正常消息流，重复点击入口不会创建空会话或清空草稿。首次发送后输入框立即清空，内容区原位显示“正在发送”的用户消息；真实消息到达后在同一位置接管，失败则原位提示并把内容恢复到输入框供重试。准备草稿跨项目／分支选择保留，与已有会话草稿独立；切回历史会话恢复它原有的输入。发送失败后保留已创建会话，不重复创建。

空间标题右侧的“新对话”图标进入该项目的新对话准备页，不改变列表展开状态，也不提前创建空会话。选择其他空间时只校验已登记目录并读取该目录的 Git 分支，立即更新准备页上下文；不关闭当前 Service、不切换执行连接，也不读取项目列表、会话目录、信任或模型。左侧空间和会话列表保持原对象与交互状态，目标分支读取完成后一次替换。首次发送前才沿用现有执行项目切换流程；届时有活动任务会先确认停止，再激活目标空间并核对信任和分支，继续使用应用已经持有的模型目录与本次选择。普通非切换断线仍禁用会话导航。

预选空间不是当前执行空间时，输入区继续使用应用已读取的 Provider 目录和当前权限选择；模型与权限选择器不属于空间，切换空间不重新加载、不清空也不短暂禁用。模型选择只在准备页暂存，不修改当前或目标空间的默认配置。外部目录授权仍只在实际激活目标空间后读取和提交。发送前观察到分支或 HEAD 变化时采用当时的真实环境继续执行，不要求用户重复发送；只有用户明确选择了另一分支，才在首次发送流程中执行受控 Git 切换。会话一旦创建就立即绑定该身份；随后权限设置明确失败或回执未知时恢复草稿并在同一会话核对或重试，不再创建第二个空会话。用户取消停止旧任务和切换空间时同样恢复准备草稿并重新开放发送。

输入框聚焦不增加额外边框，右下角没有手动调整尺寸的拖动柄；多行输入由内容撑开。发送与停止使用同一位置的图标按钮，悬停提示和可访问名称说明当前动作；停止提交期间保持禁用，避免重复请求。

已发送的用户消息可逐条复制；Agent 复制按钮按 Runtime `turnId` 归属，同一 turn 内只在没有后续工具调用的最终回复下显示一次，并只复制该完整最终回复，不包含同轮工具前说明、思考、工具、子 Agent 或其他非最终文本。用户气泡和 Agent 最终回复与后续内容的间距为 32 px；非最终回复到后续工具保留 8 px；工具记录到下一段非最终正文为 8 px，到最终回复为 16 px，工具组内保持紧凑。悬停消息或用键盘聚焦可显示复制按钮；成功时显示较大的勾，两秒后恢复复制图标；发送状态未定、失败或流式回复不提供复制。轮次底部的回复状态行在准确 Turn 终态后移除。发送回执未知时保持“待确认”并阻止重复提交，等待新的运行时事实或显式会话恢复。

块级代码使用带语言标题的代码框；未标注语言时显示“代码”。完整最终回复通过原文读取核验后，可在代码框中单独复制代码内容，不包含语言标题；预览、流式回复或最终身份未确认时不提供代码复制。复制失败可重试，暂时只读时暂停操作，关闭完整正文即撤销资格；长代码仍可通过键盘聚焦后在自身区域内滚动，行内代码的阅读方式保持。

新 Run 在持久提交前明确遇到 revision 冲突时，客户端可重新读取投影并且仅重提一次；刷新后已有活动 Run 则保留草稿，不自动改投为 steer。这不改变回执未知时禁止自动重发的规则。

输入框上沿以无底色的紧凑上下文条选择已打开项目或添加本地目录；没有项目时菜单只显示“添加项目…”，不显示空列表与分隔线。Git 仓库旁边直接显示真实分支，不重复展示固定的本地环境提示；非 Git 项目完全不显示分支选择器，仍可正常发送。Git 只是空间的可选能力：`.git` 标记无法确认、Git 未安装或 Git 探测失败时按普通空间继续，不阻止创建对话；项目选择、分支信息读取和刷新不弹出临时提示；只有用户主动执行分支切换时才要求 Git 能力可用，真实阻断保留在所属操作结果中。上下文条与输入正文共用左侧视觉基准，只承担轻量元信息层级，不作为独立大卡片与输入框争夺视觉重心。选择项目或已有本地分支后立即生效；切换分支时有运行、排队或等待中的任务，或存在暂存、未暂存、未跟踪的改动，都会阻止切换。不会自动提交、丢弃修改或创建 worktree。分离 HEAD 和尚无提交的仓库显示真实状态；只允许在仓库根目录切换分支。分支菜单可以刷新，失败或回执未知时检查刷新后的实际状态，不自动重试。

应用启动先显示独立启动页，完成本地服务连接、首屏空间会话目录及当前项目的准备检查后再显示主界面，不展示主界面逐项加载的过程。服务连接或首屏目录全部读取失败时，启动页显示原因并提供“重新尝试”；空目录可以正常进入，局部目录失败、项目失效或模型未配置不阻止进入主界面处理。启动页没有人为最短停留时间；进入主界面后发生断线仍保留页面与草稿，不重新遮挡为启动页。

Windows 原生 Mica 与 macOS Vibrancy 窗口的启动页不铺实色底，准备中和初始化失败时均直接显示系统玻璃材质，文字与操作按钮沿当前主题保持可读；其他窗口保留原背景。

重构后的正式 Native 已迁入原启动页，并接入当前服务连接与首屏完整目录读取：首次准备未完成时等待，初始化失败显示原因并可明确重试；初始目录观察确认不可用时也提供重试，原连接恢复完整目录可直接进入，用户重试后旧连接的迟到目录不能覆盖新页面。进入后断线保留页面与草稿。切换或重试后，旧选择、草稿与状态读取的迟到失败不影响新页面；普通会话操作失败也不弹出“操作未完成”。可恢复读取与未知原提交在后台自动核实，原草稿和消息保留。独立业务的真实失败通过会话区域上方的非模态 Toast 临时弹出，不占用会话正文或随正文滚动，约6秒后消失，鼠标停留或消息内有焦点时暂停，也可明确关闭；消息使用通俗解释，只说明能够核实的原因，不显示内部错误码，也不指向普通界面没有的操作入口。Toast只保留普通客户端独立业务实际可触发的项目记录不存在、本地数据存储异常与服务处理异常三种专门文案；找不到记录不直接说成“已删除”。其他普通业务异常使用中性说明，不推断成败或引导直接重试。隔离诊断测试也不会为会话、草稿或读取错误增加全局Toast；原操作结果继续在所属消息和记录中核对。本地数据错误不一概称为草稿失败，普通读取失败不推断原操作结果未知；添加或移除空间已有成功回执时，随后列表刷新失败也不改报业务失败或重复提交。打开设置后，应用级提示仍通过同一临时 Toast 显示，保持剩余停留时间；设置表单只显示自己的局部错误。启动错误保留启动页；这些提示不会另开“操作未完成”确认框或主动隐藏网页。实际迁入范围及 DOM／macOS 首次和冷启动证据见[Native owner](../../../../apps/desktop/README.md#原启动页与初始化重试)；有效服务诊断时的“保存诊断”也已接回，见[诊断保存范围](../../../../apps/desktop/README.md#原启动诊断保存)；其余安装恢复要求继续按原方案验收。

应用重启会恢复已打开项目列表并自动读取应用历史，不创建会话或发送任务。项目目录失效或模型配置错误不妨碍阅读已有历史，各自显示局部提示；Git 不可用按普通项目继续，不追加分支提示。发送前核对目录、信任和模型；普通资料文件夹无须 Git。本地服务的启动、连接与恢复由客户端内部负责，不提供重连或断开操作，内容页不展示连接中断或服务未就绪提示。内部恢复期间保留会话内容与草稿；侧栏会话点击立即改变阅读选择，连续点击只恢复最后选择的会话，不等待旧会话完成连接才响应。已选会话在校准期间仍显示阅读页，不误显“新对话”欢迎页；发送、停止与审批继续等待新连接就绪。操作结果未知由后台查询原申请，真实执行结果保留在所属消息中。未发送草稿不承诺应用重启后恢复。

普通关闭窗口保留应用与任务，再次激活显示原窗口；明确退出或实际切换执行项目会停止自有服务中的执行，已有修改不撤销。明确退出立即关闭可见界面，不进行退出确认或等待状态查询；正常清理先完成原网页释放与服务退出，再销毁窗口；清理最多4秒，超时终止自有服务并结束主进程，不再弹异常收尾提示，也不自动重发请求。连接断开后不能使用旧的就绪状态提交操作；回执丢失时自动查询原申请，消息区外不追加“操作提交结果未知”或临时查询按钮；未知效果仍按所属消息的真实结果保留。

通用 Native 的明确退出直接进入原停止流程，不再读取活动任务来决定是否退出，也没有取消退出或退出确认失败提示。退出时暂停页面自动读取，旧状态、目录、选择及私有草稿读取的迟到失败不追加提示；真实执行结果和未知效果继续保留在所属记录中。原窗口与网页隐藏后，任务和服务清理沿原主进程进行，最多4秒；未完成即强制退出，使整个退出不超过5秒，不追加收尾警告或确认。服务非零退出仍是清理失败，界面关闭不等于清理成功。当前窗口、所属进程与有限故障验证范围见[退出 owner](../../../../apps/desktop/README.md#原窗口关闭与退出收尾)，不代表完整安装恢复或平台资格。

工具的准备状态与执行结果分别展示。Core 已核实尚未派发、因上下文或工具信息变化而失效的调用，显示“上下文已更新，此次未执行”或“工具信息已更新，此次未执行”；聚合标题不追加状态计数，逐项原因不计为执行成功或实际失败。实际派发失败、拒绝、停止、未知结果和无法核实的旧记录继续保留原状态。正常只读探索发现新目录指令时，读取继续完成，下一次模型判断使用新指令。

工具审批会显示具体命令与说明，可以选择“仅批准这一次”或拒绝；结果仍由服务核实。补充问题使用紧凑的 Questionnaire 卡片展示问题、进度、单选项和允许的自由回答，整行选项可点击，推荐项显示中文标记；作答区不显示内部状态、执行身份或原始 JSON，取消与翻页／提交位于同一操作栏；一次请求包含多题时可通过上一题／下一题自由查看，最后一次提交全部答案，每条答案以 `q1`、`q2`、`q3` 题目 ID 保留协议归属。选项提交同时保留内部 option ID 供校验与恢复，但交给 Agent 和历史摘要的是选项文案；自由回答保持用户原文，不把 `q1-o1` 等内部编号当作语义答案展示。选项不常驻显示字母顺序或详细描述；有描述的选项在右侧显示 info 图标，鼠标悬停或键盘聚焦后显示该选项的标题与完整描述。第一页只显示下一题，最后一页才显示提交回答；可以在当前题未答时先查看后续问题，但尚有任一题未回答时提交按钮不可用。交互块不使用内部滚动条，完整内容直接占据底部布局并让会话阅读区收缩。取消回答会把取消结果交给模型，模型仍可继续；停止任务与取消回答分别作用于原任务和原问题。计划面板显示完整正文与步骤，提供批准此计划、修改要求与拒绝，不选择权限模式；未能完整读取正文时不能批准，较大正文先加载完整附件。扩展或验证交互仍显示限制，用户可取消。高级恢复尚未交付。

新 `apps/desktop` Native 候选现已通过本机 macOS 的默认 ask_user 问卷窗口验证：未作答可浏览、多题一次明确提交、会话切换保留问卷草稿、取消问卷后原任务继续；当前父轮的问题出现时隐藏主输入，回答或取消后恢复原主草稿。原值、文案和原 Run 分别核对。问卷草稿的页面生命周期另有 DOM 证据；计划审核另有下述验收，全部设置与完整视觉迁移仍未完成。实际范围见 [Native 问题 owner](../../../../apps/desktop/README.md#native-普通问题与页面草稿)。

普通 Native 可显示工具主动请求的计划确认；“先审核计划”开关仅属于隔离测试界面，普通启动和开发客户端不提供该开关。手动、Auto 和 Full 都需要用户明确批准当前计划，批准不改变权限模式，也不批准后续其他工具调用；补充修改要求后，新版本仍需重新批准。拒绝本版计划与停止原任务各有入口，停止不撤销已有结果；结果未知时明确退出也立即关闭界面，效果仍按所属记录核对。当前父轮自己的计划审核期间隐藏主输入，但权限选择器、原 Full 确认与停止任务仍可用；交互结束后恢复原主草稿。权限状态未知或读取失败时保留原门禁，不借计划卡切换权限；普通工具审批保留输入区与权限选择器。具体可用范围和本机验收见 [Native 计划 owner](../../../../apps/desktop/README.md#native-计划入口与完整审核)。

子 Agent 等待批准或回答时，其准确交互卡继续显示，父会话仍可输入新请求；一项子任务待批不会占住其他协作工作的父输入。每张批准卡仍只授权所显示的原执行；旧卡答复不会批准同一协作者后来一轮，停止也保持原准确任务范围。

补充回答和计划修改意见在当前页面进程内保留：切到其他会话、新对话或定时任务再回来，可以继续编辑原文。它们与主输入框草稿分开，也不会带入其他会话或下一道问题。提交失败保留输入，确认提交或取消成功后清理对应交互的草稿；完整页面刷新和应用退出后不保证恢复。

点击会话标题栏的“标签页”图标打开最右侧栏，默认显示“新标签页”。标题栏采用48px紧凑高度，标签本身高度保持不变，缩小上下留白。顶部标签条支持切换、关闭和用 `+` 新建网页标签；网页、变更与子 Agent 详情合计最多同时打开8个标签，已满时打开新的详情会提示先关闭一个标签。关闭最后一个标签会自动收起右侧栏，再次点击“标签页”图标会显示新的空白页。新标签页的“工具”目前只有“变更”，点击后打开或切回唯一的变更标签，展示整个仓库当前工作区相对 HEAD（当前分支末次提交）的变更，包括已暂存、未暂存和未跟踪文件，不按 Agent 贡献归类。右侧文件树标明暂存区与工作区状态，可按路径筛选、折叠目录和翻页；选中文件才读取当前差异。正文默认双栏，也可切换统一视图，显示已知行号、增删色和轻量语法色；已保留的未变更段可折叠，省略内容不能展开，增删计数只代表预览。首次打开变更页会调宽阅读区域，之后保留用户拖动的宽度；窄栏上下排列，文件树不会隐藏。已暂存与未暂存抵消时仍保留状态并说明当前内容与 HEAD 相同。未产生首个提交时按空树比较新增文件。变更标签可见期间会合并工作区文件与 Git 状态变化后自动同步，外部编辑器、Shell 和 Agent 的修改均在范围内。同步保留同文件的阅读位置、文件树折叠与布局；暂时读取失败保留上次结果并说明尚未确认最新内容，有限重试后仍可手动刷新。切换标签、收起侧栏或窗口隐藏后停止观察，重新显示时核对最新内容。文件系统不支持完整目录通知时使用低频后备核对（Linux通常约10秒加读取时间），不保证每次写入立即显示；手动“刷新变更”仍可用。非 Git 项目、读取失败、二进制／不支持的文件和过大内容分别说明，不把失败当作干净仓库。列表和正文都有展示上限并提示截断。子模块内部改动不递归显示；使用内容过滤器（如LFS）、分离索引或特定全局／info属性设置的仓库会明确提示暂不支持，需用本地Git工具查看，不会为显示差异执行仓库配置的外部程序。在设置中可选择 VS Code、Zed 或 TextEdit 打开当前项目内仍存在的文件；同一选择也用于消息中的路径链接和读取文件路径，默认 VS Code，在当前进程保留。打开的是当前磁盘内容，编辑器需已安装。迁移前 Tauri 版本曾在本机 macOS 确认 VS Code 实际打开；TextEdit 仅确认启动分发，Zed 未安装。Electron 版本的实际编辑器窗口仍待重新验收。

网页标签提供后退、前进、刷新／停止和地址栏。输入 HTTP／HTTPS 网址可直接访问，普通文字按 Bing 搜索；localhost 可用于本机页面。网页独立运行，不读取应用接口、会话正文或本地文件，也不会把网页自动发送给模型。新窗口网页链接在当前标签打开，暂不支持导入浏览器数据、安装扩展、下载或外部协议。网络加载失败时，内容区显示“无法访问此站点”、目标网址、排查建议和“重新加载”；错误码放在次要位置，不展示整段日志。可修改地址、后退或手动重试，网站自己返回的404等页面照常展示。

侧栏沿原宽度动画与调宽操作开合，明暗主题的标题栏均显示与会话标题栏对齐的底部分隔线。收起、Esc 或切换标签会结束变更内容与子 Agent 详情的读取，当前会话的标签与网页历史保留；窗口缩窄后拉宽也保留它们。关闭网页标签、切换会话或重载窗口会释放旧网页；重载和退出不恢复标签或浏览记录，浏览器 Cookie 只在当前窗口进程内保存。关闭侧栏后焦点返回顶栏按钮，输入草稿和实际执行保持。

首次打开或缓存已被淘汰的会话显示加载进度，长历史分批读取后完整展示。已保存的正文先于实时连接校准展示；实时状态查询或订阅失败不会挡住已读历史，也不会使任务自动重跑。单次会话加载或校准超时后保留已读正文，可重新加载或切换其他会话；超时本身不主动断开其他会话共用的连接。实时校准完成前可阅读、复制和编辑草稿，发送、停止与审批保持不可用。已打开的会话若出现实时消息缺口，会保留正文并自动补读历史；消息补齐且实时订阅重新就绪后才恢复操作，补读失败仍可阅读并重新加载，不会自动重发任务。首次发送选择的权限模式与当前一致时保持原模式并继续提交。同一连接内再次打开已缓存会话，立即显示上次正文并恢复阅读位置和展开状态；空会话也会缓存。后台仍会完整校准历史，期间可以阅读、复制及编辑草稿，发送、停止与审批等操作等待校准成功。校准失败保留已读正文并提供“重新加载会话”；明确不存在或拒绝读取时清除正文。缓存容量有限，超长会话离开后可能需要重新加载；非当前会话缓存不跨连接重建、页面刷新或应用重启保存，普通断线仍保留当前正文供阅读。每个空间的目录默认读取并返回全部会话，不提供手动加载更早会话的入口；页面按最新更新时间从新到旧排序，默认显示前 5 条，点击列表末尾辅助文字色的“展开更多”每次再显示 10 条，最后不足 10 条时显示剩余会话。收起空间后再次展开恢复为 5 条，其他空间不受影响。一个空间读取失败不清空其他空间。点击其他空间的会话直接阅读，不停止原任务；在已有会话发送时按原会话身份路由，不切换当前执行项目，也不停止其他会话任务。本地目录不存在时，空间名称变浅，仍可打开会话，不常驻提示目录关联情况。已有会话继续发送不以本地目录存在、Desktop项目登记或当前选中项目为前提。服务按会话持久身份与既有授权执行；原目录被删除时仍可对话，依赖该目录的Shell和文件工具在实际调用时返回错误，不自动创建目录或改用其他目录。新建项目会话仍核对所选目录与授权。自动重接恢复所选会话和进程内草稿，不重发任务。

设置页的“提供商”以简洁列表展示用户已添加的独立连接、名称、类型、配置状态与编辑/删除入口，空列表不预置提供商。点击“新增提供商”直接打开应用最右表单，通过“服务商预设”下拉框选择 OpenAI、DeepSeek、Ollama 或自定义兼容服务模板，再填写连接名称与配置；同一模板可添加多个实例。编辑沿用同一右栏；删除另显示相关模型、默认模型和本机定时任务影响，明确确认后才移除配置，存在默认/定时引用时拒绝删除且不自动换模型。系统凭据库秘密保留。关闭后回到原按钮；删除成功后回到新增按钮。列表中的配置状态不承诺远端连接或执行已验证。切换提供商会清空上一提供商尚未保存的密钥、地址和模型名称。必填 API key 与服务地址格式在面板内提示错误并聚焦对应字段，不弹出浏览器原生校验提示。“提供商与模型”同页按连接管理已发现模型，在“管理模型”浮层中启用或禁用；模型行不显示默认标识，页面不提供默认模型选择卡片。默认模型也可禁用，默认引用保持原值，后续运行仍须核实模型已启用且可用，不自动替换模型。启用或禁用模型、后台重新核对配置和保存提供商时，页面保留当前分类与滚动位置，不整体变灰；等待期间阻止重复配置操作；关闭再打开设置不会解除等待，完成后才恢复配置操作。启停开关先保持用户选择的位置，提交失败则按服务确认的状态恢复并显示错误；提供商保存期间输入只读。无可选模型时显示空态和服务提供的诊断代码，不将未配置误报为可用。输入区模型选择器只展示已启用的模型路由，并暂存本次选择。新会话在首条消息创建时绑定该路由，已有会话在下一条消息开始时更新自身路由，不覆盖其他会话；活动任务继续使用开始时冻结的模型。通用 Native 的 API key 通过选定 Profile 的系统凭据库保存，JSONC 只保存引用，输入在提交后清空；保存仅更新选定连接，保留同一 Provider 的其他连接。模型名称留空时查询模型列表，手动填写时直接保存，是否可执行仍需实际任务验证。提交结果未知时只能显式查询原提交；最新配置读取不能代替原保存回执，不自动重试。

输入区的模型与思考选择器先展示紧凑思考浮层，点击模型名称进入提供商与模型双栏；展开和返回时尺寸平滑过渡，内容轻微淡入，系统减少动态效果时直接切换。两列分别滚动，模型数量变化不改变浮层高度。选择器及思考浮层统一使用 13 px 文字，档位名称、模型名称与轨道之间的可见间距一致，顶部与底部留白均衡。滑块按轻度、中、高、极高、Max、Ultar六档选择，蓝宝石星光随档位加速，最大档为融合蓝色的紫宝石；轨道高度为24px，不绘制边框，白色按钮在悬停或拖动时放大25%，结束后恢复，松手时短暂扩散粒子；系统减少动态效果时关闭尺寸过渡与装饰动画。所有已配置且可用的模型均可调节思考程度，实际请求统一传递所选档位，由模型服务决定是否接受。已有会话优先显示当前手动选择；没有当前选择时，恢复该会话最近一次运行中同一模型使用的具体档位，再读取模型配置。新会话从所选模型的配置读取档位。模型按钮、浮层标题与滑块显示同一具体档位；模型选中后始终存在具体思考档位：优先恢复当前选择或该会话上次实际值，再采用模型配置；缺省为中。目录为稀疏档位且不含中时，采用其中最低的可选档位。默认档位直接显示在标题、按钮摘要和滑块上，无需先调整；发送始终携带显示值，不显示“未指定”。明确点击、拖动或键盘选择会同步改变本次选择与下一轮参数。选择在当前页面进程内按对话保留，切换模型清除原模型的临时档位；新对话首条消息使用准备页的选择，之后继续发送沿用该对话的选择。模型与档位只作用于下一次新运行，不修改全局默认，也不改变正在运行的任务；运行中发送仍为文本引导。页面刷新后，未发送的临时选择清除；已有会话恢复上次实际使用的档位，新会话读取模型配置，活动运行仍使用其已冻结档位。

思考浮层不常驻显示会话协议说明。已开始运行的对话仅在模型列表底部轻提示“仅显示当前对话可用的模型”，候选仍按[模型兼容规则](../../features/models-and-configuration.md)过滤。


保存 Provider 与刷新配置分别确认结果：已保存但刷新失败时，提示刷新后选择模型，无需重复保存；服务明确拒绝时保留拒绝原因。写入结果未知时，即使后续刷新成功也不改称保存成功；刷新同样失败时明确说明两者，避免将查询错误误认为写入未发生。

设置中的 MCP 和 Skills 都是用户级全局页面，无需选择项目或会话，切换会话保持列表、阅读位置和未提交表单。页面只显示用户级条目，项目与工作区配置不出现在这里，也不提供范围切换。MCP 列表展示服务名称、地址、连接状态和启用开关，点击服务打开详情。新增表单校验通过后直接添加；详情按当前状态提供连接、重试或登录，已连接时自动加载工具名称和说明，点击工具可展开参数。“更多”收纳当前适用的刷新工具、重新连接、断开、授权维护和删除；退出登录只清除此设备的登录信息，撤销授权另向服务提出撤销，删除和退出前显示具体确认。需要登录时单独发起认证，认证成功后再明确连接。服务要求登录、登录失效和浏览器登录超时会在对应服务详情中显示原因与下一步。正在进行的操作会自动核对原结果，并更新登录及连接状态，仍可取消；认证成功后不会自动建立连接。结果未知或重启后仍待确认的记录保留“查看结果”，由用户明确核对，不自动重试。配置不可用但仍有连接时保留断开入口。Skills 只读展示名称、描述、正文及用户来源，提示禁用或配置、读取异常，没有安装或启停入口。此功能不改变 Web 的只读权限。

正式 Native 的 Skills 分类读取用户配置中明确选择的目录，来源限于用户配置根和 Profile 的 Skills 目录，不读取项目配置或项目文件。完整读取成功后展示统一列表，点击条目在应用最右侧查看只读详情。点击“刷新 Skills 目录”重新读取用户文件及配置；刷新失败保留上次完整目录和已打开详情，并说明未更新。可用空目录与目录不可用分别说明，关闭分类只停止目录读取。它没有安装或 Workflow 激活入口。实际窗口、切换会话和冷数据验证范围见 [Native Skills owner](../../../../apps/desktop/README.md#native-skills-只读目录)。

客户端启动以 300ms 内完成本地连接和首屏目录为优化目标；目录无需先恢复所有历史或准备模型。迁移前 Tauri 宿主的部分热缓存服务至目录测量曾低于该预算，但首次运行和完整系统启动仍未满足资格；Electron 需要重新取得从系统启动到窗口绘制的端到端证据。测量条件与负载限制见[历史启动说明](https://github.com/ferqx/kite-code/blob/d5407cfe4319c5a84d530f63b1d0a0123218ad34/apps/kite-desktop/docs/history-and-recovery.md#启动预算与验证边界)。

点击未缓存的会话后，右侧消息区保持原尺寸并在中央显示无底色的浅色风筝图标，以不改变布局的轻微闪光表达加载；系统要求减少动态效果时显示静态图标。页面不显示加载文字或欢迎内容，历史分批读取完成后直接渲染完整正文，避免加载节点引起布局抖动。已有缓存正文的后台校准继续保留正文，不显示该覆盖层。

通用 Native 的工具过程现在沿用原轻量工具行与结果展开。执行中、失败、停止和结果未知按已核实的原执行展示；消息完整不表示工具成功。读取文件失败在行内保留简短状态，点击该工具展开完整原因；只有已确认成功且可用的文件操作提供路径按钮。目标文字来自已读的原请求，有歧义时不补目标。Shell 启动受理与后台任务完成分别表达，完整输出和准确停止继续从环境信息／Runtime logs 操作。工具记录的展示信息尚在读取时，原始结果默认收起，状态显示“状态待核对”，不会先显示整段 JSON 再换成简洁工具行，也不把待读取误报为执行结果未知。未知工具或版本显示原名称、版本和可展开原文；无法核实状态时保留可主动展开的原结果，也可明确重新核对。关闭结果或切换会话只结束读取，不停止或重新运行工具。

Native 已接原轮次阅读：按已核实的 Run 显示过程、耗时与终态，结束后过程默认折叠，确认的最终回复独立可见；可重新展开过程，同轮相邻的已知文件读取／搜索等沿原工具聚合。完整正文自动依次读取，回复内不提供“重新读取”按钮；真实读取失败保留已显示内容并说明失败。复制最终回复使用已完整读取并核验的准确正文。恢复时已保存的旧 Store 终态可作为历史展示，原出处保留；Fork／Include 封存内容不借来源 Run 后来的状态补最终回复。状态无法核实时保原消息或“上次确认状态”。

Native 从父会话环境卡打开的子 Agent 只读详情显示在右侧栏独立标签，复用父会话的消息组件：按已核实的轮次显示过程、耗时与终态，完成后过程默认折叠，最终回复独立显示；相邻的工具调用沿相同工具聚合，Markdown 和准确全文复制也共用原组件。详情标签保持只读，没有输入、审批或文件打开操作；主会话保留自己的输入、审批和原操作资格。详情会自动跟随已保存的新消息和回复前缀；正在生成的前缀仍标为未完成。已完整读取并核实的正文直接显示。切换标签、关闭详情标签、收起侧栏或打开设置会结束该详情的读取，原任务继续执行；父会话正文继续更新，草稿、阅读位置与展开状态保持。再次选中已缓存的详情标签时，先核准其仍属于当前父会话，再显示上次正文并在后台校准；读取失败保留上次内容并说明未更新。仅轮次或工具展示信息读取失败时，已经核实的正文仍可阅读，页面明确提示并可通过刷新重新核对。缓存和阅读状态都有容量限制，超长或已淘汰的会话重新进入时需要读取，页面不会为全部历史会话保留隐藏消息组件。

通用 Native 的复制按钮现已接系统剪贴板，保原完整正文与成功／失败反馈。原宿主复制上限为 1 MiB UTF-8 字节，超限显示复制失败，不复制预览或截断正文；全文阅读能力保持独立。macOS 当前首次与冷启动的实际剪贴板证据见[复制 owner](../../../../apps/desktop/README.md#原消息复制与标题栏缩放)。

通用 Native 在新链路明确备份恢复为新 Store 后，可从原 Fork 页面继续读取完整大回复。原消息、模型和出处保持；关闭全文或切换会话结束本次阅读，冷重开仍需主动读取，不重新发起原任务。封存内容不借来源轮次的后来状态补成最终回复；原源会话的准确全文复制资格在关闭后撤销。macOS 当前安装版范围见[完整正文 owner](../../../../apps/desktop/README.md#恢复后封存-model-正文)，全部恢复组合仍待核对。

默认问答工具的已保存结果沿原组件显示实际问题和人类回答；取消信息回答显示“已取消回答”，任务按真实状态继续。人工审批已接原按钮与范围菜单，完整大请求读完并核实后才能回答。工具上的原审批事实分别显示已提交待核对、已人工批准、自动批准／拒绝／等待或未知；停止后保留可核对的已有记录，批准不代表工具执行成功。首次和冷启动的人工审批记录已核实，原记录可从下文“交互记录”阅读。当前会话输入区仅提供工作区内修改／自动审核／完全访问，选择直接使用三策略的实际权限值，只改该会话；完全访问取消或切会话后的旧确认不生效；原停止按钮按准确活动任务提交取消，等待原状态核实。macOS 当前 Store 已核自动批准、拒绝、转人工、无效结果回到人工及审批中停止；转人工保原原因，拒绝或停止时没有文件作用，冷读不重发。全部封存／恢复组合和完整 PC 验收仍待核对。当前范围与证据见 [Native owner](../../../../apps/desktop/README.md#原审批面板与授权观察)。

通用 Native 在新链路明确备份恢复为新 Store 后，原源会话和分支的已回答问答仍沿原工具记录展示相同问题、选项标签与完整自由文本。查看、展开、切换和冷重开只读取保存记录，不重新回答或调用模型；封存记录不会借来源任务的后来状态获得执行或回答资格。macOS 当前安装版范围见[问答 owner](../../../../apps/desktop/README.md#原轮次阅读聚合与问答回执)，其他问答／审批恢复组合仍待核对。

工具消息按已确认原型统一为轻量行：上下各留 8 px，工具聚合展开后不缩进；hover 高亮文字与图标，不增加背景色。仅具体文件名 hover 时显示下划线并可打开。Shell 行以终端图标、实际操作状态和单行省略的命令摘要显示，点击展开带边框与圆角的 Shell 卡片。卡片采用 CodeBlock 的固定 Header、滚动输出和底部结果结构：带 `$` 提示符的执行命令在 Header 按原始换行完整显示，长行自动折行、不省略，可复制完整原始命令；Header与输出之间不绘制分隔线，滚动区通过scroll-fade显示随位置变化的边缘渐隐；仅输出区滚动，右下角显示实际结果；已确认成功时显示“成功”与勾号，不追加退出码，失败时保留具体退出码。独立输出滚动区最高 256 px，聚合内随剩余空间收缩，状态保留在卡片底部；手动上滚后停止跟随，滚回底部后恢复；不显示“回到最新输出”按钮。实时记录被已保存回执接替、命令全文读取完成时保持展开及阅读位置。运行中的文字有轻微扫光，减少动态效果设置下静态显示。

同一轮中连续的工具调用统一聚合，读取、搜索、修改、Shell、MCP 和 Agent 协作均适用；可读的阶段说明、用户引导或另一轮次开始新的分组。聚合从第一项起默认收起，后续新增工具、回执接替和展示信息补齐保持原容器及展开选择。仅用于声明工具、且当前能确认没有正文的模型消息不占独立消息行，也不拆开连续工具；历史从未完成更新为完成时保持原聚合。存在正文或正文仍需读取时保留原阅读入口。标题按组内动作去重组合，例如“编辑文件读取文件运行命令”，不加“了”或顿号，不显示工具总项数。标题后不追加任何数量、状态或异常文本。各工具行仍按实际状态表达执行、等待、审批、失败、结果未知、停止或此次未执行，不推断成功。展开后的整体高度最高 240 px，超出部分在聚合内部滚动；聚合内工具列表项之间的纵向间距为 0，聚合与工具详情统一使用带滚动条的 ScrollArea，并在滚动边缘显示随位置变化的淡出提示；列表、输出与长详情均可聚焦后使用键盘滚动。鼠标在聚合或工具详情内滚动时，优先滚动当前内容；到达顶部或底部后继续滚动外层会话，内容无需内部滚动时也可直接滚动会话。摘要随实际动作组合更新，不切换成最后一个工具的名称或路径。展开聚合后，可继续逐项查看命令输出、修改差异、问答、原始记录或准确的子 Agent 详情。

已核实的工具尚未派发时显示“等待执行”，已派发且尚未返回结果时显示“执行中”；读取、修改和其他工具保持相同含义。Shell在排队、审批和执行过程中即可显示具体命令，不等执行完成；命令来自准确工具记录，不按模型正文猜测。已保存会话重新打开时直接读取原命令及结果，不需要新建对话或重新提问。自动审批、等待人工审批和拒绝保留各项事实；执行权不可核实时停止活动提示。派发不代表执行成功，最终结果以实际保存状态为准。

“会话工具”中的“交互记录”可展开阅读原问题、计划和审批请求，查看已保存答案、取消与回答被执行接收的事实。这里只阅读，当前待回答记录仍从原待输入卡操作。计划保留格式化阅读和准确修改反馈，大附件须完整读取并核实后才能展开原文。分页期间状态变化会保留本会话上次完整记录并说明未更新，可点击“重新读取交互记录”；切换会话清理旧范围，关闭只结束读取。新链路明确备份恢复为新 Store 后，可继续阅读实际保存的问题、计划和审批记录及完整附件，原出处保留并显示“恢复历史，只读”；旧未完成记录按实际恢复结果显示取消。查看不会重新回答、执行或获得审批权，分支不自动取得来源后来的交互记录。当前验证范围见 [Native owner](../../../../apps/desktop/README.md#原交互记录只读历史)。

自动审批状态附在所属工具上：审批中、已自动批准、未通过或等待人工审批。已自动或人工批准不再常驻文字，在命令后以14px低对比度盾牌勾图标表示，悬停或键盘聚焦可读完整说明，Escape可关闭；审批中、等待人工、拒绝等仍显示13px辅助文字。实际执行失败、超时与结果未知保留异常提示。确认未派发的审批拒绝或取消只显示对应审批状态，不再追加“未执行”或重复的停止状态；Shell展开后的状态区也不重复审批等待。已批准后的真实执行结果独立保留。需要阅读原因时点击对应工具展开，保留服务提供的完整文本。人工审批主按钮为“仅批准这一次”，服务允许时右侧菜单可直接“批准本次及本会话相同命令”；左侧为“拒绝”。授权范围仍以服务匹配规则为准，批准不等于执行成功。上下文压缩在正常消息区以类似工具消息的左对齐轻量行显示状态，文字两侧不绘制横线，字号、行高和上下留白与工具消息标题一致。同一次压缩由进度接管为已保存记录时保持原行和阅读位置，不因历史刷新先消失再出现；后续压缩使用各自状态行。实时进度显示“正在压缩上下文”；只有旧进行中记录、没有当前进度确认时不显示该状态行。实际结果包括已发布完成、失败、取消或未发布；模型摘要成功但未提交不能显示完成。压缩摘要不作为最终回答或复制内容，普通完整回复也须等准确 Run 完成后才取得最终回复资格。问题回答完成后可在轻量回执中展开查看。

工具明确失败时，该工具行的图标、名称、目标和箭头使用异常红色，悬停或展开后保持；末尾不再显示重复的“失败”标签，读屏仍可识别失败状态。聚合标题保持普通颜色，不因其中某项失败而变红。结果未知、等待和审批拒绝等准确提示继续分别保留；完整异常内容通过点击对应工具展开阅读，不跟在工具消息后。聚合内的 Shell 也可点击命令查看输出，收起聚合后再打开会保留先前展开选择。

网页工具以地球图标、“读取网页”和网站／路径呈现，不显示内部 `web_fetch · 1` 版本名；行内地址省略协议、查询参数和片段，过长路径截断，悬停可查看完整的网站／路径。只有能核实原调用与支持版本时才显示对应目标，不从网页返回内容猜测。读取成功后不展示网页正文，也不提供正文展开入口；Agent 仍可使用原工具结果。失败时仍可展开原原因；网页超时会显示中文说明，并保留准确 `web_timeout` 代码，不据此推断具体网络或解析阶段，也不自动重试。

自动批准完成后，工具详情不再显示通过理由，即使该工具随后失败或结果未知，也只展开实际执行异常；批准事实继续由原盾牌图标及其提示表达。自动拒绝、等待人工和审批结果未知的原因仍可阅读，已保存的授权记录保持原样。

在另一空间的已有会话发送时，直接按原会话ID提交，不要求切换当前项目，不关闭配套服务，也不停止其他空间任务。新会话属于所选空间，已有会话按持久空间身份执行；授权、模型和草稿继续分别隔离。明确退出、显式取消及真实工作目录冲突仍按各自规则处理。

通用 Native 的独立操作失败遵循上文 Toast 临时提示约定，提示关闭或到时后清除。会话因执行权失效而不可继续时，仍需区分被占用、清理未完成与外部结果未知；实际恢复入口和取得资格见[Native owner](../../../../apps/desktop/README.md)。核对原效果不发送输入框草稿，旧执行结束缺少证据时不能以重发消息代替核对；详情见[恢复语义](../../features/recovery.md)。

原 kite-desktop 的 Git 切换会影响其项目配置加载，需要在所有空间任务结束后重启配套服务，不自动取消任务。通用 Native 的新对话切换与配置冻结遵循上文当前入口约定；普通项目选择和发送消息不关闭 Service。

Ask 请求出现时，消息列表立即显示“询问用户”工具记录和问题，等待用户回答；回答或取消后在同一位置更新。Ask 历史保留唯一可展开工具记录：单题标题展示“询问用户”和问题，内容为“回答：”及答案；多题标题展示“询问用户 · 已回答 N 项”，明细带有序前缀，每项按“问题：回答”展示。取消后内容只显示“已取消”。内容与标题文字对齐，换行对齐前缀后的正文，每项最多 5 行，超出截断，连续字符自动换行。仍按 toolCallId 去除重复工具记录，不展示结果 JSON。

Shell 输出已确认截断时，状态区显示“输出已截断”；尚未取得完整输出时不将空白解释为成功且无输出。启动受理只显示已受理，等待超时与命令仍在运行分别表达，停止请求保留等待结束的状态，不能据此宣称后台命令成功或已停止。自动审批期间拒绝或停止且没有派发时只保留对应审批状态和可展开原因，不追加“未执行”；实际执行后的输出、失败、超时及结果未知保留。命令全文尚在读取时可显示明确标注的命令摘要；工具结果先于模型调用记录到达时，仍按准确工具原输入读取命令，保持原卡片和展开选择。无法核实时保留原记录阅读入口。

可展开消息的箭头紧贴标题内容（6 px），位于状态文字之前；收起时仅悬停图标与文字组成的紧凑标题区或键盘聚焦时显示，展开后持续显示。文件修改的文件名与 diff 按钮保持独立操作；不可展开的读取不显示箭头。轮次过程有独立折叠控制，箭头紧跟状态与耗时，思考正文不提供展开入口。“用时”等轮次状态仅在鼠标悬停文字区域时变亮，右侧空白、按钮内边距和箭头不触发文字高亮；展开后移开文字也恢复原色。可折叠标题保留键盘聚焦提示，静态耗时仍不提供点击动作，轮次摘要不因成功、失败、停止、中断或等待恢复改变颜色；过程内具体工具和重连行仍表达其真实状态。点击“用时”收展时，过程高度和后续正文的留白同步过渡，不先跳动再收起；系统启用减少动态效果时一同直接切换。

思考状态只在活动 Turn 底部回复状态行用简短“正在思考…”表示；正文或工具活动到达后切换为“正在回复…”，准确终态后移除。客户端不展示思考正文，也不把思考段时间当作整轮处理耗时。

阶段说明、工具与最终回复的间距由同一轮的外层布局维护；隐藏的思考内容不占用消息间距。

本轮回复异常失败时，简洁原因保留在原轮次的处理过程内，重连耗尽时可展开原重连行阅读原因与建议；收起过程后只保留中性用时摘要。普通开发与正式客户端不展示内部错误码或技术诊断；相关诊断只供隔离测试制品。缺少分类信息时通过Alert明确说明无法确认原因，并给出检查模型连接、配置及已执行工具结果的建议，不再显示笼统的消息保留提示；模型默认重连按前述认证／权限例外和5次上限执行。

工具消息展开后，标题文字、图标和箭头持续高亮；收起后恢复默认辅助色，悬停和键盘聚焦仍可高亮。详情展开与收起有短暂过渡；系统启用减少动态效果时直接切换。

工具详情在对应工具行下方原位展开。计划、验证和 MCP 发现／资源工具显示可读动作名；MCP 调用在已保存元数据核实后显示原工具名称，尚未核实或来源不可读时显示“MCP 工具”，仍可展开原结果。未知定义继续保留原名称；已知工具的未来版本不影响名称，但不套用尚未支持的结构化结果格式，也不根据正文猜测分类。

在展开的输出或文件差异中按 Home／End，首／尾内容应同时进入外层阅读区的可见范围；无需再寻找被聚合区域遮住的最后一行。此操作只改变阅读位置，不执行或重跑工具。

“列出目录”未指定路径时，工具行显示 `.`，表示工作区根目录；显式指定的路径沿原文显示。只有能核实原调用及工具版本时才补默认目录。

源码与打包版使用同一正式会话入口，不再按代码目录或 epoch 自动分库。已验证来源会自动整理；`STORE_INCOMPATIBLE` 表示未证明可安全读取的格式，`STORE_ACCESS_DENIED` 提示检查数据访问权限，`STORE_CORRUPT` 表示数据库或已识别结构校验失败，`STORE_INSUFFICIENT_SPACE` 提示释放磁盘空间后重试。原数据不会因这些检查失败而被清空或替换。

启动失败且Service提供了有效诊断时，可点击“保存诊断”，在系统文件对话框选择新的JSON文件。报告只包含错误分类、准备阶段、格式版本与处理提示，不包含会话内容、目录或原始服务输出。取消选择不会写文件；已有文件不覆盖，保存失败时选择新的文件名重试。迁移期间会显示阶段；确认其他客户端或整理流程占用存储时先自动等待，最长10秒，占用解除后在当前窗口继续启动，超时再提供重试。应用菜单中的退出先请求安全退出，发布前在安全点取消，发布已开始则在后台等待结算；新对话的分支读取／切换和打开文件的启动请求也纳入退出收尾，不继续启动新的请求。确认退出后立即关闭可见界面，后台保留原网页、租约及清理与恢复资料，服务释放及退出确认后销毁窗口并结束主进程，不再确认。普通窗口关闭仍按原行为隐藏窗口；请求退出本身不表示取消已完成，已打开的外部编辑器仍由系统管理。

正式 Native 的会话内文件写入／编辑行可通过文件名旁的独立箭头展开“本次操作差异”，只读取原成功回执，不以右侧 Git 工作区视图或当前磁盘补造历史。新建显示新增行，编辑显示删除／新增，内容不变明确标注。完整历史版本保留在独立的“查看本次交付的文件”入口，不盖过差异。正文只在展开时读取，预览最多400行、每行2048个UTF-16单元，并保留最多64 KiB的预览预算；省略和截断明确提示。超过1 MiB的历史全文不整份加载，已保存的完整Artifact不改变。旧记录未保存差异时保留操作与可用路径并说明原因。关闭和切换只结束读取，输入草稿和实际执行保持。原来源属于另一项目或不能确认当前项目时只读历史，不提供编辑器按钮。常规中的编辑器选择已接历史文件操作路径按钮，当前 renderer 默认 VS Code；消息正文和已核实的文件读取／写入／编辑行也已接原路径入口，打开当前项目文件；跨项目历史、子详情或未知格式只读。缺失目标通过可读临时消息告知。常规摘要显示当前项目的配置默认模型，无会话和新对话准备页显示用户默认；临时会话选择和活动轮次保持各自语义。macOS 新 Native 的原面板与消息入口首次/冷读、常规摘要、作用域校验和选择已取得有限证据，实际外部编辑器窗口的重新验收范围仍保持上文所述；准确边界见 [Native owner](../../../../apps/desktop/README.md#原文件变更面板与编辑器)。

离线备份恢复后，原会话和已封存分支的成功文件历史仍可阅读，原差异保留原始出处，不随当前磁盘的独立编辑改变。历史文件操作、工具行与普通消息的路径仍可打开已重新确认属于同一项目的当前文件；来源属于另一项目或无法确认时保持只读。阅读和关闭不重跑原文件操作，打开当前文件也不会恢复历史内容。当前恢复读取与目标资格已有真实 Main/HTTP 消费者证据；整窗口恢复点击、实际外部编辑器和跨平台资格仍按上述范围核对。

## Agent 浏览器

普通网页网络加载失败时显示浏览器式错误页，保留地址栏和导航。DNS、断网、连接、超时与证书问题给出对应的可读建议；点击“重新加载”只重试当前页，Agent控制中须先接管。证书验证不会被错误页跳过。更正地址或重试成功后返回正常网页，失败历史与网站自身的错误页面仍按原浏览器导航保留。

网页加载及首帧等待不另设应用倒计时，由浏览器引擎报告加载结果。页面较慢时继续显示加载状态，引擎真正报错后再显示失败页；不会仅因等待超过固定秒数显示“网页显示尚未确认”。应用界面布局尚未对齐时也继续加载，布局恢复后继续显示原网页，无须刷新。主动停止加载后，已就绪的原网页继续显示；尚无可显示文档时显示“已停止加载”，可以刷新或输入新地址，不显示加载失败。Agent结束控制不取消普通网页的展示等待。切页、收起、导航或关闭时，旧展示等待随对应页面和窗口生命周期撤销，不刷新或重放原导航。

网页内容区统一使用直角边界。拖动右栏左侧分隔线调整宽度时，网页随当前分栏更新，保留原页、表单与阅读位置。Windows下分隔线和拖拽把手随原生网页一起移动，鼠标及键盘调宽继续使用原分隔线；实际平台验证范围见下述Desktop owner。

2026-11-03 已修正Windows下网址和标题已更新、正文仍一直转圈的问题。新源码在窄栏可正常显示网页，收起再展开及切换标签保留原页和表单；已有开发窗口需完整重启，普通Native需重新构建。当前已实测隔离Windows生产模块与百度首页，安装制品和完整跨平台体验仍按[Desktop owner](../../../../apps/desktop/README.md#固定-renderer-布局收敛2026-11-02)的限定范围理解。

2026-11-09 已进一步修正新外壳留白布局下的同类转圈问题：网页按实际外层和分栏边距显示，不要求外层贴满窗口；收起再展开、切页和调宽继续保留原网页。Windows隔离实窗已核百度窄栏显示及同页恢复、调宽；开发客户端需完整退出后重启，普通Native需重新构建。其他平台与完整安装资格仍按上述实际验证范围保留。

统一入口候选已实现，最新修复的完整实机验收仍在进行：`computer-use` 是产品内置的全局技能，不需要安装到项目或用户技能目录。新 Native 网页任务按需加载它，经一个受控执行入口使用普通网页标签；没有页面时按任务创建，已有准确目标则复用。三种权限模式下，浏览器操控均不经过自动审核或用户审批，也不需要手动点“交给 Agent”。准确页面、任务、控制权与硬能力限制仍核实。登录、验证码等需要用户处理时结束本轮自动化并正常回复说明，不创建人工等待。

Agent 可在后台继续，切换会话、收起侧栏或隐藏页面只改变观察；用户仍可对实际受控页面暂停接管、明确继续或停止。正式截图通过原工具图片通道交给模型，侧栏预览本身不等于模型视觉输入。模型观察、控制状态和冻结注释分别调度；读取刷新不应造成工具栏反复切换文字或抢回前台。普通脚本错误、已知的参数／过期引用／读取失败只停止当前批次；已取得的页面和变量保留，模型可重新观察后继续剩余安全步骤。工具失败和已保存的未知会交回模型说明，回复完成不表示未知网站效果已确认；取消、交还或执行环境无法安全复用时仍结束自动控制，明确停止任务仍终止整轮。旧显式浏览器配置与已冻结任务保留原入口。当前验证与未完范围见[Desktop owner](../../../../apps/desktop/README.md#统一浏览器入口候选2026-10-28)和[实施方案](../../../plans/2026-10-28-browser-computer-use.md)，下文独立兼容面板按其实际范围理解。

网页控制与页面选项菜单在原生网页上方显示，打开菜单不抓图、不隐藏网页或将内容区换成占位；显式进入注释仍沿独立的冻结画面流程。接管／停止按准确任务与控制状态受理，导航在途时也可请求撤销新的自动化操作，在途效果单独核实。缩放窗口时网页跟随实际分栏，已有标签的后台核对不会额外挤占内容高度。原版macOS连续缩放曾出现网页保持旧宽度、灰边或黑空，稳定后恢复。当前Apple Silicon开发客户端与新构建Native候选已接入同版本合成修正，本机真实标题栏双击及连续拖边的限定过程未重现旧灰边或明显分栏错位；原页、表单和阅读位置保持。既有运行窗口需重启，旧Native制品需重新构建才包含修正；其他平台及完整过程体验仍按实际证据理解。当前原生菜单和同步量测实现及实机资格归上述Desktop owner，不以定向回归替代全过程验收。

## Native 的扩展能力

当前正式Native可在主会话的“会话工具→扩展能力”展开已注册扩展目录，按动作提供的表单填写并执行，或明确查询已保存结果。动作显示原命令的受理与实际执行结果；已受理表示仍须核实执行。结果未知时“查询原命令”只查该次申请，冷启动也可从已保存的原命令查回。确定结果后点击“新动作”才开始下一次明确申请；需要新业务标识的动作由用户填写，不能复用未知申请自动重跑。

通用结果显示完整内容、类型／版本、附件引用和扩展提供的原结果动作。查询、刷新目录、收起面板和切换会话都只影响阅读，不启动模型或取消工作。刷新期间保留上次完整结果供阅读，其动作待重新查询后才可使用；失败或迟到的结果不能改绑到新会话。换Store恢复的旧申请保原身份，不能自动成为新Store的执行许可。可用动作继续遵循当前宿主的权限、工作区信任和准确执行定义；没有注册或没有权限的能力不能由页面补造。参考mini-review只用于明确测试装配，不是默认产品功能。实现与已验范围归[Native owner](../../../../apps/desktop/README.md#native-公共扩展完整能力)。

## 开发 Native 的文件检查点恢复

新 `apps/desktop` Native 入口在当前主会话提供“文件检查点”面板。先按需读取目录，再读取所选点的当前文件预览与准确会话边界；仅会话、仅代码、代码与会话三个范围必须明确选择和确认。仅会话生成新会话而不恢复磁盘；仅代码保留当前会话与选择，仍单独展示普通恢复动作的人类审批；代码与会话先恢复代码，只有核对原代码成功后才出现“明确继续原会话分支”，不会自动执行第二步。

两步的原申请身份在第一次提交前全部保存在当前 Profile。退出、崩溃、读取取消或回应丢失后，“查询原恢复”只核对原 Command/restore ID，不重发写入、不另建 ID。代码成功但分支未知时保留两种事实。明确继续前还会重新核对原检查点的完整当前文件预览，所有文件必须仍是已确认的恢复结果；独立编辑或随后完成的写入会拒绝继续，原代码成功记录保留，分支尚未执行。读取和提交之间没有对独立编辑器的全局锁。换 Store 恢复的旧申请保留原来源，作为只读历史，不重标或自动取得新 Store 执行许可。

切换 Session、修改范围或标题、隐藏面板和关闭读取都会使旧观察失效，迟到响应不能覆盖新页面；已提交的申请继续按原身份保存。完整文件来源、媒体、保护路径或当前后像无法核实时，代码恢复可能不可用或冲突；准确的会话边界可以独立成立，不因此授予文件或媒体访问。当前范围已由实际 macOS default Service、Node SQLite 和 Electron 开发制品验证，测试和剩余制品边界见 [Desktop owner](../../../../apps/desktop/README.md#native-files-检查点恢复)。正式 Native 已消费同一公共恢复能力；只读 Web 保持阅读入口。

通用 Native 已接入上述四类 Provider 的设置、手动模型名称与显式空名称发现，以及每个 Session 的下一次模型和临时思考选择。新模型先禁用，启用后才进入输入选择器；默认模型也允许禁用，后续运行按启用状态准入，不自动替换默认引用。活动 Run 的模型与档位保持原值，普通引导不携带新模型或档位。新 Session 首次输入才保存模型路由，冷启动保留原 Session 路由，临时档位回到服务配置。提供商保存仅显示简短成功或失败反馈，不展示历史提交结果。已发布后的刷新失败与写入未知分别处理；未知保留简短提示与原提交查询入口。完整行为见[模型与配置](../../features/models-and-configuration.md)，当前本机窗口证据与限制见[Native owner](../../../../apps/desktop/README.md#native-provider-与下一次模型选择)。

正式 Native 的 MCP 设置已接入来源、认证、连接与完整工具详情：先核当前会话，再明确选择范围、审查来源或已有凭据引用，连接与工具各自审批。当前macOS正式窗口已核两范围来源操作、连接与重连、完整工具正文、下一Model schema和一次效果。建立失败且可靠停止时，查询原申请可确认本次未建立，再独立新申请；原证据不完整仍未知，不自动重发。macOS默认Chrome和系统凭据库的登录、刷新、清除、撤销、取消登录及重启恢复组合已实际验收；测试使用本机自有认证服务，不承诺其他平台或任意外部服务兼容。本机局部设置方案已收束，实际行为、正式消费者与本轮完整回归范围由[Native owner](../../../../apps/desktop/README.md#native-mcp-完整设置)维护；完整平台与整体阶段门禁保留，上文旧客户端的 MCP 描述继续定义迁移预期。

开发分支的统一浏览器候选把网页操作集中在普通网页标签顶部的单行工具栏。打开或收起网页使用会话标题栏现有的“标签页”图标，不另设“浏览器”文字入口；切回会话后，同一受控页面仍沿原范围恢复到标签栏。已有任务的控制状态菜单提供暂停并接管和停止，不提供无任务的“交给 Agent”预授权按钮或人工继续步骤；“页面选项”只提供浏览器导航、失败详情与重试，按紧凑操作行展示。收起右栏或切换页面会取消原菜单；失效菜单请求按取消处理。菜单本身失败时保留原网页，并在原菜单入口显示可重试提示。尚未导航的新标签页在下方内容区显示起始页，保留“工具／变更”等入口；它们不放进浏览器工具栏，也不另加标签栏按钮。打开真实网页后，起始页工具消失，内容区只展示网页。窄栏把后退／前进收入页面选项，保持网页区域尺寸；空白页无可用选项或尚无受管页面时，不显示空菜单和不可用的注释按钮。打开“指向注释”后，画面只显示快照与选区，“网页注释工具”在同一工具栏中提供指向、状态和备注编辑；返回网页或隐藏标签会关闭菜单，未提交的备注仍按原规则保留。接管、等待或错误提示不在已打开网页区域插入按钮、说明栏，也不增高工具栏。同一会话普通后台刷新不反复插入页面恢复文案；真实切换或读取失败仍需核实页面。网页刷新沿用加载图标，不显示“会话已变化”“状态已变化”“原操作未发送”等临时提示；页面选项和控制菜单中过期的操作也不追加这类文字。真实加载失败和菜单故障仍保留原说明及重试方式。

新对话尚未发送消息时，也可以新建标签并手动浏览网页；无需先创建空会话。切到已有会话会隐藏准备页的网页，返回新对话时恢复原页及其输入。准备页的网页不会自动取得 Agent 控制权。在新标签页输入首个网址后，等待网页显示时使用常规加载动画；空标签仍显示原起始内容，导航期间仍可停止。网页和工具栏准备完成后再交接，失败沿原可读提示处理。准备失败时显示可读说明，保留实际网页，不自动刷新或重开。切回已打开的网页，或关闭当前网页回到邻页时，保留准确原页并准备目标画面后交接，不刷新网页或用其他同网址标签代替。快速改变选择时，旧准备不能带回旧页；真正关闭的标签仍销毁，最后一页关闭后收起右栏。同一会话切换已加载网页时，工具栏保持稳定；地址、加载状态和前后退能力按目标网页更新，不因切换额外闪暗。原页表单与导航状态按原页面保留，实际开发制品的连续画面及剩余限制见[Desktop owner](../../../../apps/desktop/README.md#固定-renderer-布局收敛2026-11-02)。

拖动聊天区与右侧网页栏之间的分隔线，可以收起右栏。拖到折叠位置时，网页及其工具栏随右栏隐藏，页面本身保留；再次点击“标签页”展开时继续原页。收起侧栏不会关闭网页标签或刷新网页，也不会停止仍在执行的浏览器自动化。重新展开已有网页标签时，侧栏沿统一的180毫秒缓出动画恢复宽度，系统启用减少动态效果时直接切换；准确原文档和显示尺寸仍可确认时复用原生页面资源，并重新确认展示与输入绑定，不能确认时显示常规加载动画。隐藏与重新显示不使旧截图坐标或页面引用重新有效。

切换会话时隐藏并保留原网页；返回后按该会话的侧栏状态恢复，不播放跨会话的收栏动画，也不会把切会话当作手动收起。用户主动收起的侧栏仍保持收起。

Cmd+W隐藏窗口后，从Dock重新打开会重新确认并显示原网页，保留原标签、表单和阅读位置，不刷新或重新导航。当前 macOS 原生浏览器会按侧栏和标签意图核对实际显示；原页仍在但显示绑定丢失时，自动重新建立该原页的展示，旧截图坐标先失效。恢复失败保留可读说明，不循环刷新或重试业务动作；实际短暂过渡与平台限制仍以Desktop owner的对应制品记录为准。

返回已打开的网页时，界面保留准确的原页资料，不再将它当作空白新标签展示“工具”起始区；网页是否已显示仍以本次实际交接为准。关闭当前网页回到主界面时，先完成目标界面的绘制，再关闭网页；准备失效或关闭结果无法确认时显示可读说明，不自动重发关闭操作。连续画面是否仍有短暂暗空及残片，以 Desktop owner 的对应制品记录为准。

开发分支中，内置浏览器在工作区内修改、Auto和Full模式下都不经过审核或用户审批。页面接管仍绑定准确页面、目的网址、当前任务及现有登录状态范围，硬能力、取消和结果未知的约束保持。新消息继续旧页时先取得本轮的新候选句柄并观察。同一轮发现目标已关闭、不可访问或地址变化时会给出可读说明，不借恢复自动刷新、替换网页或重放动作。新的明确任务给出网址且原页已确证不存在时，可以合理新建页面；它具有新的页面身份和观察，不能沿用旧引用。普通页面或页面文字不能补造权限，也不能把当前任务扩为任意网站或账户操作。

开发版界面热更新和界面整页重载都不应刷新网页。Main仍持有准确原页时，网页的表单、导航和阅读状态按原页面保留；界面重建须重新核实展示与操作范围，旧的截图坐标和控制引用不能沿用。整页重载期间可出现应用加载状态；只有原页及原显示位置仍可确认时才继续显示真实网页，否则先暂隐再重新建立显示。Service重启会重新建立后端与本轮观察，不能重放旧动作；Main进程重启会销毁其WebContents，不能声称原网页文档仍存活。实际客户端、连续画面及其限制归[Desktop owner](../../../../apps/desktop/README.md#统一浏览器入口候选2026-10-28)。

旧显式兼容流程曾支持Agent明确说明卡点并交还人工，返回请求后继续不依赖网页的工作。新Native任务采用上面的正常final／新消息流程，不注册该人工等待。历史流程中，网页在人工控制下禁止Agent操作；用户完成后点“继续并通知 Agent”，确认交接后将关联结果送给仍活动的原任务。请求过期或原任务结束时提示需要新指令，不因沉默或迟到回应自动抢回页面/新建任务。当前macOS隔离Native已使用真实gpt-6-luna／low验证同页填写、蓝光与光标、程序化输入屏障、交还后的人工输入、等待期间独立工作，以及回应准入后切会话、原任务收到一次关联结果再操作和正常停止。准备期间切走会拒绝旧观察，不能把一次按钮点击当作已经受理。物理键鼠／IME、完整备注取证与整体发布资格仍缺；此前选择变化、窄条画面和清理unknown也不因新范围通过而改写。准确证据与限制归[Desktop owner](../../../../apps/desktop/README.md#普通页面控制租约候选2026-10-27未发布)。
