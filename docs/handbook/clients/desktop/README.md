# 桌面客户端（开发中）

Tauri 桌面客户端已完成首轮本机接入与原生验收，尚未作为正式入口发布。[首版计划](../../../plans/desktop-client.md)保留完整目标；当前不能据首版范围推导所有功能已可用。

开发版可选择本地项目、确认工作区信任、使用已有本地模型配置、新建和查看最近会话、提交任务、读取文本与工具过程并取消执行。安装与运行方法见[开发入口](../../../../apps/kite-desktop/README.md)。

打开项目不等于信任项目；确认面板显示工作区及关联外部只读目录。会话内容按所属会话展示，输入草稿在当前进程按项目与会话保留；退出后的草稿恢复尚未提供。

关闭窗口保留应用与任务，再次激活显示原窗口；明确退出或断开项目会停止自有服务中的执行，已有修改不撤销。当前退出确认覆盖整个服务连接，尚未根据活动任务省略空闲提示。异常收尾会提示检查结果，不自动重发请求。

工具审批会显示具体命令与说明，用户可以选择“仅批准这一次”或拒绝；审批结果仍由服务核实。问题、计划等其余交互面板和模型设置写入尚未交付，遇到未支持的交互会显示限制，用户可取消。代码变更查看、外部编辑器跳转与高级恢复也尚未交付。

已有会话加载时显示进度，超时提供错误提示；明确重连会恢复所选会话与进程内草稿，不重发任务。切换项目会清除旧的选中会话和正文。当前会话目录按 profile 列出最近 100 条，跨项目目录展示仍将继续完善。工具取消或拒绝后的历史不再显示为进行中。
