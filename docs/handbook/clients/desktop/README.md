# kite 桌面客户端（开发中）

设置以全屏双栏页面呈现，沿用桌面主界面的当前主题与基础字号；宽窗口下设置侧栏固定为 236 px，不随主页面侧栏拖拽变化。左侧直接切换“常规”“提供商”“模型”“MCP”“Skills”，不提供设置搜索。返回应用与主侧栏新对话入口采用一致的单行按钮尺寸和悬停、聚焦交互，并紧邻设置分类；macOS 沉浸式标题栏下单独避开窗口交通灯，不让交通灯覆盖按钮。其他平台不增加该标题栏留白。“常规”显示默认文件打开应用和当前模型；编辑器选择只在当前页面进程内保留。返回应用关闭设置页，不修改任务或会话。参考图中的权限、语言及窗口行为等开关尚无对应设置能力，页面不提供这些控件。

> 已实施范围：[会话存储兼容性与连续性 V1](../../../plans/session-store-compatibility-and-continuity.md)已统一正式数据入口，并验证 macOS 已知格式的自动整理、历史来源归并和原会话保留。未知格式保留原数据，不切换空库；Linux 产品入口与 Windows 原生迁移资格仍待验证，具体边界见方案中的交付记录。


侧栏底部用户区通过上边框与空间列表分隔，用户按钮只显示单行“个人工作区”，不再另行显示“本地用户”；点击仍打开设置与主题菜单。

桌面客户端采用 Electron + React/shadcn UI + 独立 Kite Runtime Host。迁移实现和本机自动原生验收已完成，已验证流式执行、窗口隐藏恢复、刷新重接与正常退出；制品身份和剩余人工验证见[原生验收](../../../../apps/kite-desktop/docs/native-validation.md#electron-本机迁移验收)。

明确退出客户端时，只有存在排队、运行或等待用户交互的会话任务才显示二次确认；所有会话均空闲时直接进入安全清理并退出。任务状态无法完整核实时仍显示确认，避免误停任务。关闭窗口仍只隐藏客户端，不等同于退出。

退出先等待配套服务安全收尾；清理报错时会提示结果需要核对并允许退出，持续等待超过 20 秒时可选择继续等待或强制退出。退出检查、确认或清理期间再次明确退出也会走紧急退出。强制退出会尝试终止本应用拥有的服务进程；正在执行的任务和文件副作用可能尚未确认，下次启动后应按持久会话记录核对。

侧栏空间行只显示名称；会话行显示标题，并在最右侧用旋转图形表示 Run 仍在进行（包括受管等待必需子 Agent），用高亮圆角文字“待用户输入”表示等待回答、审批等交互，待输入优先于运行图形。受管等待的详情浮层使用通用“任务进行中”，不显示“等待后台结果”。空闲和正常完成不显示行内状态。会话数量、完整状态和更新时间在详情浮层中查看。浮层首次悬停 500 毫秒后出现；浮层出现后快速移到其他列表项会立即切换详情，移开一段时间再返回则重新等待。首次等待期间移开不会弹出。键盘聚焦也可查看，Escape 关闭。会话顶栏右上角的环境信息按钮控制“环境信息”卡片显隐，卡片默认展开，CSS 宽 300 px（2 倍显示比例的截图约为 600 像素），按 Shell／子智能体分组；卡片内文案使用常规字重。卡片停靠展开时消息阅读列和输入区最大宽度为 720 px，并为卡片预留右侧空间；会话滚动条始终保持在中栏最右侧。会话实际可用宽度不足 1092 px 时，停靠卡自动收起；之后即使宽度恢复也保持关闭，需用户再次点击。宽度不足时用户仍可点击按钮，以不压缩会话区域的右上角浮层查看；浮层打开期间宽度恢复则自动转为停靠卡。手动隐藏与自动收起均以短暂淡出、向右缩合和会话区域同步扩展完成；从其他主会话或子详情返回时直接显示卡片，不重新播放入场动画；系统启用减少动态效果时立即切换。除用户主动打开的窄宽浮层外，卡片不覆盖消息、工具输出或输入区。Shell 组显示新鲜、仍在运行或正在停止的执行；同一连接内返回已读主会话、正在核对新状态时，卡片暂时保留上次已确认的 Shell 和子智能体行并标明“上次状态 · 正在核对”，不提供停止操作。首次读取或没有可复用展示快照时，子智能体组仍保留已验证的全部子会话；名单已到但后台状态尚未匹配时保留详情入口并标记“状态待确认”。新鲜后台状态明确报告不可用时才标记“不可用”。有公开名称时只显示名称与状态，不附加执行 ID；旧记录缺少名称时才回退显示执行 ID。后台 service 与诊断字段不在该卡片中展示；上次状态只用于阅读，实时订阅与操作权限仍须重新核对。任一分组没有项目时显示对应空状态。

required 后台子 Agent 尚未终态时，Runtime 保持同一 Run 的受管等待及准确 task 关联；Desktop 侧栏保留通用活动标记；所选父会话的历史已加载、投影身份匹配且 Run 确认因 required 子 Agent 等待时，在消息阅读列末尾显示“正在等待子 Agent 结果”。这是随 Run 状态出现和消失的临时提示，不写入会话消息，也不把先前一段模型正文标为最终回复；最终回复只在 Turn 完成后确认。侧栏不另设等待徽标，输入框上方不设状态行，也不延续模型思考动画。子 Agent 的实时状态由环境信息卡片展示。此时输入框保持可发送；新文本引导恢复原 Run，不取消 child，也不创建第二个 Run。切换会话或刷新重接后，内部等待原因及关联 task 由持久投影恢复，不靠客户端轮询补正。after-turn 结果因已有用户活动 Run 而被 `human_start_preferred` 抑制时，只展示持久结果可用事实，不把结果伪装成已注入该活动 Run。

桌面与 Web 共用会话主页面；可用操作按各端权限提供。桌面保留本地项目、任务输入、审批与执行控制，Web 当前只读。当当前会话已观测到提示缓存 token 时，输入框底部工具栏显示该会话累计缓存命中率；无样本时不显示 `0%`，切换会话不沿用上一会话的指标。macOS 窗口采用沉浸式标题栏：同一个顶部 header 横跨侧栏和会话区，左段以实色背景层级放置侧栏收起图标，右段只显示会话标题和操作，并在会话页 header 底部显示分隔线，不重复显示所属空间；会话标题最多显示 10 个字符，超出时以省略号收尾，悬停仍可查看完整标题。侧边栏按浅色或深色主题使用实色背景，不启用透明窗口、系统 vibrancy 或 Liquid Glass。内容背景延伸到窗口顶边，原生交通灯、窗口拖拽及双击 header 缩放保持可用。窗口底层与页面使用相同背景色，快速拉伸时不应露出黑色空白。

迁移前的 Tauri 客户端曾完成首轮本机接入与原生验收；该记录只作为历史行为证据，不能证明当前 Electron 制品与窗口。桌面客户端尚未作为正式入口发布，[首版计划](../../../plans/desktop-client.md)保留完整目标；当前不能据首版范围推导所有功能已可用。

后续已确认以 Codex 的客户端功能和日常交互体验为对标目标，具体差距与迭代入口见[日常体验方向](../../../plans/desktop-client.md#首轮验证后的日常体验方向)。这是后续研发目标，下文仍说明当前已交付行为。

桌面客户端产品名为 **kite**，**kite-code** 为 TUI 名称；两栏界面、Electron 窗口与当前开发包均使用 kite。通用日常工作、shadcn/ui 界面及覆盖空间、会话、交互、结果、子代理、设置和恢复的整体目标稿见[界面与协作体验](../../../plans/kite-client-experience.md)，不据设计稿宣称这些能力已交付。

[工具消息结构与状态](../../../plans/kite-client-experience.md#会话消息与工具渲染)按 Runtime 提供的展示分类呈现：同组探索可聚合，独立工具保持独立；有明确子 Agent 归属的内部工具及异常只进入所属子 Agent 容器，归属随工具 queued 和 terminal 生命周期保留，因此只恢复终态时也不会产生顶层重复；缺少归属的旧异常仍保留独立入口，子 Agent 结果不会丢失。queued、running、waiting、completed、failed、rejected、cancelled 与 unknown 使用不同文字状态。Shell 的 stdout/stderr、退出码及输出限制按真实字段放入可展开输出，文件修改显示工具报告的差异；缺失信息时不补造。当前可读内容和交互限制仍以下文为准。

当前 Run 需要恢复时，其当前轮尚未结算的工具在页面上显示“需要恢复”，不继续显示“正在工作”。这是对 Run 状态的临时展示，不写入或伪造工具终态；Run 状态更新后以真实工具事件为准。

开发版在当前父会话的“环境信息 → 子智能体”和对应的子 Agent 工具消息中提供详情入口；子会话创建并进入父作用域列表后，无需手动刷新即可打开只读详情，重新打开已完成的父会话也会自动恢复完整子会话列表，没有匹配子会话的旧后台记录只显示状态。切到其他会话后返回时，先保留此前已核对的子会话详情入口，再静默更新名单；同连接重新核对或当前页断线重接时保留上次已确认的环境状态并标明正在核对，期间不能停止执行；已有条目不额外显示读取提示。没有可复用展示摘要时，名单先显示“状态待确认”；新鲜快照到达后更新真实状态与操作资格。父会话读取明确被拒绝或身份核对失败时，立即移除其暂存的子会话入口和环境展示；子详情明确返回不存在或无权读取时，从父会话名单移除该入口。详情复用主会话的消息与工具渲染，先显示独立历史，再持续显示子 Agent 的实时过程；进入子详情时脱离父页面的实时订阅，返回后重新校准父页面，期间服务端任务继续运行。已读过的父会话和子详情在同一连接内再次打开时立即显示有容量限制的已读正文，空历史也不重复显示整页加载；后台继续核对最新历史与实时订阅，失败时保留已读内容和重试入口。非当前页缓存淘汰后按首次读取处理；临时断线期间，已读主会话可从有界缓存继续阅读，切回时仍核对会话与空间身份，连接恢复后必须重新读取历史并校准。子详情的非当前页缓存随断线清除；当前子详情只保留已读内容供等待核对。缓存不赋予发送或子会话读取权限。断线重连期间保留正在阅读的子详情和已读子名单，不先显示空的父页面；名单待核对时不授予子详情读取资格。核对父子身份后才恢复该详情；用户明确返回父会话或切换其他会话时取消自动恢复，迟到结果不能再跳回子详情。子线程不进入侧栏顶层会话目录。子 Agent 列表仍可在环境信息中刷新，读取失败也可在原处重试。详情读取和订阅按准确父子血缘授权，面板内不能对子线程发送、停止或修改。此入口的正式运行验收仍见[后台 Agent 协调方案](../../../plans/background-agent-shell-conversation-coordination.md)。

Agent 邮箱状态依据当前会话的持久事件显示为独立状态行：发送方的“已受理，等待目标读取”不表示子 Agent 已读；接收方的“已准备进入目标模型输入”表示输入已绑定；续轮结果结算另有终态提示。重复历史记录更新同一消息状态，私有消息正文不出现在状态行中。

开发版可选择本地项目、确认工作区信任、配置 Provider 和选择模型、新建和查看最近会话、提交任务、读取文本与工具过程并取消执行。安装与运行方法见[开发入口](../../../../apps/kite-desktop/README.md)。

左栏默认以 200 px 最小宽度展开，可拖拽至 420 px；调整后的宽度在本机保存并于重启后恢复。拖拽分隔线把左栏收起后，顶栏显示展开按钮，点击可重新展开左栏。左栏保留已添加的项目，所有空间默认展开并自动读取会话列表；新添加的空间进入列表首位，之后切换执行空间只改变当前选择，不调整已有空间顺序。展开或收起只改变显示，不切换项目。工作台入口暂时隐藏；会话继续按空间出现在左栏，点击直接进入原会话，不创建副本或改变执行状态。各空间的会话可展开或收起，不提供会话标题搜索。点击会话直接加载消息，无需二次确认；上下键移动列表焦点，Enter 打开会话。切换会话不停止当前任务，也不会发出新消息；首次发送正在创建会话时，已有空间和会话导航也不整体禁用，用户切换阅读目标不会改变该消息所属的新会话。目录在连接和新建时自动读取；侧栏中已有会话的运行与待输入状态随会话索引更新，包括切到新对话、安排任务等非会话页面后完成的后台 Run，不依赖当前阅读页的订阅。各空间内会话按最新更新时间倒序排列，单纯点击阅读不更新时间；侧栏不再显示“切换项目”、“断开项目”和刷新按钮。返回已连接窗口只更新本地目录是否存在，不重新加载会话列表。其他端新建且尚未进入本地目录的会话仍需下一次目录读取才显示。

已加载且没有会话的空间在项目名称下方显示“暂无聊天”，并与项目名称的文字左边缘对齐。

“空间”标题右侧的 `+` 打开系统目录选择器，选中一个本地目录后将其登记为空间并进入该目录的新对话准备页；取消选择不创建空间。标题的添加按钮和空间行的新对话、移除按钮仅在各自行悬停或获得键盘焦点时显示；触屏设备上常显。空间行的两个操作按钮紧邻排列。新对话入口使用编辑图标，添加空间仍使用加号；操作按钮平时为次级文字色，鼠标移到按钮或键盘聚焦时高亮。空间行的移除按钮先显示原生二次确认，明确提示会停止该空间正在运行的会话、永久删除相关会话历史及本机项目登记，工作目录文件不受删除操作影响。默认选择保留空间；确认后由 Service 按空间身份中断运行、关闭被删会话的订阅并删除会话树历史，全部相关历史删除且服务端收尾确认后才移除本机登记。同一空间正在删除时，重复操作等待原删除结束后再试；超时或收尾失败保留项目登记，可在核对后重试。若正在显示被删空间的会话，页面关闭并停止接收该会话数据；重连和刷新也不会恢复已删会话页面。已经发给模型服务商的 HTTP 请求可能继续处理；本地执行停止且迟到结果不能再写入后，仍可删除空间历史。无法确认本地执行或工具副作用已清理时拒绝删除并保留记录。删除途中失败时提示已完成的删除数量；已删除的会话不会恢复。其他空间的会话与任务不受此次移除操作影响。

左栏提供“安排任务”入口，页面展示任务空态与列表契约；点击创建后，表单在页面最右侧的通用侧栏中打开，主区域继续显示任务页。表单包含名称、任务说明、项目、运行频率及独立 Git worktree／本地项目环境选择。当前 Service 尚未提供定时任务的保存、调度、运行记录或通知协议，因此保存保持禁用，页面明确说明限制；填写内容只属于当前页面草稿，不宣称已创建或会在后台运行。

已登记 Git 仓库在连接准备时直接授权 Agent 访问空间，不展示“信任此项目”或重试授权提示；用户主动添加或选择的普通目录同样视为访问授权，具体工具继续遵循执行授权。授权由 Service 保存。需要访问工作区外的关联目录时，仍单独展示确切路径并确认；授权失败时保留输入，不伪造成功。空间、Git 仓库、分支或命令失败不作为 notice 插入客户端页面内容，统一使用带单个“确定”按钮的 shadcn `AlertDialog` 告知，确认后关闭并清除本次错误。会话内容按所属会话展示，输入草稿、阅读位置和过程展开状态在当前进程按项目与会话保留；退出后的恢复尚未提供。会话切换不取消原会话执行。助手正文支持统一排版的 Markdown 标题、段落、列表、代码块、引用与表格，正文不增加内边距或独立限宽，与消息阅读列同宽；明确类型的连续读取／搜索聚合为轻量摘要，进行中显示近期步骤，完成后默认折叠；展开后以统一图标轨道和单行“动作＋目标”排列，不显示重复的完成徽标。读取不展开文件内容，Shell 可展开有界输出、修改可展开工具报告的差异；单条进行中工具直接显示一行，运行、等待与异常状态继续保留，组合工具标题只显示操作摘要，不附加运行、等待或异常状态；具体错误摘要只在展开后显示于对应工具项内。主会话只显示子 Agent 入口；子 Agent 的工具消息与步骤仅在该入口的过程容器内展示，列表最大高 320 px，超出时在容器内滚动，不常驻过程正文或结果段落；展开过程时不重复显示完成状态，失败工具的完整提示通过该工具行展开查看；子 Agent 已结束而工具缺少终态时显示“结果未知”，不继续播放运行中动画；有明确可见父工具时在该 task 展开区的子 Agent 容器查看，完成后仍保留；缺少可见父工具时保留子 Agent 容器入口，内部工具不进入主消息列表。独立子会话的只读详情从当前父会话的环境信息卡片打开，不能作为平级会话直接进入。

已提交任务执行失败时，会话中保留一条“本轮回复失败”提示，即使模型尚未生成任何回复。模型服务认证失败会明确提示检查当前提供商的凭据和账号权限；已分类的模型重试耗尽、服务不可用、会话存储不可用和工具纠错耗尽显示对应原因。缺少可靠分类时只提示检查会话失败详情和任务状态，不将后台任务、工具或 Runtime 错误推断为模型服务故障。模型给出的工具参数不符合当前格式时，该工具显示脱敏的参数错误，不展示原始模型响应。重新打开会话仍可查看失败记录。用户主动取消不显示为执行失败，读取历史不会重新发送任务。模型切换仍按会话保存的提供商和模型执行，不要求与设置中的默认模型一致。

发送与停止共用输入框右下角同一个 `26×26` 圆形主控位：消息准备与发送期间显示 loading 并禁止重复提交；失败或发送结果待确认时停止旋转。任务运行且草稿为空或正在停止时显示停止；输入运行中引导后切换为发送；两个动作不得同时出现。

任务运行或内部受管等待后台结果、且未等待用户交互时，输入框继续可编辑；发送运行中引导和停止操作保持可用，纯文本通过 `steer_turn` 追加到同一 Run。审批、补充问题或计划审核等真实交互仍独占回答区域并暂时隐藏主输入框。切换会话后，已保存为展开的工具详情直接恢复完整内容，不再播放一次展开动画；用户在当前会话中主动展开或收起时仍保留短暂过渡。

Ctrl+A／Cmd+A 在会话页面只全选消息内容，在输入框中只全选当前输入。会话消息支持原生选词、拖选与复制，段落和列表行选区限制在内容范围。侧栏、标题、按钮、提示等非消息展示文字不可选中复制；输入框保留正常的选择、复制与编辑能力。会话消息和左栏分别滚动；工具消息中可独立滚动的输出和文件差异在还有内容可滚动的边缘显示渐隐提示。首次进入显示最新消息；向上阅读后不再被流式更新拉到底部，可点击“回到最新消息”。输入框上方不展示独立状态信息，也不保留状态行空白；输入框底部工具栏集中展示按 Provider 分组的已配置模型，以及带有审批方式说明、图标和简短行为描述的权限模式菜单；模式名称与说明按系统语言显示中文或英文，不展示快捷键教学；选择文字与下拉图标使用固定间距。点击左下角“本地用户”按钮打开选项浮层，可进入设置，或在主题区域选择“暗”“亮”“跟随系统”。默认跟随系统；选择立即应用到主界面、设置与原生表单控件，并在本机保存，重启后恢复。跟随系统时，系统外观变化会自动更新界面；固定暗色或亮色时不受系统切换影响。Full 选项与已选状态的图标、文字以及风险弹窗标题使用警示色，确认按钮使用危险操作样式；桌面客户端每次从其他权限切换到 Full 前，说明 Full 允许代理无需逐项征得同意，在当前环境允许的范围内运行命令、读取或修改文件、访问互联网；提示文件被覆盖或删除、敏感数据传输及难以撤销的损失风险，并说明可以切回其他审批方式、系统限制仍有效；取消不更改权限，明确确认后才继续；点击当前已选中的权限不重复提示或提交。切换会话后，模型选择器先显示目录中该会话的模型，投影加载后再按最新状态更新；已有会话选择并确认权限后立即显示目标模式，保留静态下拉箭头，后台确认期间暂时禁用重复选择；服务端确认后落定，失败时恢复已确认模式。权限命令提交给该会话，按该会话所属工作区核对信任；即使当前正在查看其他项目或尚未选择执行项目，也不需要切换执行项目，不停止其他会话任务。修改历史会话权限不要求先恢复任务，也不依赖该会话原模型配置仍可用；修改成功不会启动任务或解除其恢复要求。若当前服务丢失执行权后仍保留旧会话 Runtime，需要重新启动服务后再修改，不会自动接管。另一服务进程持有该会话执行权时仍会拒绝修改，版本冲突需要读取最新状态后重新选择。若会话在修改期间被其他进程删除，本次修改明确失败，不按未知结果处理。工作区未信任或不可用时不修改权限；新对话的选择在创建会话后、发送首条消息前生效。没有活动人机交互时，输入框位于下方，Enter 发送、Shift+Enter 换行；空白输入和加载期间不能发送。任务运行但未等待交互时，输入框继续可编辑，Enter 把纯文本作为定向引导追加到同一 Run，不取消当前请求、不新建 Run；目标在提交前结束时保留草稿，不改投新任务。停止仍由独立按钮发起；提交后显示等待收尾，只有服务终态才显示已停止，已有修改保留。审批、补充问题、计划审核或其他等待交互出现时，主输入区隐藏，避免与当前交互争夺操作；交互结束后恢复原草稿。这不是新 Run 的后继队列。会话侧边显示后台 Shell、service 和子 Agent 的准确身份与状态；只有当前连接代次中新鲜且仍运行的项显示停止入口，断线后的旧运行项不可操作。

左栏品牌下方的“新对话”是与空间区域同级的全局入口；工作台入口暂时隐藏；尚未打开项目也可以进入并写下需求。欢迎区的四个建议只追加可编辑草稿、聚焦输入框并将光标移到新增文本末尾，不发送；首次发送时才创建会话并进入正常消息流，重复点击入口不会创建空会话或清空草稿。首次发送后输入框立即清空，内容区原位显示“正在发送”的用户消息；真实消息到达后在同一位置接管，失败则原位提示并把内容恢复到输入框供重试。准备草稿跨项目／分支选择保留，与已有会话草稿独立；切回历史会话恢复它原有的输入。发送失败后保留已创建会话，不重复创建。

空间标题右侧的“新对话”图标进入该项目的新对话准备页，不改变列表展开状态，也不提前创建空会话。选择其他空间时只校验已登记目录并读取该目录的 Git 分支，立即更新准备页上下文；不关闭当前 Service、不切换执行连接，也不读取项目列表、会话目录、信任或模型。左侧空间和会话列表保持原对象与交互状态，目标分支读取完成后一次替换。首次发送前才沿用现有执行项目切换流程；届时有活动任务会先确认停止，再激活目标空间并核对信任和分支，继续使用应用已经持有的模型目录与本次选择。普通非切换断线仍禁用会话导航。

预选空间不是当前执行空间时，输入区继续使用应用已读取的 Provider 目录和当前权限选择；模型与权限选择器不属于空间，切换空间不重新加载、不清空也不短暂禁用。模型选择只在准备页暂存，不修改当前或目标空间的默认配置。外部目录授权仍只在实际激活目标空间后读取和提交。发送前观察到分支或 HEAD 变化时采用当时的真实环境继续执行，不要求用户重复发送；只有用户明确选择了另一分支，才在首次发送流程中执行受控 Git 切换。会话一旦创建就立即绑定该身份；随后权限设置明确失败或回执未知时恢复草稿并在同一会话核对或重试，不再创建第二个空会话。用户取消停止旧任务和切换空间时同样恢复准备草稿并重新开放发送。

输入框聚焦不增加额外边框，右下角没有手动调整尺寸的拖动柄；多行输入由内容撑开。发送与停止使用同一位置的图标按钮，悬停提示和可访问名称说明当前动作；停止提交期间保持禁用，避免重复请求。

已发送的用户消息可逐条复制；Agent 复制按钮按 Runtime `turnId` 归属，同一 turn 内只在没有后续工具调用的最终回复下显示一次，并只复制该完整最终回复，不包含同轮工具前说明、思考、工具、子 Agent 或其他非最终文本。用户气泡和 Agent 最终回复与后续内容的间距为 32 px；非最终回复到后续工具保留 8 px；思考或工具记录到下一段非最终正文统一为 8 px，到最终回复为 16 px，工具组内保持紧凑。悬停消息或用键盘聚焦可显示复制按钮；成功时显示较大的勾，两秒后恢复复制图标；发送状态未定、失败或流式回复不提供复制。Agent 正文下的“正在回复”在最终回复落定后移除。发送回执未知时保持“待确认”并阻止重复提交，等待新的运行时事实或显式会话恢复。

新 Run 在持久提交前明确遇到 revision 冲突时，客户端可重新读取投影并且仅重提一次；刷新后已有活动 Run 则保留草稿，不自动改投为 steer。这不改变回执未知时禁止自动重发的规则。

输入框上沿以无底色的紧凑上下文条选择已打开项目或添加本地目录，Git 仓库旁边直接显示真实分支，不重复展示固定的本地环境提示；非 Git 项目完全不显示分支选择器，仍可正常发送。Git 只是空间的可选能力：`.git` 标记无法确认、Git 未安装或 Git 探测失败时按普通空间继续，不阻止创建对话；只有用户主动执行分支操作时才要求 Git 能力可用。上下文条与输入正文共用左侧视觉基准，只承担轻量元信息层级，不作为独立大卡片与输入框争夺视觉重心。选择项目或已有本地分支后立即生效；切换分支时有运行、排队或等待中的任务，或存在暂存、未暂存、未跟踪的改动，都会阻止切换。不会自动提交、丢弃修改或创建 worktree。分离 HEAD 和尚无提交的仓库显示真实状态；只允许在仓库根目录切换分支。分支菜单可以刷新，失败或回执未知时检查刷新后的实际状态，不自动重试。

应用启动先显示独立启动页，完成本地服务连接、首屏空间会话目录及当前项目的准备检查后再显示主界面，不展示主界面逐项加载的过程。服务连接或首屏目录全部读取失败时，启动页显示原因并提供“重新尝试”；空目录可以正常进入，局部目录失败、项目失效或模型未配置不阻止进入主界面处理。启动页没有人为最短停留时间；进入主界面后发生断线仍保留页面与草稿，不重新遮挡为启动页。

应用重启会恢复已打开项目列表并自动读取应用历史，不创建会话或发送任务。项目目录失效、Git 不可用或模型配置错误不妨碍阅读已有历史，各自显示局部提示。发送前核对目录、信任和模型；普通资料文件夹无须 Git。本地服务的启动、连接与恢复由客户端内部负责，不提供重连或断开操作，内容页不展示连接中断或服务未就绪提示。内部恢复期间保留会话内容与草稿；侧栏会话点击立即改变阅读选择，连续点击只恢复最后选择的会话，不等待旧会话完成连接才响应。已选会话在校准期间仍显示阅读页，不误显“新对话”欢迎页；发送、停止与审批继续等待新连接就绪。操作结果未知仍会明确提示检查实际效果。未发送草稿不承诺应用重启后恢复。

关闭窗口保留应用与任务，再次激活显示原窗口；明确退出或实际切换执行项目会停止自有服务中的执行，已有修改不撤销。只有存在活动任务或任务状态无法核实时才显示退出确认；清理失败或长时间等待时提供紧急退出。异常收尾会提示检查结果，不自动重发请求。连接断开后不能使用旧的就绪状态提交操作；回执丢失时显示“操作提交结果未知”，自动恢复后仍应检查会话及实际文件，再决定继续。

工具审批会显示具体命令与说明，可以选择“仅批准这一次”或拒绝；结果仍由服务核实。补充问题使用紧凑的 Questionnaire 展示单选项和允许的自由回答；一次请求包含多题时可通过上一题／下一题自由查看，最后一次提交全部答案，每条答案以 `q1`、`q2`、`q3` 题目 ID 保留协议归属。选项提交同时保留内部 option ID 供校验与恢复，但交给 Agent 和历史摘要的是选项文案；自由回答保持用户原文，不把 `q1-o1` 等内部编号当作语义答案展示。选项不常驻显示字母顺序或详细描述；有描述的选项在右侧显示 info 图标，鼠标悬停或键盘聚焦后显示该选项的标题与完整描述。第一页只显示下一题，最后一页才显示提交回答；可以在当前题未答时先查看后续问题，但尚有任一题未回答时提交按钮不可用。交互块不使用内部滚动条，完整内容直接占据底部布局并让会话阅读区收缩。取消回答会把取消结果交给模型，模型仍可继续；当前交互期间不提供停止按钮。计划面板显示正文与步骤，支持 Accept Edits/Auto 批准、修改要求及取消；正文缺失或超过显示上限时不能批准。扩展或验证交互仍显示限制，用户可取消。高级恢复尚未交付。

补充回答和计划修改意见在当前页面进程内保留：切到其他会话、新对话或安排任务再回来，可以继续编辑原文。它们与主输入框草稿分开，也不会带入其他会话或下一道问题。提交失败保留输入，确认提交或取消成功后清理对应交互的草稿；完整页面刷新和应用退出后不保证恢复。

点击顶栏“文件变更”打开页面最右侧的通用侧栏，展开文件操作可阅读成功文件工具保存的差异或写入内容。最右栏与左侧导航在展开、收起时以短暂的实际宽度过渡推移中间会话区，并保留用户最近拖拽的栏宽；系统启用减少动态效果时立即切换。最右栏与左侧导航、中间会话区同为全客户端高度的同级栏，三栏相邻边界均可拖拽调整宽度；会话侧栏使用标签页结构，当前只有“文件变更”一个有事实支撑的标签。关闭或 Esc 返回顶栏按钮，切换会话自动关闭，输入草稿保持不变。这不是当前工作区 Git diff，也不覆盖 Shell/MCP 等工具未报告的逐文件修改。输出可能截断，空列表不代表磁盘没有变化。在设置中可选择 VS Code、Zed 或 TextEdit 打开当前项目内仍存在的文件；同一选择也用于消息中的路径链接和读取文件路径，默认 VS Code，在当前进程保留。打开的是当前磁盘内容，编辑器需已安装。迁移前 Tauri 版本曾在本机 macOS 确认 VS Code 实际打开；TextEdit 仅确认启动分发，Zed 未安装。Electron 版本的实际编辑器窗口仍待重新验收。

首次打开或缓存已被淘汰的会话显示加载进度，长历史分批读取后完整展示。已保存的正文先于实时连接校准展示；实时状态查询或订阅失败不会挡住已读历史，也不会使任务自动重跑。实时校准完成前可阅读、复制和编辑草稿，发送、停止与审批保持不可用。已打开的会话若出现实时消息缺口，会保留正文并自动补读历史；消息补齐且实时订阅重新就绪后才恢复操作，补读失败仍可阅读并重新加载，不会自动重发任务。首次发送选择的权限模式与当前一致时保持原模式并继续提交。同一连接内再次打开已缓存会话，立即显示上次正文并恢复阅读位置和展开状态；空会话也会缓存。后台仍会完整校准历史，期间可以阅读、复制及编辑草稿，发送、停止与审批等操作等待校准成功。校准失败保留已读正文并提供“重新加载会话”；明确不存在或拒绝读取时清除正文。缓存容量有限，超长会话离开后可能需要重新加载；非当前会话缓存不跨连接重建、页面刷新或应用重启保存，普通断线仍保留当前正文供阅读。每个空间的目录默认读取并返回全部会话，不提供手动加载更早会话的入口；页面按最新更新时间从新到旧排序，默认显示前 5 条，点击列表末尾辅助文字色的“展开更多”每次再显示 10 条，最后不足 10 条时显示剩余会话。收起空间后再次展开恢复为 5 条，其他空间不受影响。一个空间读取失败不清空其他空间。点击其他空间的会话直接阅读，不停止原任务；在已有会话发送时按原会话身份路由，不切换当前执行项目，也不停止其他会话任务。本地目录不存在时，空间名称变浅，仍可打开会话，不常驻提示目录关联情况。已有会话继续发送不以本地目录存在、Desktop项目登记或当前选中项目为前提。服务按会话持久身份与既有授权执行；原目录被删除时仍可对话，依赖该目录的Shell和文件工具在实际调用时返回错误，不自动创建目录或改用其他目录。新建项目会话仍核对所选目录与授权。自动重接恢复所选会话和进程内草稿，不重发任务。

设置页的“提供商”以列表展示当前支持的 OpenAI、DeepSeek、OpenAI-compatible 与 Ollama，按实际快照显示可用状态；点击“配置”或“编辑”在页面右侧面板打开对应 Provider 表单，关闭后返回原列表按钮，不承诺连接或执行已验证。切换提供商会清空上一提供商尚未保存的密钥、地址和模型名称。必填 API key 与服务地址格式在面板内提示错误并聚焦对应字段，不弹出浏览器原生校验提示。“模型”页按 Provider 展示已发现模型，可启用或禁用，并通过下拉框从已启用且可用的模型中选择默认模型；当前默认模型须先更换才能禁用。切换默认模型、启用或禁用模型、刷新配置和保存提供商时，页面保留当前分类与滚动位置，不整体变灰；等待期间阻止重复配置操作；关闭再打开设置不会解除等待，完成后才恢复配置操作。启停开关先保持用户选择的位置，提交失败则按服务确认的状态恢复并显示错误；提供商保存期间输入只读。无可选模型时显示空态和服务提供的诊断代码，不将未配置误报为可用。输入区模型选择器只展示已启用的模型路由，并暂存本次选择。新会话在首条消息创建时绑定该路由，已有会话在下一条消息开始时更新自身路由，不覆盖其他会话；活动任务继续使用开始时冻结的模型。API key 随本机用户 kite-code.jsonc 保存，输入在提交后清空；保存会替换同一 Provider 的配置。模型名称留空时查询模型列表，手动填写时直接保存，是否可执行仍需实际任务验证。提交结果未知时应检查最新配置，不自动重试。

保存 Provider 与刷新配置分别确认结果：已保存但刷新失败时，提示刷新后选择模型，无需重复保存；服务明确拒绝时保留拒绝原因。写入结果未知时，即使后续刷新成功也不改称保存成功；刷新同样失败时明确说明两者，避免将查询错误误认为写入未发生。

迁移前 Tauri 版本在本机 macOS 完成过配置、问题/计划、项目与会话草稿、修改与测试、结果阅读、VS Code 跳转、重启继续、长会话、与 TUI 的同会话写入保护、损坏制品提示和手动替换应用后的数据保留。Electron 已在隔离原生窗口中用真实 DeepSeek 模型验证：A 的两个 required 子会话运行时反复进入子详情、返回父会话并切换 B/A，返回 A 仍能连接，同一 Run 随后完成；此证据只覆盖该定向场景，详见[原生验收](../../../../apps/kite-desktop/docs/native-validation.md)。包内 Service 的 MCP OAuth、原生凭据保存与重启恢复不能自动证明 Electron 窗口流程。系统输入法、实际外部编辑器、原生授权和工具进程树崩溃等剩余场景尚未重新取得窗口证据。桌面端仍是开发版本；正式签名、公证、下载分发与签名包升级、其他平台尚未完成资格验证。从其他程序导入已有凭据的系统授权行为也未完成验收，不承诺无提示迁移。

本次两栏界面通过真实服务回归、DOM 交互测试与浏览器布局检查；系统中文输入法、preload/IPC 和 Electron 窗口仍需单独验收。验证范围见[两栏会话界面](../../../../apps/kite-desktop/docs/conversation-ui.md)。

设置中的 MCP 分类显示配置来源、连接与认证状态，可展开连接详情；按实际状态开始／取消认证或重新连接。操作完成后查看最新状态，浏览器认证完成后点击刷新；结果未知时不自动重试。Skills 分类展示当前项目可发现的名称、描述、来源与可用状态，没有安装入口。此功能不改变 Web 的只读权限。

页面完整刷新后，若原项目服务仍在运行，应用自动接回服务、恢复原会话并继续读取任务状态，无需重新添加项目或确认清理，也不停止原任务。普通界面热更新保留客户端连接；完整刷新不保证保留未发送草稿。应用或服务真正退出后的恢复不自动重放已停止的任务。

客户端启动以 300ms 内完成本地连接和首屏目录为优化目标；目录无需先恢复所有历史或准备模型。迁移前 Tauri 宿主的部分热缓存服务至目录测量曾低于该预算，但首次运行和完整系统启动仍未满足资格；Electron 需要重新取得从系统启动到窗口绘制的端到端证据。测量条件与负载限制见[启动说明](../../../../apps/kite-desktop/docs/history-and-recovery.md#启动预算与验证边界)。

点击未缓存的会话后，右侧消息区保持原尺寸并在中央显示无底色的浅色风筝图标，以不改变布局的轻微闪光表达加载；系统要求减少动态效果时显示静态图标。页面不显示加载文字或欢迎内容，历史分批读取完成后直接渲染完整正文，避免加载节点引起布局抖动。已有缓存正文的后台校准继续保留正文，不显示该覆盖层。

工具消息按已确认原型统一为轻量行：上下各留 8 px，读取／搜索聚合展开后不缩进；hover 高亮文字与图标，不增加背景色。仅具体文件名 hover 时显示下划线并可打开。Shell 摘要点击展开输出，容器最大高 320 px、内部可滚动，结果固定在容器底部；手动上滚后停止跟随，可回到最新输出。运行中的文字有轻微扫光，减少动态效果设置下静态显示。

自动审批状态附在所属工具上：审批中、已自动批准、未通过或等待人工审批，等待使用中性色，原因按服务提供的文本显示。人工审批主按钮为“仅批准这一次”，服务允许时右侧菜单可直接“批准本次及本会话相同命令”；左侧为“拒绝”。授权范围仍以服务匹配规则为准，批准不等于执行成功，停止后保留已有批准记录和输出。上下文自动压缩以轻量分隔消息显示进行中、完成或失败；问题回答完成后可在轻量回执中展开查看。

读取工具失败保持单行状态，不另附原始错误段落；审批拒绝原因仍正常显示。聚合内的 Shell 也可点击命令查看输出，收起聚合后再打开会保留先前展开选择。

在另一空间的已有会话发送时，直接按原会话ID提交，不要求切换当前项目，不关闭配套服务，也不停止其他空间任务。新会话属于所选空间，已有会话按持久空间身份执行；授权、模型和草稿继续分别隔离。明确退出、显式取消及真实工作目录冲突仍按各自规则处理。

操作失败通过会话页面顶部居中的 Toast 显示，不使用遮罩弹窗、不抢输入焦点，保留草稿，可手动关闭。普通失败标记“错误”，需要恢复核对标记“警告”，类型同时用文字和颜色区分。会话因执行权失效而不可继续时，提示区分被占用、清理未完成与外部结果未知。“检查恢复”在允许恢复时解除恢复门禁并重新加载状态，不发送输入框草稿。旧执行结束缺少证据时保留历史和草稿，不能以重发消息代替核对；详情见[恢复语义](../../features/recovery.md)。

Git 分支切换会影响项目配置加载，当前仍需配套服务重启。若任何空间还有运行或等待中的任务，会要求先等待任务结束，不自动取消它们；全部空闲后再切换并重新连接。普通切换空间和发送消息不需要这次重启。

Ask 请求出现时，消息列表立即显示“询问用户”工具记录和问题，等待用户回答；回答或取消后在同一位置更新。Ask 历史保留唯一可展开工具记录：单题标题展示“询问用户”和问题，内容为“回答：”及答案；多题标题展示“询问用户 · 已回答 N 项”，明细带有序前缀，每项按“问题：回答”展示。取消后内容只显示“已取消”。内容与标题文字对齐，换行对齐前缀后的正文，每项最多 5 行，超出截断，连续字符自动换行。仍按 toolCallId 去除重复工具记录，不展示结果 JSON。

Shell 只展示部分日志且服务提供的总行数超过当前内容时，状态区显示“输出已截断”。自动审批期间停止且没有执行记录时，明确说明命令未开始执行；执行后停止则保留实际输出，不标为“未执行”。

可展开消息的箭头紧贴标题内容（6 px），位于状态文字之前；收起时仅悬停图标与文字组成的紧凑标题区或键盘聚焦时显示，展开后持续显示。文件修改的文件名与 diff 按钮保持独立操作；不可展开的读取不显示箭头。思考过程使用灯泡图标与同一折叠交互，内容有界滚动。

思考标题实时显示“思考中 · N 秒”，按客户端接收该段首条实时思考事件的时间每秒更新，折叠不停止计时；正常完成、失败或取消中断后均显示“已思考 · N 秒”并冻结。这是客户端观察耗时，不代表服务端模型请求总耗时。历史缺少时间依据时不显示秒数。

思考内容展开或收起时，与后续非最终正文都保留 8 px；末尾空白行不占用展示空间。

工具消息展开后，标题文字、图标和箭头持续高亮；收起后恢复默认辅助色，悬停和键盘聚焦仍可高亮。详情展开与收起有短暂过渡；系统启用减少动态效果时直接切换。

源码与打包版使用同一正式会话入口，不再按代码目录或 epoch 自动分库。已验证来源会自动整理；`STORE_INCOMPATIBLE` 表示未证明可安全读取的格式，`STORE_ACCESS_DENIED` 提示检查数据访问权限，`STORE_CORRUPT` 表示数据库或已识别结构校验失败，`STORE_INSUFFICIENT_SPACE` 提示释放磁盘空间后重试。原数据不会因这些检查失败而被清空或替换。

启动失败且Service提供了有效诊断时，可点击“保存诊断”，在系统文件对话框选择新的JSON文件。报告只包含错误分类、准备阶段、格式版本与处理提示，不包含会话内容、目录或原始服务输出。取消选择不会写文件；已有文件不覆盖，保存失败时选择新的文件名重试。迁移期间会显示阶段；确认其他客户端或整理流程占用存储时先自动等待，最长10秒，占用解除后在当前窗口继续启动，超时再提供重试。应用菜单中的退出先请求安全退出，发布前在安全点取消，发布已开始则等待结算；等待超过 20 秒可由用户明确强制退出，届时下一次启动按持久恢复资料核对。窗口关闭仍按原行为隐藏窗口；请求退出本身不表示取消已完成。
