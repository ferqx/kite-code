# TUI 常见问题

| 症状 | 先核对 | 处理 |
| --- | --- | --- |
| 启动失败 | 模型配置、工作区信任、版本配对 | 按启动诊断修正；不要删除会话数据尝试修复版本 |
| 找不到历史会话 | 工作区、source/installed profile | 使用同一运行入口和 profile，再查看 `/resume` |
| 正文出现但仍 Working | 工具或运行尚未正式结束 | 等待终态；必要时取消并核实结果 |
| 消息排队未开始 | 前一轮或子任务清理仍未完成 | 等待；切会话不会把队列转移 |
| 审批点击后仍显示 | 提交中或发生连接/状态错误 | 阅读提示，重新取得当前请求后重试 |
| 会话切换后串消息 | 是否为旧请求迟到结果 | 这是应排查的问题，记录切换顺序和诊断，不当作正常行为 |
| 完成后重复输出或跳到底部 | resize、焦点、状态更新与复现步骤 | 记录终端类型、窗口大小和操作顺序 |
| 压缩提示无新内容或收益不足 | 当前上下文是否已有有效压缩 | 继续新任务后再决定是否压缩 |
| 快捷键无效 | 当前焦点、终端是否截获、命令是否实际支持 | 优先用参考文档中的可靠入口 |
| Web 没启动 | TUI 默认不会启动 Web | 按 Web/Server 手册显式启动 |

提供问题信息时注明客户端、操作顺序、预期与实际、版本和安全的错误摘要。不要上传凭据或未经检查的完整会话。
