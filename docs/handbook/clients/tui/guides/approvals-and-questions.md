# 审批、问题与方案确认

审批面板说明将执行的操作、目标及可选择的授权范围。确认前核对命令和目标；面板出现不代表工具已执行。

## 审批

上下选择、Enter 提交当前选项。只使用界面实际提供的授权选项；一次允许不应理解为永久开放所有命令。

Esc 拒绝当前审批，并结束当前轮的相关执行；当前目标应显示为拒绝，其他相关调用按取消结果收敛。Ctrl+C 是整轮取消，与选择某个授权选项不同。

提交中保持面板可见。连接、过期或状态变化错误发生时，交互不应伪装成已授权；读取提示，重新取得当前请求后重试。连续按键不能把旧请求的回答应用到后来切换的会话。

## 权限模式

通过 `/permissions` 选择模式。Ask/Accept Edits、Auto 与 Full 的含义见[共享权限说明](../../../features/tools-and-approvals.md)。计划模式与权限模式分别表达规划意图和执行授权。权限面板存在会话授权时，可按 C 清除这些授权；这不会撤销已经执行的操作。

## 回答问题

单题显示问题和选项，多题按步骤推进；按面板提示选择或输入自定义答案。多步骤返回键可能只回到上一题，不能一概当成取消整轮。

已经提交并确认的回答在恢复时不应再次要求回答。提交失败仍需处理原问题，不能只关闭面板继续假定模型已收到。

## 方案审核

方案审核允许阅读计划、批准或提出修改。批准时选定的执行方式应与后续运行一致。见[计划指南](planning.md)。

当前开发版本按 Esc 拒绝时，等待回执期间可能仍显示审批选项，没有与 Enter 相同的提交中反馈。不要因选项仍可见就判断拒绝未发送或立即改选批准；先等待结果或检查连接。这项反馈差异尚未修复。
