# 取消、继续与恢复

取消执行、继续对话、恢复会话和恢复文件是不同操作。

## 取消当前任务

普通运行界面按 Ctrl+C 或 Esc 发出取消请求。当前目标的本地请求准备完成后先显示 `Cancelling · cancellation requested`，系统观察到取消流程后显示 `Cancelling`；两者均不表示已停止。等待系统确认和外部操作清理；没有新输出不等于已停止。重复按键不应重复发起独立取消。

审批界面的 Esc 表示拒绝当前审批并收敛该轮，嵌套输入中的 Esc 可能只返回上一层。使用 Ctrl+C 取消整轮时，不将其当作某一授权选项。

普通问答的多步骤界面先用 Esc 返回上一题；第一题 Esc 取消准确原问答执行。同一任务的 Agent 可以收到取消结果后继续，取消问答不等于取消整轮。无法核实原问题或取消未确认时保留错误／未知提示，不自动取消其他执行。

取消不能撤销已经落盘的文件或已经完成的外部操作。结果未知时，先核实副作用，不盲目重复执行。取消后输入的后续任务可能仍需等待前一轮清理完成。

## 继续与打开历史

通过 `/resume` 打开会话，再输入新的任务继续。仅打开历史不应自动重放已经执行的写操作。

## 恢复点与分叉

`/rewind` 选择恢复点，进入确认后选择当前提供的恢复范围：恢复代码和会话、仅会话或仅代码。认真核对影响范围；会话恢复会创建新会话并保留来源，代码恢复不等同于简单切换会话。

恢复点应对应可恢复的完整边界；验证失败时不假装恢复成功。新会话不继承一次性授权，恢复后可继续选择更早的节点。

退出界面使用 `/exit`。数据保留见[历史与导出](history-and-export.md)。

## 执行权丢失

Server 返回需要恢复时，TUI 停止显示 Working 和无法确认的工具、子任务活动指示，并提示执行与清理尚未确认。已提交任务的执行异常不等于消息未发送；历史记录仍保留。需要先核实外部副作用并完成恢复处理，不能把界面停止动画当作工具已取消，也不能盲目重跑。

冷重开或连接到另一个 Service 后，历史可能仍记录原执行者的运行状态。当前连接无法核实该活动时会明确提示，正文和原状态保留；任务仍可能在另一执行者中运行。这个提示不证明原执行者已死亡，不会自动中断、恢复或重放任务。


## 通用开发 TUI 的 Files 三范围操作

`/rewind` 打开实际恢复点目录，上下选择准确的用户消息边界，再 Enter 查看文件预览。可核实原出处的分叉历史仍显示对应原消息，不能按列表位置推定恢复目标。预览中的空 Enter 不提交；1 仅会话、2 仅文件、3 会话与文件只选择范围，再按 Enter 才明确申请。仅会话创建实际新会话，原代码不变；仅文件保留当前会话；两者先恢复文件，确认原恢复成功后仍需明确继续第二步。文件恢复有独立审批；A 关闭恢复面板后回答准确原卡，再重新 `/rewind` 查回保存结果。

目录里的“已保存”（Saved）保留原申请。L 查询所选原结果，R 重新核实原结果或目录，C 明确继续尚未开始的新会话步骤；正在处理恢复申请时等待该次结果。文件成功但新会话未确认仍是部分完成，不要重新生成申请或重做文件恢复。两者都已确认成功后，才关闭面板、进入准确新会话并提示实际恢复的文件数；预览、受理回执或历史成功记录都不能代替这次确认。缺少、错误或未知结果保留原申请，不显示完整成功。关闭、Ctrl+C、切会话只停本地读取，迟到结果不会把你带回旧会话或在新会话显示旧成功提示，未确认写入仍保原 unknown。进程重启后只查原 ID，不自动提交；备份恢复到另一 Store 也不重标原申请或自动执行。

明确继续前重新核原恢复点的实际文件详情。若外部编辑或后来的已完成任务改变文件，即使 selector 未变，也拒绝 Fork 并保留 Code 已成功、Fork 未开始的事实。现有校验不承诺阻止最后读取与 Fork 间任意外部编辑器竞争。恢复点仅覆盖接入 Files 的真实修改，不把上下文选择当作文件回滚，亦不宣称捕获 Shell 或外部修改。正式 Terminal 与开发 TUI 共用上述通用入口，已有本机真实编译 CLI/80×24 PTY 与强杀证据；完整恢复与其他平台资格仍由其交付门禁负责。

## 通用 TUI 的显式原申请恢复

`/recovery` 支持输入 `run <原 Run ID>`、`report <原报告 Command ID>` 或 `interrupt confirm`，再按 Enter 明确提交。回执丢失保留原申请；Ctrl+L 查询原 ID，Ctrl+C 只停止本次读取，Esc 关闭面板，不另发工作取消或重新提交。连续 Ctrl+C、Ctrl+L 仍分别执行这两项操作，已停止读取的迟到结果不会覆盖后来查询。

粘贴只填入文字，粘贴中的 Enter 或控制字符不能代替按键确认、查询或取消。恢复受理与实际 Run 完成分别核对，原审批仍须独立回答；具体接续、中断、报告范围见[恢复说明](../../../features/recovery.md)。
