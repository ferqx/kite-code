# 工具与子任务

Agent 可读取文件、搜索、执行命令、修改文件或委派子任务。实际可用工具取决于配置、模型能力、权限和当前运行条件；工具名称出现不等于已经执行。

## 阅读工具结果

只读探索按当前 Run 的实际只读定义聚合成原统计摘要，写操作和不同调用批次保持分开。独立工具使用单独卡片，显示目标、执行状态和安全可展示的结果。Shell 运行时使用原五行真实输出尾部，未完整时提示打开已保存完整输出；成功时保留有界结果和退出状态；用户主动折叠后可隐藏正文。

通用工具结果保持有限预览；无论省略的是长行尾部还是后续整行，都会显示“结果预览已截断”及 `Ctrl+E` 完整已保存结果入口。预览不拆开中文或 emoji 的完整字符，截断显示不改变原记录；未截断的结果不附额外提示。

成功的正式 Files 写入卡片使用核实的原路径和写入前后基线，直接显示逐行增删 diff；新建文件显示原内容预览。内容未变与实际修改分别提示，预览截断会明确说明。没有合法原凭据时不把参数或其他执行的结果拼成修改证明。

输入为空时，Enter 可展开或折叠当前可操作的尾部工具/子任务块。输入非空时 Enter 只提交消息。已经写入终端历史的内容不一定仍是可交互卡片。

正式 Terminal 与开发 TUI 共用这一操作：空主输入只切换当前可见尾部结果的正文，名称和原执行状态继续显示。排队输入、同会话刷新及结果版本更新保留当前折叠选择；清屏不会删除原结果，切换会话后展示选择重新开始。

Ctrl+E 打开有限窗口的执行目录，上下选择中间工具／后台卡片并阅读原完整结果。工具调用保留原完整参数和换行，同名工具依准确调用 ID 关联结果；只有完整 Model reader 核实后才称完整调用。消息按原序号排列，执行按明确的来源或父关系放入对应阶段；没有该关系的执行单列在本任务记录中，不按工具名猜时序或结果成功。

活动 Thinking 保留有限实时尾部，完成后的完整思考保持收起。Ctrl+O 读取原完整输出时同时保留正文和思考，导出使用已加载的原文；缺少读取能力或不支持原格式时明确提示。读取和导出不改变执行状态。

## 并发子任务

同一 Model 调用批次且实际生命周期交叠的子任务在原 Delegating 聚合中显示；没有这项来源则保留单独卡片。步骤区随执行推进；终端空间不足时只显示有界尾部。可见步骤减少不表示执行记录被删除，也不应推断子任务已被取消。

主屏按实际终端高度分配步骤和可见子任务数，空间不足时先显示聚合、折叠数量与最新子任务摘要，避免完整树把输入和当前状态挤出屏幕。展开或缩小窗口只改变展示，完整记录仍由原详情入口读取。

向输入队列添加消息不能改变当前子任务的展开状态。取消主任务需要等待相关子任务和外部操作收尾；最终状态不能由“没有新输出”推断。

## 查看后台任务与恢复历史

正式 Terminal 与开发 TUI 的 `/background` 显示当前会话快照中的原后台任务。上下选择，O 读取完整已保存输出，C 读取原子会话日志；也可明确输入 `/background output <原执行ID>` 或 `/background child <原执行ID>`。输出保留首次读取水位之前的全部原文和缺口，子日志保留固定消息上界及完整已保存模型正文；新内容通过显式刷新读取。

子会话详情中的长正文保持 Markdown、代码高亮和表格格式；上下滚动、Home／End 和窗口变化继续使用同一完整正文，不因超过一屏退成原始 Markdown 文本。

明确从备份恢复后，原任务仍保留原身份，目录标为“恢复历史；只读”。可以查看原输出和子日志，读取和重新打开不会启动旧任务。历史条目不能停止或取得新的执行资格；当前连接中仍活动且已重新核实的准确任务才可 S 后 Enter 停止，或输入 `/background stop <原执行ID>`。受理停止请求不代表实际终止或清理完成。

关系缺失、来源不符或读取期间绑定改变时，读取失败，不把其他任务正文显示为原结果。Esc、Ctrl+C、关闭面板和切会话只结束本地读取；不会取消后台任务。

## 拒绝、失败和未知结果

审批拒绝、工具失败、取消和结果未知分别处理。拒绝的工具没有运行；失败可能已经产生部分副作用；未知结果不能直接当作失败后安全重跑。先阅读诊断和最终说明，必要时让 Agent 检查实际文件或命令结果。

涉及审批见[审批与问题](approvals-and-questions.md)，扩展工具见[MCP 与 Skills](mcp-and-skills.md)。
