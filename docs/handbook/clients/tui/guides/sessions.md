# 新建、查找与切换会话

会话保存对话与执行历史。切换会话改变当前查看的内容，不等同于取消任务、恢复文件或新建分支。

## 新建与选择

`/new` 创建新会话；当前会话尚无用户消息时不会反复创建空会话。`/resume` 打开会话选择器。

使用上下键在搜索行与列表之间移动，输入关键词过滤，选中会话后 Enter 打开。搜索有内容时 Esc 先清空搜索；处于空搜索行时先回到列表；随后可关闭面板。打开当前已选会话不会再执行一次任务。

历史加载期间显示加载状态。快速选择 A 再选择 B，A 迟到的加载成功或失败都不能覆盖 B。加载失败不表示历史已删除，应按错误提示重试或检查连接。

## 运行中切换

在 A 执行时切换到 B，只切换前台展示。A 的运行、审批及已提交结果仍属于 A。切回 A 时展示其当前状态和历史，不继承 B 的瞬时交互或上下文。

模型、权限、上下文等状态按会话和实际配置规则恢复；不要把上一会话的状态栏当成新会话的事实。排队消息仍绑定提交时的会话，见[输入与排队](input-and-queue.md)。

## 删除与命名

选择器中，搜索为空且焦点位于会话行时，按 D 打开删除确认。默认保留；确认后删除相应会话数据，不回滚工作区文件。删除当前会话后会建立可继续输入的新会话。

当前选择器没有手动重命名入口，不能通过 `/resume <名称>` 重命名或直接打开。显示名称由产品现有命名流程生成。恢复、分叉与改名不是同一功能。

导出内容和限制见[历史与导出](history-and-export.md)，恢复历史节点见[取消与恢复](cancellation-and-recovery.md)。
