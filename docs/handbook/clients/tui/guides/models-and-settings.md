# 模型与界面设置

`/model` 打开模型选择器，按 Provider 分组选择具体模型。命令不接受模型名参数。相同名称但 Provider 不同的模型是不同路由，不能只凭显示名称判断实际请求目标。

## 生效时机

保存模型配置后，正在执行的请求继续使用开始时确定的配置；下一次执行采用新的设置。会话切换时恢复该会话对应的状态。配置保存失败应显示错误，不以选择器关闭证明写入成功。

`/effort` 选择推理深度，实际支持程度取决于模型与 Provider；它不能让不支持相关能力的模型自动具备该能力。

## 界面偏好

`/language` 选择系统语言、简体中文或英文；`/theme` 选择 teal、blue、purple、cyan 或 mono 配色。界面文字与颜色更新不应产生第二份历史，也不翻译模型原文、路径或命令。

主题、语言等为终端客户端偏好，不表示 Web 同步采用相同设置。权限通过 `/permissions` 调整，计划通过 `/plan` 或 Shift+Tab 进入。

设置作用域和可用值见[设置参考](../reference/settings.md)，模型连接问题见[排障](../troubleshooting.md)。

## 界面语言与原始内容

当前正式 TUI 的固定提示随已保存语言显示，包括宿主快捷键、后台任务、原请求恢复、文件恢复、待决卡片选择、文件候选和粘贴占位。中文粘贴块显示为“已粘贴 N 个字符”，实际发送仍使用原始内容；光标和换行按当前显示文字计算。

只有偏好保存成功才改变显示；保存失败保留原语言并显示原因，无法确认保存结果时先重新读取。模型、用户、工具和问题正文、完整请求 JSON、路径、命令、原 ID、机器状态值和错误码保留原文。因此原始材料中出现英文不代表语言保存失败。

## 统一 TUI 的模型设置

`/model` 和 `/effort` 修改当前工作区的项目设置。模型以 Provider 和准确 ID 显示，并标明启用、配置是否完整；上下选择后，Enter 先展示修改内容，再按 Enter 保存。E 核对启用或禁用，不能禁用当前默认模型。该设置适用于同工作区后续执行，正在运行的请求保留原配置。

`/effort` 针对当前默认模型，只显示服务实际提供的参数选项和只读原因。选项表示适配器能够编码的值，远端 Provider 仍可能拒绝。清除项目 effort 后会重读实际有效值：项目没有其他 options 时可能恢复用户层设置；仍有其他项目 options 时也可能继续遮蔽用户层 effort。

R 重新读取，K 查询原保存操作，Esc 放弃当前确认或关闭。保存失败会明确显示；回执丢失显示 outcome_unknown，K 仅查询原操作，不重复保存。观察失联显示 stale 时仍可读设置，写入须等连接和当前视图恢复。关闭面板不会取消正在运行的模型任务。

## 界面偏好的保存与恢复

`/theme`、`/language` 使用当前 profile 的终端偏好。上下选择，Enter 保存，Esc 或 Ctrl+C 关闭；R 重读磁盘。只有保存成功才改变显示，失败保留原配色和语言并显示原因。若另一个终端已经修改文件，重新读取后再选择，不自动覆盖。

配色为 teal、blue、purple、cyan、mono；语言为 system、简体中文、英文。system 使用设备语言，macOS 优先系统首选语言。选择跨会话保持，退出后重开同一 profile 可恢复。它不改变模型原文、工具正文、路径、命令、会话内容或权限，观察失联也不妨碍本机显示设置。偏好保存在新 profile 的 `ui/preferences.jsonc`，不读取旧用户配置。正式 Terminal 与 `bun run tui:dev` 使用同一显示和偏好实现，各自使用所选 profile。
