# 模型与界面设置

`/model` 打开模型选择器，按 Provider 分组选择具体模型。命令不接受模型名参数。相同名称但 Provider 不同的模型是不同路由，不能只凭显示名称判断实际请求目标。

## 生效时机

保存模型配置后，正在执行的请求继续使用开始时确定的配置；下一次执行采用新的设置。会话切换时恢复该会话对应的状态。配置保存失败应显示错误，不以选择器关闭证明写入成功。

`/effort` 选择推理深度，实际支持程度取决于模型与 Provider；它不能让不支持相关能力的模型自动具备该能力。

## 界面偏好

`/language` 选择系统语言、简体中文或英文；`/theme` 选择 teal、blue、purple、cyan 或 mono 配色。界面文字与颜色更新不应产生第二份历史，也不翻译模型原文、路径或命令。

主题、语言等为终端客户端偏好，不表示 Web 同步采用相同设置。权限通过 `/permissions` 调整，计划通过 `/plan` 或 Shift+Tab 进入。

设置作用域和可用值见[设置参考](../reference/settings.md)，模型连接问题见[排障](../troubleshooting.md)。

## 当前语言限制

语言切换尚未覆盖全部自有状态、错误和粘贴提示，界面可能混用中英文。当前语言保存失败时，界面实际保留旧语言；即使提示称“本次会话已切换”，也不能据此判断切换成功。这些是尚未修复的差异，不改变语言设置应更新自有界面文字的预期。
