# 历史、导出与数据保留

通过 `/resume` 读取已有会话。历史来自保存的会话数据，不是从终端滚动缓冲区反向解析。窗口清屏、切换会话和退出 TUI 不等于删除会话。
已加载的历史轮次可以一直向前阅读，不因超过 500 轮而静默丢掉较早的内容。

## 导出

在目标会话执行 `/export`。成功后显示文件路径；默认写入用户 Kite 配置目录的 `session-<时间>.md`。文件为 Markdown，包含当前已加载对话中的用户文本、回答文本和可导出的思考块。

导出不是完整数据库备份：工具卡、审批、所有诊断、文件恢复资料和瞬时状态不保证包含。运行中导出仅反映当时已加载内容；要获得最终对话，等待执行结束再导出。

统一 Agent 开发 TUI 的 `/export` 写入当前选定 profile 的配置目录，文件名加入唯一标识，权限为仅当前用户读写。大正文只有已完整加载的部分才作为全文导出；未加载时保留预览并明确标记不完整。导出本身不会加载更多正文或调用模型与工具。正式入口切换和平台范围见[实施进度](../../../../plans/unified-agent-refactor-v1-progress.md)。

写入失败显示 `Export failed`。检查目标目录权限与空间后重试，不把命令回显当成文件已写入。

## 清屏与删除

`/clear` 清理当前正文和已结束执行结果的展示，完整历史、已读取全文及导出输入仍保留；它不删除会话、不回滚工作区文件，也不停止任务。待决审批、活动工作与未知操作继续显示，新正文或状态变化会重新出现。同一会话刷新保留清屏结果，切换到其他会话后可重新查看原历史。

Ctrl+L 先查询未知原命令，再在选中会话未变时刷新并清理本地展示；未知回执不会变成重复提交。面板取得焦点时使用该面板的按键规则。删除会话需要在会话选择器里明确确认；详见[会话指南](sessions.md)。

源码 checkout 与已安装版本在同一 canonical 配置根下默认使用同一正式会话库。切换运行方式后找不到会话，先核对是否显式选择了其他数据根、工作区或历史来源，并查看启动诊断；不要手工复制运行中的数据库作为恢复方式。
