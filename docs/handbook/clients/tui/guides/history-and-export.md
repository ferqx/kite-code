# 历史、导出与数据保留

通过 `/resume` 读取已有会话。历史来自保存的会话数据，不是从终端滚动缓冲区反向解析。窗口清屏、切换会话和退出 TUI 不等于删除会话。

## 导出

在目标会话执行 `/export`。成功后显示文件路径；默认写入用户 Kite 配置目录的 `session-<时间>.md`。文件为 Markdown，包含当前已加载对话中的用户文本、回答文本和可导出的思考块。

导出不是完整数据库备份：工具卡、审批、所有诊断、文件恢复资料和瞬时状态不保证包含。运行中导出仅反映当时已加载内容；要获得最终对话，等待执行结束再导出。

写入失败显示 `Export failed`。检查目标目录权限与空间后重试，不把命令回显当成文件已写入。

## 清屏与删除

`/clear` 或 Ctrl+L 清理当前展示，不回滚工作区文件。删除会话需要在会话选择器里明确确认；详见[会话指南](sessions.md)。

源码 checkout 与已安装版本使用的会话位置可能不同。切换运行方式后找不到会话，先核对 profile 和工作区，再考虑数据是否丢失。不要手工复制运行中的数据库作为恢复方式。
