# 终端滚动、展开与重绘

TUI 使用终端主屏，完成的输出保留在终端原生滚动历史中。使用终端自身滚动和文本选择阅读之前内容，不假设存在应用内的完整历史分页器。

## 展开与状态更新

输入为空时 Enter 可切换当前尾部可交互工具或子任务块；输入有文字时只提交输入。连续 Enter 按准确当前会话逐次切换，不能因前一次重绘尚未结束而把后一次按键重复应用为同一状态。活动过程仍可能变化，已经完成的历史不应因状态栏更新而重复输出。

活动圆点和 `Working` 使用动画显示活动状态；Working 不显示整轮计时。Thinking 与工具卡只使用原派发时间／真实结束时间；没有来源不造秒数。正常完成正文自动核实完整读取后写入历史，活动正文与工具仍在动态区域更新。动画变化不代表收到新的模型或工具结果。

运行中的状态刷新不应把已经上滚的阅读位置拉回底部，也不应残留重复题头或旧输出。任务结束、活动指示器退出后，不再仅为动画或计时刷新终端；用户输入、窗口变化等仍可触发重绘。

模型目录这类可选显示读取暂时失效时，保留最近已核模型的显示，不因名称暂缺清空并重播原生历史。未核实的下一默认模型和容量仍保持未知；保留历史不代表设置读取已成功。

## 调整窗口与焦点

resize、会话切换或语言变化可能需要整体重绘。重绘应尽量保持完整帧，不应复制历史。切换终端焦点、选择文本或拖动原生滚动条不应被当成 Esc 取消任务。

正式 Terminal 与开发入口共同启用 Kitty 键盘协议；支持该协议的终端可准确传递 Shift+Enter 等组合键，退出时恢复键盘模式。终端不支持或拦截的按键仍按其实际能力处理。

狭小终端可能折叠子任务步骤或缩小可见输入窗口，不代表存储内容被删除。先扩大终端或查看导出，再判断内容缺失。

## 退出

`/exit` 归还终端和光标。退出不恢复进入 TUI 前的旧屏幕，也不删除已保存会话。需要停止任务时先执行取消；服务和客户端生命周期见[服务说明](../../../server/lifecycle.md)。

渲染异常显示可读错误页，Enter 或 Esc 明确退出；普通界面不显示内部调用栈。异常退出返回失败并执行所属连接和进程的收尾，渲染器已经停止时宿主也会结束等待。正常退出仍先保存未提交草稿，保存失败保留编辑器和错误提示。

如果完成后仍反复清屏、跳到底部或出现重复正文，属于需要排查的展示问题，不是预期的会话重放方式。
