# TUI 命令参考

命令名和固定别名不区分大小写。先输入 `/` 可查看候选；完整命令通过 Enter 提交。下表说明实际操作入口，参数不应凭名称猜测。

| 命令 | 参数与别名 | 操作与范围 |
| --- | --- | --- |
| `/model` | 无参数 | 选择 Provider 与模型，见模型指南 |
| `/effort` | 无参数；带参数会提示错误 | 选择推理深度 |
| `/theme` | 无参数 | 选择主题 |
| `/language` | 无参数 | 选择语言 |
| `/resume` | 不支持按参数直接打开 | 打开会话选择器 |
| `/new` | 无需参数 | 新会话；已有空会话不重复创建 |
| `/plan [任务]` | 可选任务文字 | 进入规划，或直接规划指定任务 |
| `/permissions` | 无参数 | 选择权限模式 |
| `/mcp` | 无参数 | 打开 MCP 管理 |
| `/rewind` | 无需参数 | 选择恢复点及恢复范围 |
| `/export` | 无需参数 | 导出当前加载的对话文本 |
| `/context` | 无需参数 | 查看当前请求上下文 |
| `/compact [重点]` | 可选摘要重点 | 手动压缩；不绕过内容收益检查 |
| `/compact reset` | 特殊解析项 | 预检后清除活动压缩点；失败保留旧点，不删除历史 |
| `/status` | 无参数 | 查看连接、profile、版本和配对状态 |
| `/clear` | `/c` | 清理展示，不回滚文件 |
| `/help` | `/h` | 打开帮助 |
| `/exit` | `/quit`、`/q` | 退出 TUI |

不要依赖解析器忽略多余参数的行为。`/model <模型>`、`/mcp <动作>`、`/status <参数>` 都不是推荐入口。`/auto-compact` 仅是过程标记；没有 `/web`、`/release` 或 `/telemetry` TUI 命令。

MCP 提示与启用的 Skill 可以提供动态命令；名称来自当前发现结果，不属于上表固定命令。

详细操作见[TUI 导航](../README.md)，按键见[键盘参考](keyboard.md)。未知命令不会自动获得某个设置或服务控制能力。
