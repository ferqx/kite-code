# 键盘操作参考

按键含义取决于焦点。输入建议、普通面板、问题和审批出现时，以当前面板的操作为准。

| 按键 | 生效位置 | 行为 |
| --- | --- | --- |
| Enter | 非空主输入 | 提交一次输入，不同时展开工具 |
| Enter | 空主输入 | 展开或收起当前可见尾部工具／子任务的结果正文，保留原状态 |
| Shift+Enter / Alt+Enter | 主输入且终端正确传递 | 在光标处换行 |
| ↑ / ↓ | 多行输入 | 移动光标；边界处浏览历史输入 |
| ← / → | 主输入 | 移动光标 |
| Home / End | 主输入 | 当前视觉行的开头/结尾 |
| Backspace / Delete | 主输入 | 编辑输入；粘贴占位块按整体处理 |
| Tab | 命令/文件候选 | 补全当前候选 |
| ↑ / ↓、Enter | 选择面板 | 移动选择并确认 |
| Esc | 建议或普通面板 | 关闭或返回上一层；搜索可能先清空 |
| Esc | 普通运行界面 | 请求取消 |
| Esc | 审批 | 拒绝当前请求并收敛本轮 |
| Ctrl+C | 任意主要交互 | 请求整轮取消；一秒内再次按下会请求退出 |
| Shift+Tab | 全局 | 切换计划模式 |
| Ctrl+T | 没有面板取得焦点 | 显示／隐藏已保存思考；未读时读取当前尾部 Model 的原完整输出 |
| Ctrl+L | 没有面板取得焦点 | 先核实未知原命令，在同一会话刷新后清理本地正文展示 |
| D | 会话列表、搜索为空 | 打开删除确认 |
| C | 权限面板且存在会话授权 | 清除当前会话授权 |

帮助面板当前还列出 Ctrl+E 和 `?`，但主输入/全局处理未提供相应完整入口；使用 `/help` 打开帮助，不将这两个提示当作已验证操作。

终端可能拦截组合键，尤其是换行与系统级快捷键。遇到差异先检查终端配置；不要假定 Web 使用相同按键。

空 Enter 和 Ctrl+T 已由正式 Terminal 与开发 TUI 的同一消费者接入。思考默认隐藏；不具备全文 reader 或原格式不支持读取时显示明确说明。空 Enter 没有可见尾部结果时不提交消息；非空主输入继续使用原消息提交，不改变折叠选择。

## 通用开发 TUI

MCP 面板只用上下、Enter 和 Esc 进行可见选择；范围确认需要独立 Enter，面板内 Ctrl+C 只关闭读取。刷新和原未知操作查询同样来自可见选项，不使用字母业务快捷键，见[MCP 目录与选择](../guides/mcp-and-skills.md#通用-tui-的-mcp-目录与选择)。

准确的项目 Source Question 用上下明确选择 approved/rejected/cancel，Enter 只提交已选决定；空 Enter 零回答。Esc 清未提交选择，Ctrl+C 关闭面板，不请求业务取消。来源目录中的原 ID 选择也零查询，明确“Check original source decision”才读原结果，见[项目来源与原决定](../guides/mcp-and-skills.md#项目来源与原决定)。

通用开发入口的主输入按完整字素编辑，保留中文、组合字符与 emoji；上下按实际显示行移动，边界处读取本输入范围的历史。固定 `/` 候选使用上下选择、Tab 补全；Tab 不提交命令，Esc 关闭候选。终端发送完整 bracketed paste 时，在结束标记前不提交，之后保留完整多行正文；大粘贴占位块按整体删除。文件候选仍待接入。

Ctrl+B 打开完整待决卡目录，上下选择、Enter 返回原卡、Esc 关闭。答复未知时 Ctrl+L 查询原命令并刷新，不再次提交；这些键的开发入口语义见[审批和问题](../guides/approvals-and-questions.md)，不表示正式旧入口已完成切换。
