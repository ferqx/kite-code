# 键盘操作参考

按键含义取决于焦点。输入建议、普通面板、问题和审批出现时，以当前面板的操作为准。

| 按键 | 生效位置 | 行为 |
| --- | --- | --- |
| Enter | 非空主输入 | 提交一次输入，不同时展开工具 |
| Enter | 空主输入 | 切换当前可操作尾部块的展开状态 |
| Shift+Enter / Alt+Enter | 主输入且终端正确传递 | 在光标处换行 |
| ↑ / ↓ | 多行输入 | 移动光标；边界处浏览历史输入 |
| ← / → | 主输入 | 移动光标 |
| Home / End | 主输入 | 当前视觉行的开头/结尾 |
| Backspace / Delete | 主输入 | 编辑输入；粘贴占位块按整体处理 |
| Tab | 命令/文件候选 | 补全当前候选 |
| ↑ / ↓、Enter | 选择面板 | 移动选择并确认 |
| Esc | 建议或普通面板 | 关闭或返回上一层；搜索可能先清空 |
| Esc | 普通运行界面 | 请求取消 |
| Esc | 审批 | 拒绝当前请求并收敛本轮 |
| Ctrl+C | 任意主要交互 | 请求整轮取消；一秒内再次按下会请求退出 |
| Shift+Tab | 全局 | 切换计划模式 |
| Ctrl+T | 没有面板取得焦点 | 切换思考展开 |
| Ctrl+L | 没有面板取得焦点 | 清理当前展示 |
| D | 会话列表、搜索为空 | 打开删除确认 |
| C | 权限面板且存在会话授权 | 清除当前会话授权 |

帮助面板当前还列出 Ctrl+E 和 `?`，但主输入/全局处理未提供相应完整入口；使用 `/help` 打开帮助，不将这两个提示当作已验证操作。

终端可能拦截组合键，尤其是换行与系统级快捷键。遇到差异先检查终端配置；不要假定 Web 使用相同按键。
