# 键盘操作参考

Ctrl+L 不执行刷新、清屏或原命令查询。清理显示使用 `/clear`。按键含义取决于焦点。输入建议、普通面板、问题和审批出现时，以当前面板的操作为准。

| 按键 | 生效位置 | 行为 |
| --- | --- | --- |
| Enter | 非空主输入 | 提交一次输入，不同时展开工具 |
| Enter | 空主输入 | 展开或收起当前可见尾部工具／子任务的结果正文，保留原状态 |
| Shift+Enter / Alt+Enter | 主输入且终端正确传递 | 在光标处换行 |
| ↑ / ↓ | 多行输入 | 移动光标；边界处浏览本输入范围最近 500 条历史输入 |
| ← / → | 主输入 | 移动光标 |
| Home / End | 主输入 | 当前视觉行的开头/结尾 |
| Backspace / Delete | 主输入 | 编辑输入；粘贴占位块按整体处理 |
| Tab / → | 命令候选 | 先扩展共同前缀；无法继续扩展时补全高亮项，不执行 |
| Tab | 文件候选 | 补全准确引用，不提交 |
| Enter | 命令／已就绪的文件候选 | 补全高亮项并提交一次；文件读取中不提交 |
| ↑ / ↓ | 命令／文件候选 | 选择候选，首末项不循环 |
| ↑ / ↓、Enter | 选择面板 | 移动选择并确认 |
| Esc | 建议或普通面板 | 关闭或返回上一层；搜索可能先清空 |
| Esc | 主输入含折叠粘贴 | 清空当前输入，不提交 |
| Esc | 普通运行界面 | 请求取消 |
| Esc | 审批 | 拒绝当前请求并收敛本轮 |
| Ctrl+C | 主输入、审批、普通问题、主要选择器、帮助、模型、设置、MCP 根面板 | 请求整轮取消；一秒内再次独立按下会请求退出 |
| Shift+Tab | 全局 | 切换计划模式 |
| Ctrl+P | 会话主屏、运行、待批、问题与管理面板 | 打开权限面板；关闭后保留原问卷步骤和草稿，不提交答案或取消任务 |
| Ctrl+O | 没有面板取得焦点 | 正常完成正文自动读取；此键明确读取／重读尚未加载且格式支持的原 Model 输出 |
| Ctrl+E | 没有面板取得焦点 | 打开执行详情，从尾部开始；上下可选择中间工具或后台任务 |
| D | 会话列表、搜索为空 | 打开删除确认 |
| Ctrl+C | 会话选择器／删除确认 | 请求整轮取消，并关闭选择器或放弃本地删除确认 |
| R | 删除结果未知的确认 | 查询原删除命令 |
| K | Context 面板 | 打开上下文与会话原申请列表 |
| ↑／↓、K／Enter | 原申请列表 | 选择准确原 ID，再只读查询原结果 |
| V | 原申请列表 | 显示／隐藏完整原申请 |
| Ctrl+C／Esc | 原申请列表 | 停止所属读取／关闭面板，不取消原工作 |
| Ctrl+C | Source Question、MCP 新增只读子目录、执行详情、原申请恢复／查询面板 | 只停止所属读取或关闭本地面板，不取消原工作 |
| C | 权限面板且存在会话授权 | 清除当前会话授权 |
| Tab | 问题含选项和自定义回答 | 切换选项／自定义编辑；不提交 |
| Tab / Alt+S | 可选纯输入题／可选混合题 | 明确跳过当前可选回答 |
| V | Files 预览 | 打开有界文本 diff，Enter 不申请恢复，Esc 返回范围选择 |
| Enter / Esc | 不可恢复错误页 | 明确退出异常客户端，保存草稿并清理所属 Service；非零退出不冒充正常完成 |

使用 `/help` 打开帮助；`?` 没有独立帮助入口。主区的原生 Ctrl+C 批次只算一次取消；一秒内两次独立 Ctrl+C 才请求宿主正常退出。主要选择器与新增只读 reader 的取消范围不同，按上表和面板提示操作；只有后者的本地关闭不请求取消工作。

终端可能拦截组合键，尤其是换行与系统级快捷键。遇到差异先检查终端配置；不要假定 Web 使用相同按键。

空 Enter 由正式 Terminal 与开发 TUI 的同一消费者接入，没有可见尾部结果时不提交消息；非空主输入继续使用原消息提交，不改变折叠选择。活动 Thinking 显示有限尾部，完成后的完整思考保持收起；Ctrl+O 的完整读取同时保存原正文和思考，已加载内容可用于导出。不具备全文 reader 或原格式不支持读取时显示明确说明。

## 通用开发 TUI

MCP 面板只用上下、Enter 和 Esc 进行可见选择；范围确认需要独立 Enter。根面板的 Ctrl+C 请求整轮取消并关闭面板，新增只读子目录中的 Ctrl+C 只关闭所属读取。刷新和原未知操作查询同样来自可见选项，不使用字母业务快捷键，见[MCP 目录与选择](../guides/mcp-and-skills.md#通用-tui-的-mcp-目录与选择)。

准确的项目 Source Question 用上下明确选择 approved/rejected/cancel，Enter 只提交已选决定；空 Enter 零回答。Esc 清未提交选择，Ctrl+C 关闭面板，不请求业务取消。来源目录中的原 ID 选择也零查询，明确“Check original source decision”才读原结果，见[项目来源与原决定](../guides/mcp-and-skills.md#项目来源与原决定)。

通用开发入口的主输入按完整字素编辑，保留中文、组合字符与 emoji；上下按实际显示行移动，边界处读取本输入范围的历史。命令和完整 Workspace 文件目录的候选窗口随终端高度和输入行数变化；上下选择到边界后不循环，Tab 只补全，Enter 补全并提交准确所选项一次。命令候选的右箭头与 Tab 一样先扩展共同前缀。Esc 关闭候选；普通输入再次 Esc 请求取消。终端发送完整 bracketed paste 时，在结束标记前不提交，之后保留完整多行正文；大粘贴占位块按整体删除，主输入仍含折叠粘贴时 Esc 清空当前输入。

Shift+Tab 在主输入、只读面板及待决卡片焦点下都只切换下一次输入的计划意图，不提交当前答案或改变活动任务权限。方案审核用上下明确选择原提供的模式、修改或拒绝；反馈页 Esc 返回选项并保留草稿。

Ctrl+B 打开完整待决卡目录，上下选择、Enter 返回原卡、Esc 关闭。答复未知时自动核对当前会话的原命令，不再次提交。正式 Terminal 与开发 TUI 共用这些操作，见[审批和问题](../guides/approvals-and-questions.md)；完整平台与阶段资格仍按[实施进度](../../../../plans/unified-agent-refactor-v1-progress.md)核对。
