# 状态与提示

| 显示 | 含义 | 后续动作 |
| --- | --- | --- |
| Working | 本轮仍活动，可能正在模型、工具或收尾阶段 | 等待结果，或明确取消 |
| Cancelling | 取消已请求，仍在等待确认与清理 | 等待；不把它当成已撤销文件 |
| Retrying | 系统正在重试可恢复步骤 | 观察最终结果，避免重复提交同一操作 |
| Thinking | 当前思考或只读探索阶段 | 阅读当前活动窗口及最终摘要 |
| Delegating | 子任务正在执行或聚合展示 | 查看步骤及最终结果 |
| 等待审批/问题/方案 | 需要当前用户交互 | 在面板回答，不向另一会话替代提交 |
| Loading | 会话或列表正在加载 | 后续新选择优先，迟到结果不能覆盖 |
| rejected | 操作在执行前被拒绝 | 调整任务或重新发起正确授权 |
| failed | 操作失败，可能已发生部分作用 | 阅读诊断并核实实际结果 |
| unknown | 结果无法可靠确定 | 核实副作用后再决定重试 |
| Export failed | 导出文件未成功写入 | 检查路径权限和空间 |

`/status` 显示 transport、profile、build、版本及配对结果，不提供 Web URL 或完整运行日志。版本配对失败应修正安装或重新启动匹配的显式服务；不能继续假定连接可用。

正文中“完成”不是唯一完成信号。结果仍有阻塞、取消或未知状态时不能视为成功。详细排查见[故障处理](../troubleshooting.md)。
