# TUI 界面导览

主界面由顶部环境信息、消息区和底部输入/状态区域构成。用户输入与回答构成对话；工具、思考过程和子任务显示执行进度。不同类型的内容不等于不同会话。

正式 Terminal 与 `tui:dev` 使用同一 Ink 消费者，保留原顶部圆角信息框、双横线输入区、`❯`、用户背景块、代码语言框／高亮、表格边框、工具树和选择面板。模型、权限与工作区信息来自当前服务读取；不可用时明确说明，不补造配置。工具参数和结果按原调用及来源关联，卡片保留有界预览，完整业务字段可在详情读取；空输入 Enter 折叠尾部结果，Ctrl+E 打开执行目录，可选择中间卡片阅读详情和准确后台任务的子日志。

活动任务显示已保存 Model 输入中的实际模型／档位；尚无该输入时，单独标明来自本轮固定配置。下一轮模型在明确诊断展示中另列，不因保存新默认值而改写当前任务。页脚用量来自准确成功 Model 的已保存 usage，同一调用只计一次；没有缓存事实不显示 0%，没有上下文容量事实不推算利用率。

普通界面不常驻显示消息／执行 ID、Store、摘要、版本和已完成回执账本。结果未知、观察失效、未确认取消、部分正文及真实错误仍显示，原申请仍可查询；跨会话迟到申请保留原身份。`/status`、`/recovery` 和明确的原申请详情继续提供核实所需信息。开发启动默认使用同一普通界面，自动测试的额外展示由显式选项开启，见[测试入口](reference/commands.md#测试诊断展示)。

| 区域 | 用途 | 注意 |
| --- | --- | --- |
| 顶部信息 | 辨认当前模型、工作环境等 | 配置已保存不表示正在运行的请求立即切换模型 |
| 消息区 | 阅读输入、正文、工具与结果 | 过程内容可继续变化；终端历史不是完整数据备份 |
| 输入区 | 编写任务、命令和补充输入 | 面板或交互取得焦点后，按键作用于该交互 |
| 状态行 | 辨认 Working、Cancelling 等活动状态 | 不用动画是否变化判断任务是否仍在运行 |
| 排队消息 | 查看当前会话尚未开始的后续输入 | 排队不等于已经创建执行 |
| 选择面板 | 模型、会话、设置、MCP、帮助等 | 上下选择、Enter 确认、Esc 返回，局部提示优先 |

活动状态行不显示整轮计时。Thinking 和工具卡使用原派发和结束日志时间；它包含派发阶段，不表示 Provider 首 token 或进程开始时间。缺原时间或日志有缺口时不显示虚构秒数，恢复历史不从打开界面的时刻重新计时。

审批、问题和方案审核占用底部交互区域，期间正常运行状态行可隐藏。这是焦点变化，不代表任务已经结束。

使用 `/help` 查看帮助，`/status` 查看连接与版本信息。具体消息含义见[状态参考](reference/states-and-messages.md)，操作见[键盘参考](reference/keyboard.md)。

界面说明适用于终端；Web 的页面布局和更新方式见 [Web 导览](../web/interface.md)。

## 实际终端输出示例

下面是隔离工作区与本地 mock model 的真实 PTY 输出（省略临时工作区路径行）；它是文本快照，不是跨终端像素布局承诺。

```text
╭──────────────────────────────────────────────────────────╮
│ ──◆ Kite Code                                            │
│                                                          │
│ model      mock-model max                                │
╰──────────────────────────────────────────────────────────╯

❯ Explain this example project without editing files.

  This is a handbook example. The task has finished without changing files.

────────────────────────────────────────────────────────────────────────────────────────────────────
❯
────────────────────────────────────────────────────────────────────────────────────────────────────
mock-model max · [自动审批]
```

顶部是模型信息，中间为一次输入与完成回答，底部为可继续输入区域。此例已完成，因此不显示 Working；活动和取消行为由相应指南说明。
