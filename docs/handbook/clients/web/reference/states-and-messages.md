# Web 状态与提示

| 状态 | 含义 | 处理 |
| --- | --- | --- |
| Loading | 请求尚未完成 | 等待或选择其他目标，迟到响应不应覆盖新选择 |
| Empty | 成功读取后没有可展示记录 | 核对工作区和 profile，不等于连接失败 |
| Error | 请求或访问失败 | 查看诊断并检查服务；旧快照可能仍显示 |
| Selected | 当前页面正在展示的会话 | 后续 History 和日志读取应属于该会话 |
| running / waiting | 会话活动或等待交互 | 可触发可见页面的 History 更新；Web 不能代为回答 |
| completed | 执行完成 | 阅读结果，日志仍需按需刷新 |
| rejected | 工具执行前被拒绝 | 不应出现该次调用的退出码 |
| failed / cancelled | 失败或取消结果 | 不理解为成功，必要时回执行客户端处理 |

页面状态与工具状态是不同层次。连接错误不会把任务变为 failed，空列表也不会删除会话。

若显示内容与实际执行不同，先核对会话、更新时间和连接，再判断缺陷。见[排障](../troubleshooting.md)。

## 当前显示差异

当前 Web 可能把 Run 的 cancelled、unknown 和 failed 都显示为 failed，工具取消也可能显示 failed。上表定义的结果含义不因此合并；仅凭这个标签不能判断副作用是否发生或能否重试。需要恢复时回到执行客户端核对对应会话和真实结果。
