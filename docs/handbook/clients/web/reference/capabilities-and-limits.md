# Web 能力边界

完整跨客户端对照见[能力矩阵](../../../capabilities.md)。本页解释 Web 的具体限制。

Web 当前是本机只读观察入口，可查看工作区、会话、History、恢复点信息、诊断日志、可用的模型上下文及 API 文档。

不提供 prompt 输入、会话创建、审批回答、取消、恢复、分叉、配置修改或执行控制。不能通过 API Docs 获得这些能力。

浏览器只使用当前服务授予的只读访问，不持有 Native 客户端凭据。会话地址不暴露工作区真实文件路径；查看内容仍可能包含敏感项目文字。

没有业务 WebSocket、SSE、离线缓存或后台同步引擎。History 的条件轮询与日志手动刷新见[更新规则](../guides/updates-and-connection.md)。不能将“没有流式连接”误写成“页面完全不会自动更新”。

未来客户端和功能不在本页预先承诺。需要执行操作时返回实际支持的 TUI 或 CLI。
