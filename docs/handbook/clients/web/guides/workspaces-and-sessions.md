# 浏览工作区与会话

侧栏空间行只显示名称，会话行只显示标题。会话数量、状态和更新时间在详情浮层中查看：首次悬停 500 毫秒后出现；浮层出现后快速移到其他列表项会立即切换详情，移开一段时间再返回则重新等待。首次等待期间移开不会弹出。键盘聚焦也可查看，Escape 关闭。

其他客户端新建的普通会话沿[自动命名](../../../features/sessions.md#自动命名)保存 AI 生成的可读标题；Web 读取保存结果，打开或刷新目录不会触发模型调用。

打开 Web 根页面查看工作区目录。首次可预取首个工作区的会话，其余工作区在展开时读取。客户端会自动读取后续页，直到读完当前结果；分页游标循环或快照版本变化时显示加载错误，不把不完整的前缀伪装成完整目录。

每个空间的列表按最新更新时间从新到旧排序，默认显示前 5 条会话；点击辅助文字色的“展开更多”每次再显示 10 条，不足 10 条则显示剩余部分，全部显示后按钮消失。收起空间后再次展开恢复为 5 条；各空间独立计数。这是已读取目录的分批展示。

详情中的状态和时间来自最近一次完整目录读取。未读取的空间显示“未加载”；已读取空间的数量包含全部根会话。会话详情区分原运行状态、是否活动、是否等待必需结果、排队工作和待输入数量。旧历史缺少更新时间时显示“未知”，排在有时间的会话之后，不使用打开页面的时间补齐；时间相同时保持目录中的原顺序。

点击会话或在会话行按 Enter 直接进入并读取历史及可用恢复点信息，无二次确认；方向键只移动列表焦点。侧栏不提供会话标题搜索。查看恢复点不代表 Web 可以执行恢复。

## 链接与返回

会话地址采用 `/sessions/<会话标识>`。可以直接打开有效的会话链接；浏览器后退从 API Docs 返回时应恢复对应会话，而不是重新扫描所有工作区猜测位置。

页面内导航不应重复创建独立连接或要求重新启动服务。链接中的会话标识属于当前服务的数据范围；复制到另一台机器或另一 profile 不保证有效。

## 加载与切换

快速选择 A 再选择 B，A 的迟到响应不能替换 B。加载失败显示错误，不伪装成空历史。会话不存在、不可访问或已删除时，回到目录重新选择；不要通过 Web 尝试重建它。

“刷新目录”同时刷新工作区和已展开空间的会话。读取失败时保留原已读条目，并标明当前读取失败；这些详情仍属于上次读取。页面隐藏或暂停时停止所属读取并关闭详情；重新可见或通过原页面身份核对后，重读目录和已展开空间。Escape 先关闭已打开的详情，窄屏中再次按下才关闭侧栏。

Web 当前不能创建、删除、重命名、恢复或分叉会话。需要执行类操作时使用实际支持的客户端，见[能力对照](../../../capabilities.md)。
