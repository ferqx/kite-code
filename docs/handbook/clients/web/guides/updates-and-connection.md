# 更新、刷新与连接

不同内容有不同更新方式。

| 内容 | 读取方式 |
| --- | --- |
| 工作区目录 | 进入目录时读取 |
| 工作区下会话 | 展开时按需读取 |
| 所选会话 History | 选择会话时读取；满足活动条件时增量更新 |
| Runtime logs | 进入标签页时读取，用户显式刷新 |
| 模型上下文 | 打开具体调用的 Inspector 时读取 |
| API Docs | 进入页面时读取本服务附带的规范 |

## 活动会话

只有所选会话处于 running/waiting 且页面可见时，History 按约两秒的周期读取增量，并更新会话状态。请求不会无界并发堆积；不要将此理解为逐 token 的实时流或日志也自动轮询。

切换页面或会话后，旧请求结果不能覆盖新选择。页面不可见时不承诺继续后台更新；回到页面后按当前状态读取。

## 连接失败

轮询失败保留最后已取得的内容并显示错误，不把错误伪装成空数据。Browser session 到期时，页面会通过同源请求建立替代 session，并将原读取重试一次；续建或重试失败仍显示连接错误，不循环重试。看到旧快照时先确认连接状态，不能将其当作最新执行结果。修复服务后重新访问或刷新页面，重新确认所选会话。

页面内导航不会结束浏览器访问会话；离开整个文档时会尝试清理浏览器会话。浏览器关闭不停止 daemon，也不取消其他客户端的执行。这里没有离线同步、自动重放写操作或手动 Disconnect 操作。

当前开发版本还有两项显示差异：首次直达会话时，目录旧状态可能遮蔽刚读取的新状态，导致活动会话未开始轮询；日志刷新失败也可能隐藏旧条目。先核对所选会话并重新加载，不能把旧状态或隐藏内容当成执行结束、数据删除或安全重试的证明。

服务重启或更换版本后，旧文档遇到实例身份不匹配会拒绝新响应并提示重新加载。重启可能改变地址；旧地址无法访问时运行 `kite web` 获取新地址，不自动迁移浏览器访问会话。
