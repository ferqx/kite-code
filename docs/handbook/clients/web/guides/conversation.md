# 阅读会话内容

History 展示用户消息、模型回答及可展示的工具生命周期。会话页面与桌面端共用布局与阅读交互，数据仍以 Web 接口允许的内容为准。助手回答支持统一排版的 Markdown 标题、段落、列表、代码、引用和表格，正文不增加内边距或独立限宽，与消息阅读列同宽；工具详情按需展开，普通用户与助手正文不重复显示角色标签。相对文件路径只展示文字，Web 不启动本地编辑器。

[工具消息结构与状态](../../../../plans/kite-client-experience.md#会话消息与工具渲染)复用共享渲染与明确终态；Web 继续只读，也不因共享设计获得 Public History 未提供的工具身份、分组、参数、stdout/stderr 或执行操作。缺少 Native `presentationGroupId` 时工具保持独立，不从安全 label 猜测探索分组。

Web 通过原消息 runId 和准确 Run 终态核最终回复及复制范围；助手正文和工具仍按历史顺序平铺，不启用 Desktop 的整轮过程折叠。有限状态目录外的历史 Run 可准确读取，缺能力或状态不可核时不提供整轮复制；不会仅凭 Session 状态或相邻消息推断最终回复。共享会话阅读不展示原始 reasoning 正文，Web 也不提供无准确 Turn 依据的“正在思考”轮次状态。

模型全文与原始输入读取不显示临时加载文案，等待由区域忙碌状态和原控件表达；完整内容仍须读取并校验后才显示，真实失败继续保留提示。

## 工具状态

同一次工具调用从等待、开始到终态应更新同一个展示项。完成后不能残留另一张 loading 卡。终态没有再次提供名称时，沿用此前已知的真实工具名称，不凭空补一个执行结果。

执行前 `rejected` 以拒绝提示说明原因，不显示不存在的退出码或 `No output`。执行后 `failed` 与拒绝不同，可能需要核实部分副作用。取消也不能被当成成功。

Ctrl+A／Cmd+A 只全选当前会话的可见消息内容，不跨到页面其他区域。消息正文可选中复制；侧栏、标题、按钮等其他展示文字不可选中。段落与列表项的选区限制在内容范围。消息区独立滚动，首次进入显示最新内容；向上阅读时不被新增消息拉回底部，可点击“回到最新消息”。在当前页面内切换会话后返回，恢复阅读位置和展开项；重新加载或离开页面后不承诺保留。

通用正式 Web 已发送的用户消息可逐条复制原文。悬停消息或用键盘聚焦复制按钮，成功后显示勾，两秒后恢复；失败显示重试提示，不把失败当作成功。复制保留原换行和字面量；隐藏页面、切换会话或消息正文变化后，旧复制结果不会更新新消息反馈。此操作不修改会话、调用模型或恢复旧任务权限。助手整轮复制须准确 Run 和最终回复身份，按本页末尾的完整正文范围执行，不能按相邻消息补造。

工具消息中可独立滚动的输出和文件差异，在还有内容可滚动的边缘显示渐隐提示。
工具详情展开和收起时有短暂过渡；系统启用减少动态效果时直接切换。

## 历史与更新

查看运行中会话时，内容可能按[更新规则](updates-and-connection.md)继续增加。终态会话不会因为页面停留就不断刷新所有诊断。

历史展示受当前接口允许的字段和内容范围约束，不包含全部内部数据。模型思考正文不在会话消息中展示；不要用 Web 与 TUI 画面不同判断会话数据丢失。

通用 Agent V1.3 的[只读 Web](../../../../../apps/web/README.md)对大模型回答先明确展示预览。点击 **Read complete recorded Model output** 后，完整正文经过原调用身份、字节数和 SHA 校验才显示；不完整模型流始终标为已记录的不完整前缀，不能当作完整回答或完整 Tool 调用。关闭、隐藏页面或切换会话会取消所属读取并回到预览，不停止模型或服务。复制与全选使用当前实际显示的完整正文；全文能力不可用或校验失败时保留明确预览与错误状态。正文不保存为持久浏览器缓存。

明确备份恢复生成新 Store 后，原会话及封存 Fork 中的大回答仍可沿原 Model 来源读取全文。当前连接负责只读准入，封存消息保持原 Store、Session、Run 与 Execution；来源或完整性无法核实时保留预览并显示错误。读取和复制原历史不会重新调用模型、执行工具或取得旧工作的执行权限。

Background executions 显示所选会话所属根范围的完整后台 Job 与子 Agent 目录，包括原执行、来源会话、原 Store、状态、目录游标、结果版本和已记录的投递事实。首次选择时读取，之后点击 Refresh background executions 显式刷新；刷新失败保留同目标旧目录并标 stale，不随 History 自动轮询。准确子会话提供链接进入其 History，不从标题猜测目标。

固定 Shell 身份可显示 Shell；其他 service/Job 按原 definitionId 显示，不从安全 label 补分类。目录未记录的清理确认和输出游标明确显示 unavailable；执行成功不表示已经确认清理。目录游标是分页序号，不能当作输出游标。点击 Read background output 按原 Session/Execution 读取完整已保存 stdout/stderr/progress，读取完成后显示真实输出上界，已记录缺口仍明确显示。关闭、隐藏、暂停或切会话取消所属 GET 并清除输出正文。Web 不发送运行中引导，也不停止后台执行。

通用Agent V1.3开发Web的文件恢复点面板只读原点目录、详情和原恢复ID状态。目录分页可刷新，没有固定历史快照；点可来自父分支，原Store/Session/Run身份与当前观察分别显示。详情按实际证据展示restore/remove/unchanged/conflict/unavailable，外部改动、受保护路径、未选中的恢复边界或缺来源保持原因。目录存在不等于可恢复。

恢复状态需输入准确原restore ID，只读取原journal与carrier；`restored` journal和`succeeded`执行分别呈现，pending/unknown不冒成功。v1旧记录不补造v2的顺序或确认后像。关闭、隐藏、切会话或编辑ID取消所属读取，迟到响应不覆盖新目标；这些操作不停止Job。Web不下载原像、打开本地文件、批准或执行恢复。

需要诊断事件时进入[日志](logs.md)，需要某次模型实际输入时进入[上下文检查](model-context.md)。

工具行与桌面共用轻量排版和无背景的 hover 高亮，详情按需展开已有的安全结果。Web 未取得明确工具分类或文件变更证据时保留通用结果展示，不从名称猜测 Shell／读取／修改，也不展示本地文件打开或审批按钮。

聚合内的 Shell 与独立 Shell 均支持展开已有输出；读取失败保持单行状态，不另起原始错误段落。工具字号与正文一致，图标随字号缩放。


已完成一轮 Agent 回复后，最后一段的“复制本轮Agent回复”复制该轮全部助手正文，按原顺序以空行连接；中途的普通说明也包含，思考、工具参数／结果和子 Agent 输出不包含。大正文若仍标为预览，须先明确读取该轮每段完整正文，才能复制整轮；关闭任一全文后按钮撤销。尚未结束、失败／取消、状态不可核或封存来源记录不提供此按钮；刷新历史可重试读取状态。隐藏、暂停或切会话不保留旧复制反馈或全文。
