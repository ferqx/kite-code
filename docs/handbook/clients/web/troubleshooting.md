# Web 常见问题

| 症状 | 核对与处理 |
| --- | --- |
| 地址无法打开 | 显式启动 daemon，检查 `server status`；TUI 不会自动开启 Web |
| 运行 Vite 后没有数据 | Vite 只是开发资源入口，使用根 `bun run server` 完整启动 |
| 会话列表为空 | 核对当前服务、工作区和 source/installed profile；Web 不能新建会话 |
| History 暂时不更新 | 确认所选会话 running/waiting、页面可见和连接正常 |
| Runtime logs 没有最新事件 | 使用日志显式刷新；它不跟随 History 自动轮询 |
| 直接会话链接不可用 | 确认会话属于当前服务且仍存在，回目录重新选择 |
| Inspector 不可用 | 确认打开的是支持上下文读取的具体调用；不要从其他调用补内容 |
| API Docs 有接口但无法执行 | 页面仅提供规范查看，浏览器权限与服务 capability 另有限制 |
| 关闭页面后任务还在运行 | 关闭浏览器不取消其他客户端执行；回 TUI/CLI 明确处理 |

提供故障信息时包含页面、目标会话、操作顺序、预期/实际和脱敏错误。不要提供浏览器凭据或未检查的模型上下文。
