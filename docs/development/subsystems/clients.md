# 客户端接入与展示

CLI/TUI、Desktop 与 Web 共用公开 Client 和有限展示事实。CLI/Desktop 的可信宿主拥有配套进程、资产与持久原意图；renderer 和浏览器不取得 Store/执行 authority。共享 UI 不扩大客户端的能力。

## 状态反馈规范

错误文案说明当前操作的失败和用户可执行的下一步。原因已确认时用短句说明具体限制，原因未知时简洁指出哪项操作失败。已完成的操作只有影响下一步时才写入错误提示。

有对应内容区的错误在所属区域反馈，表单校验显示在对应字段旁。没有对应内容区的操作错误使用现有 Toast。加载等进行中状态由所在控件或内容区反馈。

会话消息区的异常提示只用于会话执行循环中的异常，例如模型服务异常。审批提交、输入发送和设置保存失败使用 Toast。发送在获得失败或无法确认的结果后停止加载并立即提示，历史读取独立进行。会话文件卡展示已输出的文件和对应操作。环境信息的「参考」栏只展示文件链接和分页。真实会话消息、审批卡及已保存工具结果沿用原有展示。

### 桌面右侧文件预览

- 打开文件、重试和读取 PDF 新页面时，在预览内容区居中显示统一的加载图标。
- 预览失败在同一内容区反馈。可重试的通用失败显示「预览失败」和「重试」，每次点击只为当前文件发起一个预览请求。
- 格式、大小或访问权限等限制已确认时，显示具体原因。恢复操作与原因匹配，例如访问资格变化时提示关闭后重新打开。
