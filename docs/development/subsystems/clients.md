# 客户端接入与展示

CLI/TUI、Desktop 与 Web 共用公开 Client 和有限展示事实。CLI/Desktop 的可信宿主拥有配套进程、资产与持久原意图；renderer 和浏览器不取得 Store/执行 authority。共享 UI 不扩大客户端的能力。

## 状态反馈规范

先根据[客户端产品规则](../../handbook/README.md#客户端状态反馈)核对用户操作、可见结果和下一步。如果原控件或内容状态已足够，直接使用它。新增文字应补足影响用户判断或行动的信息。原因已确认时说明具体限制，结果未知时说明待核实的事项和可用操作。用于表达状态的控件继续提供对应的可访问名称和状态。

已知无法执行的操作先按下面的接纳前规则阻断，保留原内容，不先推进界面。其余错误有对应内容区时在所属区域反馈，表单校验显示在对应字段旁；没有对应内容区的操作错误使用现有 Toast。例行保存和其他管理操作用原控件的忙碌状态或输入限制表达，操作名称与布局保持稳定。加载等其他进行中状态由所在控件或内容区反馈。附件超限使用明确的提示框，不被通用 Toast 规则覆盖。

会话消息区的异常提示只用于会话执行循环中的异常，例如模型服务异常。审批提交、输入发送、设置保存和桌面管理操作的执行失败使用 Toast。失败后的字段输入和重试或核对入口继续留在所属界面。发送在获得失败或无法确认的结果后停止加载并立即提示，历史读取独立进行。会话文件卡展示已输出的文件和对应操作。「输出」栏展示文件链接、在资源管理器中显示文件的操作和分页。真实会话消息、审批卡及已保存工具结果沿用原有展示。

### 接纳前校验与草稿保全

保存、预览、运行和输入应先检查当前已知的准入条件；明确无法执行时先阻断，保留原页面和内容，不制造无意义的加载。前端预检不替代可信宿主校验，也不代表已执行或成功，最终状态以真实回执为准。

浏览器可导航地址照常发起加载，DNS、连接、HTTP 或页面加载失败在目标页面正常展示；不做网络可达性预探测，不为避免报错拦截正常导航或保留旧网页。

附件选择确认、拖放和粘贴共用数量、单件及合计大小校验；混合批次任一项超限时整批零添加、零不必要上传，以需关闭的提示框说明限制，保留原正文、附件、焦点和会话，不先插入失败附件。异步准备完成后、采用前再核最新额度、原会话与取消状态，迟到结果不得覆盖新稿、串入别的会话或复活已删除附件。其他错误不一概改成弹窗；已经接纳的附件后来失效，保留可识别原项及移除／恢复方式。

### 图片显示与原件保全

正常上传和 Agent 正常输出的图片均应可预览。大图优先使用有界的压缩或降采样显示副本，不改原图字节或 Agent 使用的内容，不以另设更低的预览大小上限代替合理预览。损坏检查、解码隔离与像素／内存安全边界仍保留，能力差异应透明说明。

### 异步提交的真实状态

本地尚未提交或明确未受理的失败，停止发送加载、保留原草稿，撤下临时发送占位，不在会话中表现为已发送；迟到失败不能覆盖后来编辑。结果未知时保留原请求身份、阻止重复提交，只查原请求，不推断成功或换 ID 自动重发。已受理之后模型、工具或任务执行失败，保留真实用户消息和业务记录，说明实际执行失败，不撤销已经发生的受理事实。分类依据真实边界与可信回执，不将所有异常一概当作未受理。

### 交互变更验收

- 对照每条文案出现前后的界面，核对其必要性、所属位置和持续时间。覆盖挂起、失败、恢复和重开，检查工具栏、输入框和主要按钮的位置，以及焦点、草稿和阅读锚点是否稳定。
- 覆盖数量／大小边界、混合批次及选择、拖放、粘贴等入口；核阻断时没有部分添加或不必要上传，原草稿保持。
- 覆盖取消、移除、连续操作、切换会话与迟到返回；核新稿不被覆盖、旧项不复活、结果不串页。
- 区分未提交失败、明确拒绝、未知、受理和受理后执行失败；核实际请求／效果次数与消息呈现，不把占位当成功。
- 覆盖最后已提交附件的冷恢复、损坏及容量失败；不自动发业务请求，不将尚未落盘的内容宣称可恢复。
- 观察消息先后、焦点、闪现与红字等全过程，不仅看最终截图；夹具故障与产品故障分别记录，未验平台与范围如实说明。

### 桌面右侧文件预览

- 打开文件、重试和读取 PDF 新页面先遵循接纳前规则；已知无法执行时保留原内容，通过检查并开始读取后在预览内容区居中显示统一的加载图标。图片能力按上面的显示副本原则处理。
- 已接纳后的读取、解码或状态变化失败在同一内容区反馈。可重试的通用失败显示「预览失败」和「重试」，每次点击只为当前文件发起一个预览请求。
- 独立文件预览进程退出后，释放对应视图并在原预览内容区显示「预览已中断」和「重试」。由当前文件标签发起重试，并重新核对来源与读取资格。
- 执行中才确认的格式、大小或访问权限等限制，显示具体原因；动作前已知无法执行仍先阻断。恢复操作与原因匹配，例如访问资格变化时提示关闭后重新打开。

实现和实际窗口验证见 [Desktop 办公输出文件](../../../apps/desktop/README.md#办公输出文件)。
