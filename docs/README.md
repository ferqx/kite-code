# 文档入口

- [产品手册](handbook/README.md)：产品用途、共享概念、各客户端完整指南与参考。
- [开发文档](development/README.md)：架构、实现入口、技术契约与验证。
- [有效计划](plans/README.md)：尚未完成的工作与待决问题。

产品预期与当前实现分开核对。手册不从旧 ADR 推测功能，代码文档不重新定义用户操作。具体职责见[文档维护](development/documentation.md)。

新用户从产品手册选择 TUI 或 Web；开发者按任务进入所属 workspace。历史材料仅在需要追溯时从保留 ADR 或 Git 定向读取。
