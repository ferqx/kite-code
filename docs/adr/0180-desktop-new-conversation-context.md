# ADR-0180：桌面新对话准备与本地环境选择

**Status**: accepted

**Date**: 2026-09-10

**Decision makers**: @chenchao

## Context

用户确认新对话是全局准备页面，首次发送才创建会话；项目和已有本地分支选择立即生效。现有桌面目录选择同时改变宿主工作区，前端只有连接后创建空会话入口；Runtime／App Control 没有分支切换接口，Web 仍只读。

## Decision

共享 React 页面负责欢迎区、输入和上下文菜单，桌面入口负责独立准备草稿及已授权回调。创建与首次发送继续使用现有 Runtime 命令，创建回执未知时保留本次 sessionId 供明确重连查询，不自动创建替代会话。

项目选择记录由原生应用数据目录中的单一文件保存，不参与工作区信任和 Session authority。目录选择与服务激活分开；分支查询、切换使用受限原生 IPC，目标限定为明确选择过的当前项目。切换前检查任务、释放自有 Service 并等待清理，原生再核实 Git 环境和用户改动，完成后读取真实状态并重新连接。

## Alternatives

- 点击新对话立即创建空会话：不符合用户确认的创建时机。
- 新增 Web 或通用 Runtime Git 管理协议：当前只有桌面本地用户动作需要，不扩大执行与浏览器能力。
- 自动创建 worktree、stash 或强制切换：用户明确选择当前目录分支切换，并要求保留已有改动。

## Consequences

新对话入口可在无连接时使用，但发送仍受真实项目、模型与信任约束。原生项目文件是本地选择偏好，不能推导文件执行权限。不同程序的 Git 操作不受单个桌面宿主锁协调；本轮通过发送前复查和切换前拒绝已观测冲突处理，不建立全局目录锁或自动重试。

实现、限制与验证见[新对话 owner](../../apps/kite-desktop/docs/new-conversation.md)。回退时撤销新入口和对应 Native commands；已有 Session／History 格式不变，项目选择文件不需要迁移。
