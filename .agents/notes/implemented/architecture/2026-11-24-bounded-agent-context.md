# Agent Note: 有界上下文与一次超限恢复

Status: implemented

## Problem

压缩曾覆盖最新 Tool 批次，后继决策可能收不到刚完成的准确证据。旧任务原文与已读资料也会持续占用窗口。供应商明确拒绝超长输入时，按普通重连处理会重复发送同一请求。实际 OpenAI 请求曾将 Skill 资料提升为系统级来源。

## Decision

摘要采用独立的覆盖和冻结上界，Tool 调用与结果按整批留在同一侧。待消费的工具和已纳入的结果优先保留。当前任务及显式前驱的原始输入沿实际来源保留，独立历史由摘要及近期记录交接。近期原文采用十五个百分点、最高 15000 token 的初始可选预算。已读资料和项目目录规则以任务引用及近期范围为依据。Skill 正文采用用户级指导，参考资料优先沿原 Tool 结果呈现，回填时用带出处的参考消息。

真实输入预算先保留本次输出和安全余量，维护水位服从该预算。供应商明确拒绝上下文超限时，只在取得更小且通过预检的请求后进行一次业务恢复。原拒绝、摘要和减量请求共享可冷恢复的决策出处。

接续原决策以封存时的历史和来源范围为准，决策之后完成的读取交给第一个新请求。原输入的真实性校验独立于窗口保留，失败、取消和中断的原输入作为带出处的历史保留。缩减估算计入后继窗口实际采用的来源，必要输入和摘要预留接近上限时先让出可选尾部。

获批计划的步骤完成事实有独立持久记录。真实复验曾在首次压缩后、回读计划前再次派发已完成的 Shell 写入。派发条件现在检查该轮采用的压缩点和模型实际收到的原 Tool 回执，进度核对进入原派发事务的读集。这样维持稳定计划来源及原批准摘要，同时让缺进度的新副作用等待可核实的 `read_plan` 结果。该边界以当前模型实际收到的证据为准。外部效果的逐步骤幂等需要在派发前绑定操作身份。 [Planning 实现](../../../../packages/agent/src/business/planning/README.md#计划与真实来源)

内置 Skill 读取由持有目标知识来源的适配器校验。Runtime 按原调用核对能力、输入和权限。已提交成功回执与历史共用冻结上界，兄弟调用均沿原决策。宿主证明走普通原生工作区路由的文件读取复核目标适用的来源，效果工具和受保护分支保留完整派发证明。这样能在保持文件、权限和真实业务回执边界的同时，避免无关知识变化使读调用作废。

同源内容变化后，原根普通 Model 只有在持久证明未派发且无派生效果时才能退役。已提交的退役记录可经再次冷开恢复，在同一 Run 只得到一个对应后继。拒绝用通用重试或已应用引导标记表达该边界，因为这会混淆原执行效果、用户输入归属和供应商重连计数。 [冷恢复 owner](../../../../packages/agent/src/storage/sqlite/run-resume.README.md)

退役前已受理的引导沿真实输入事务应用，工具批次从实际成功 Model 的 Step 获取归属。后继 Model 已采纳的同源 Skill 内容由原封存来源证明接续，首次 Run 的配置仍提供原 CAS。最窄窗口采用的可选预算随摘要点发布，恢复时复用这一预算。目录摘要只纳入模型可见字段，已采纳正文和资料分别保有自己的内容身份。

超限恢复以原拒绝为一次业务派发的边界。普通维护失败和因新输入而作废的摘要可以各自结算。确认未派发的摘要先结束原尝试，再准备新摘要。已发布摘要继续使用原身份。

本决定细化[原压缩发布决定](2026-10-02-recorded-context-compression.md)的覆盖范围、原输入保留和容量边界。原 Model ledger、不可变历史、低权限摘要、取消及恢复证明继续适用。

## Alternatives considered

- 继续覆盖整个输入，以摘要保存最新工具结果。摘要会遗漏精确值，也无法替代供应商所需的调用与结果配对，因此保留最新交互。
- 持续保留全部旧任务输入和读过的资料。可用空间会随历史增长而减少，因此依实际工作关系及近期预算保留。
- 继续使用统一模型重连处理超限。明确超限会重复触发同样的拒绝，因此只发送一次通过减量校验的请求。
- 通过提高 Skill 权限保证指导生效。参考内容会影响用户纠正的优先级，因此按用户指导与参考出处组装。
- 从全量来源比较中扣除同批刚读到的 Skill。项目指令等其他来源更新仍会阻断独立读取，因此由实际知识适配器复核此次目标。

## Consequences

当前实现由同一个 Runtime 和原 Store 发布事务处理。原请求与执行记录继续可查，维护期的历史摘录只进入摘要调用。受控 SDK 覆盖超限、保护区放不下和恢复边界；真实 OpenAI 场景验证了连续压缩后工具配对、Skill 来源、子 Agent 回报及任务续接。复验另覆盖读取 Skill 后强杀并续作、未声明模型窗口时实际标题发布，以及摘要落盘前后分别恢复。 [Core owner](../../../../packages/agent/src/storage/sqlite/context/compression.README.md) · [Service owner](../../../../apps/service/README.md)
