# Agent Note: 独立文件预览的中断与位置订阅

Status: implemented

## Problem

图片和普通文件的独立 Electron 视图在进程退出后仍占住预览内容区，宿主缺少恢复入口。视口静止期间，位置同步继续读取全套布局，尽管重复测量不会发送新位置。

## Decision

Main 监听独立视图的进程退出，按活跃实例匹配并释放对应资源，通过已有预览展示事件通知宿主原预览 ID 和连接代次。交付文件和原路径引用对准同一身份后在标签中提示中断，由用户重试并重新核对来源和读取资格。办公子帧继续沿用自己的退役通知。

预览订阅尺寸、滚动、可见性和布局变化。拖动和面板宽度动画期间按帧跟踪位置，沿用既有同步 IPC；静止期间合并事件并按原次序确认几何。首次显示和原生窗口重新显示继续触发直接测量。

## Alternatives considered

- 保留连续位置采样。它能覆盖未声明的任意样式位移，代价是静止期间每帧仍要测量视口和祖先布局。
- 仅订阅视口尺寸。平移可以保持尺寸，拖动或进入带动画的布局时需要连续核对原生视图位置。
- 进程退出后自动重建。文件或读取资格可能已变化，用户在原标签内明确重试能保留当前阅读上下文并控制何时重新读取。

## Consequences

重试事件和几何写入都使用原预览身份，新标签只消费自己的事件。新加入的位置动画若能改变视口且不改变尺寸，需要进入相同位置订阅边界。办公子帧隔离的适用范围见[原决定](2026-11-24-office-preview-iframe.md)，实现和窗口验证归[Desktop owner](../../../../apps/desktop/README.md#办公输出文件)。
