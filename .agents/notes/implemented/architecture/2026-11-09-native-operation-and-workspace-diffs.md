# Agent Note: 单次文件操作与 Git 工作区差异分开阅读

Status: implemented

## Problem

用户要求会话中的 write_file／edit_file 显示每次操作差异，同时明确右侧文件变更应包含整个仓库当前分支的工作区变更，并要求考虑大文件。原成功回执已有差异与完整快照，但 Native 工具行未连接差异槽，详情优先读快照，右侧只枚举工具历史。历史操作、当前工作区与完整历史版本是三种不同来源；混用会遗漏用户／Shell改动或错误归因。旧预览先输出整个共同前缀，也可能在真正修改前耗尽预算。

## Decision

会话工具沿原成功 Execution 身份取得有限观察 ID，展开才读取 `fileChange`；历史全文显式选择 snapshot，不能替代diff。右侧单独由可信 Main 读取登记 Workspace 所属Git仓库相对HEAD的最终工作区变化，独立保留暂存与未暂存状态、未跟踪文件，不声称作者或Agent贡献。此决定部分取代[原迁移决定](2026-10-08-native-file-change-receipts.md)的侧栏用途与预览算法，原操作来源、恢复、失败／unknown、编辑器与权限边界仍适用。

大文件采用确定的预算与懒加载：操作预览游标扫描、有限前瞻和上下文，不构造整份编辑脚本；输出字节／行／单行限额由[Files owner](../../../../packages/agent/src/tools/files/README.md#逐操作文件变更预览)维护。Main Git先读有限状态，再按需读单文件有限差异；所有触及工作区内容的Git命令在私有临时配置／HEAD／索引副本下运行，不加载原可执行过滤器配置。过滤器、特定attributes和分离索引暂时明确拒绝，子模块不递归；仅禁用extdiff／textconv不足以防止clean/process在status中运行。正文渲染另作防御上限，历史Artifact没有范围读取接口时先按元数据拒绝超过显示预算的全文请求。所有截断或不支持状态明确显示，文件实际写入和完整快照不受预览额度改变。

## Alternatives considered

- 仍将成功工具列表作为右侧总变更：不能涵盖用户、Shell或其他工具的工作区变化，不符合本次明确要求。
- 用Git当前内容重建每次操作：缺少当时前像，也会随独立后改而变化，继续拒绝。
- 每条消息直接内联完整快照或全仓patch：成本随历史和仓库增长，且快照不表达本次增删；采用按需、有界只读观察。
- 首个接线阶段保留原ScrollArea与红绿行，未引入完整编辑器。用户随后确认了参考图中的只读双栏、目录树与保留上下文折叠，按[有界参考差异视图决定](2026-11-09-bounded-reference-diff-view.md)实现；无限展开、文件编辑与新的执行权仍不引入。
- 在预览层使用无限LCS或扩大64 KiB预算：无法给出稳定资源上界；采用有限匹配并说明不代表最小或全局增删统计。

## Consequences

历史差异和右侧工作区可以不同，这是来源差异而非同步错误。首版Git状态只在手动刷新、重新聚焦与会话新增消息时读取；用户随后明确要求打开标签后持续同步，此刷新范围由[可见工作区同步决定](2026-11-09-visible-workspace-diff-refresh.md)部分取代。历史操作与当前工作区仍保持不同来源。大文件、二进制、冲突或不安全范围可能只能看到状态和明确原因；完整内容仍保存在原文件或Artifact，不为了界面重放操作。没有工具／协议版本升级，没有Git写入或贡献归因。

当前实现和验证入口归[Desktop owner](../../../../apps/desktop/README.md#原文件变更面板与编辑器)，用户语义归[桌面手册](../../../../docs/handbook/clients/desktop/README.md)。DOM、Git夹具与浏览器组件证据不代替完整安装窗口、真实原生写入或其他平台资格。
