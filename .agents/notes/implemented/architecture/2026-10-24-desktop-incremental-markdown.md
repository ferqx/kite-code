# Agent Note: 桌面流式正文按元素复用与新增文字渐显

Status: implemented

## Problem

用户要求桌面Agent回复在追加新文字时保留已渲染内容，并用渐显使新增文字平滑出现。原消息级memo无法避免同一条回复每次追加都渲染全部Markdown组件；整条源码Context还会使未变化的代码组件更新。简单按空行冻结前文则可能丢失后补链接定义、脚注、列表延续或围栏闭合带来的语义变化。

## Decision

2026-10-25，本文的逐字span与opacity机制由[绘制层渐显决定](../bug-fix/2026-10-25-streaming-text-paint.md)替代，以修复流式与最终正文的字距／换行差异。下述整文语义、元素memo、读取准入、缓存及逐字节奏继续适用；逐字span段落保留为该次实现的历史理由，不再指导当前文字排版。

保留原固定parser与完整消息上下文，在安全的HAST生成后设置无DOM包装的元素memo边界。比较可见内容、属性与围栏闭合事实，忽略源码位置及一次性动画提示；未变化元素跳过组件渲染，语义改变的元素照常更新。解析与KaTeX语义处理仍按整条消息执行，不宣称已实现增量Markdown解析。代码块不再订阅整条源码Context，闭合事实由该块的数据传入。已有[桌面Markdown扩展边界](2026-10-22-desktop-markdown-content.md)继续适用。

渐显限于已提交、可读的流式消息的新追加普通正文。用户指出按每批run整体渐显仍像逐段输出后，改为每个完整字素单独span与240ms透明度0→1原生动画；通常相邻字错开18ms，跨行内Markdown节点保源顺序，较大批次压缩间隔使等待不超过180ms、整批不超过420ms。延迟阶段使用backwards填充，排版与正文立即提交，不建立逐帧React状态或累计打字队列。已有run及字节点保持，动画完成释放引用；组合emoji与附加符不拆字。代码、公式与图表继续由各自组件负责。动画完成或取消释放监听，组件卸载取消动画，Activity重连不重新启动；减少动态效果、隐藏、历史首次呈现、缓存返回和非追加正文纠正直接显示。

连续性取自上一次已显示的同挂载正文，渐显资格只核当前读取准入。普通IPC校准会短暂撤销读取，不能以“上次也可读”为新增动画前提；真正Activity隐藏／重连仍清除连续性。该区别只影响展示，不恢复读取、复制或文件操作资格。

2026-10-25接入远端的自动全文读取后，Native将同一原Store/Message/Execution的已核验正文与当前copy证明分开：新版本自动读取时保留旧阅读和prepared树，不闪回短预览，撤销旧正文文件入口，复制仍由原ModelOutputMessage当前核验回调控制；首个自动全文填充不播放历史，使用`streamingReveal:false`建立后续追加连续性，之后自动核验的增量同样逐字渐显。显式手动全文保持静态，切换原身份或Activity隐藏清理保留引用；不缓存整个旧snapshot或把旧正文视为当前完整证明。

## Alternatives considered

- 按空行拆成独立Markdown文档并冻结前块：会失去跨块引用与脚注上下文，列表和围栏也可能继续改变，未采用。
- 每批文字对整条消息执行透明度动画：会使已读内容反复变淡，无法满足已显示文字稳定的要求。
- 只缓存整条消息或固定tag组件的浅props：正文追加会改变整条消息，Markdown每轮也会产生新的children对象，无法跳过稳定子树。
- 以React计时器逐字推进：引入额外渲染和队列，快速生成、取消或隐藏时容易积压；采用仅新增字素的浏览器动画。
- 每批新增run整体渐显：初版可平滑追加，但用户实际观察仍是逐段出现，不能满足逐字渐显；改为字素级错开且限制整批等待，不为大批次引入长时间动画积压。
- 同时要求上一次和本次读取均准入：初版即时bridge夹具将loading与complete合批，掩盖实际IPC中间状态；用户反馈后加入45ms跨任务读取复现动画为0，因此改为当前准入与已显示正文连续性。异步夹具与Electron证据归Desktop owner。

## Consequences

新增边界只属于桌面共享展示及Native适配，不改变Service事件、业务消息、复制来源或读取权限。稳定元素组件避免重复执行，但整条消息的语法解析和HAST转换仍有成本；文字run占用当前正文节点，离开后的保留继续服从原会话DOM缓存预算，不增加全局React节点缓存。实际验证和适用环境归[UI owner](../../../../packages/ui/README.md#markdown-消息内容)与[Desktop owner](../../../../apps/desktop/README.md#会话消息渲染验证)，不由本Note推导安装版或其他平台资格。
