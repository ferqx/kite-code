# Agent Note: Reuse large History projections through private disk pages

Status: implemented

## Problem

移除 History 的累计读取额度后，生产 worker 仍无法缓存超过 32 MiB 的完整投影。每个协议页都先重建整份历史，再选择本页记录。50,001 条、超过 40 MiB 源事件的 98 页读取在本机需要约 50 秒；分项实测中建库只有 0.31 秒，分页读取为 49.95 秒。页数乘以完整历史解码、投影和摘要工作，导致合法大历史的实际读取成本随规模迅速增长。

## Decision

生产 History worker 首次在一个 SQLite 只读快照中完成原有全量投影和摘要，随后按已有协议分页规则写入私有文件。内存只保留页的 sequence 上界、字节位置、页摘要、metadata 和当前页缓冲。后续请求先从同一只读事务重新核对 root 或准确父子范围、固定水位和 Store 内容代次，再按索引读取文件并验证页字节摘要；任意合法游标可以从页内继续，当前 Session metadata 重新进入协议字节核对。

内容代次相同时不重新扫描来源。Store16 增添 Session 实例身份、改写代次和不随删除回退的历史追加水位：纯尾部追加不推进改写代次，UPDATE／DELETE 或旧序号内 INSERT 必须推进它；删除重建 Session 生成新实例身份。每次命中在同一只读事务重验这些证明，因此运行中每页前都有追加也无需再哈希完整前缀。旧读取端口缺少该证明时，仍以原始固定前缀摘要核对；证明缺失或水位内改写则重新投影。原投影摘要继续约束跨页完整性，旧摘要不能通过缓存绕过内容变化。磁盘快照不取得执行权，不是第二份持久 Store，也不跨 worker 重启恢复。

父进程原子创建每个 worker 的私有目录，在 POSIX 上权限为 0700；页文件以 exclusive create 和 0600 写入，完成后才发布页索引。读写 FD 均在当次操作内关闭。worker 正常 EOF 清理文件；取消、失败、超时和关闭由原进程池结束 worker，父 owner 确认其退出后回收整个目录，强制结束不依赖 worker 自行运行 finally。快照以 30 秒空闲期限和 256 个 LRU 条目回收，不施加单份或累计正文大小的读取门槛。文件丢失、写入失败或证明不可用时回到来源读取。

这部分替代[原内存 transcript 缓存决定](2026-09-28-bound-history-transcript-cache.md)在生产子进程分页路径中的保留机制；直接注入的非 worker History adapter 仍使用原内存缓存，原有范围、水位、摘要和兼容恢复理由继续适用。

## Alternatives considered

- 提高或移除完整投影的内存缓存字节阈值：未采用。多个长历史会常驻大数组，依然把跨页复用与正文内存容量耦合。
- 每页仅从 SQLite 游标独立投影：未采用。旧历史归属修复、交互状态和恢复 metadata 依赖完整选定前缀，独立分片会改变当前读取契约。
- 持有完整投影并保持跨请求 SQLite 事务：未采用。长时间客户端等待会延长只读事务，取消和同水位改写也更难沿既有 owner 收敛。
- 只按固定水位复用磁盘页：未采用。同水位改写、子会话重挂和 metadata 更新必须在每次请求重新核对。

## Consequences

同代次或 Store16 纯尾部追加的全量解码、投影和摘要只做一次；后续成本随返回的页正文增长。首次投影仍需要与完整历史相应的实际内存，缺少新证明的旧端口在代次变化时仍需扫描原始行。淘汰、取消导致 worker 重建、文件损坏或实际磁盘容量不足时可以重新生成；临时缓存清理失败不替换合法来源读取，不承诺任意规模的固定内存或固定延迟。

2026-09-30 本机同一 50,001 条／98 页 SQLite 用例，分页读取由 49.95 秒降到 1.09 秒，测试总耗时由 50.29 秒降到 1.43 秒；首个页面 0.79 秒，后续 97 页合计 0.30 秒。该受控结果包含生产子进程和管道传输，未包含 Desktop 渲染或其他平台资格。

继续核对运行中分页后，20,001 条／40 页、每页前追加一次的续页合计由 1,865ms 降到 121ms，静态历史续页为 118ms；50,001 条大历史回归也改为每次续页前追加，完整读取约 1.01 秒。测试不把静态快照加速当作运行中历史的证据。Store15→16 只在私有候选中转换，完整核对旧行、约束及触发器，原来源不原位修改；见 [Store16 回归](../../../../packages/runtime-storage-sqlite/test/kite-session-store15-to16.test.ts)。

验证入口：[大历史回归](../../../../apps/kite-service/test/isolated/history-large-sqlite.test.ts)核对全部记录、固定摘要、同一文件复用及后续页面的相对耗时；[磁盘页缓存回归](../../../../apps/kite-service/test/history-page-snapshots.test.ts)覆盖同代次无来源重扫、追加后只证明一次、丢失文件重建和未知代次回退；[真实子进程回归](../../../../apps/kite-service/test/isolated/history-page-pool.test.ts)覆盖任意游标、metadata 刷新、追加、同水位更新／删除、父子范围变化及取消／关闭后的私有目录清理。当前负责文档见 [carrier owner](../../../../apps/kite-service/docs/runtime-server-carrier.md)。
