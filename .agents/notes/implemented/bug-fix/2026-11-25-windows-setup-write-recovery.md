# Agent Note: Windows 安装写入冲突与失败回收

Status: implemented

## Problem

Windows 首装写入包内文件时，暂存目录里出现同名文件可触发 CREATE_NEW 失败。由于部分树缺少已确认的身份清单，后续收尾会保留它，并以通用关闭未知错误代替原写入错误。本机曾用插入同名文件的方式复现相同提示。

## Decision

受管安装仅在本次私有解包暂存目录覆盖已核实的同名普通文件。冲突时写入和刷盘新的同卷文件，再替换原路径。写入过程中记录实际文件和目录的身份。失败后沿原删除 owner 核对身份与有限库存并确认关闭，随后在结果页显示原错误代码和回收结果。

## Alternatives considered

- 打开同名文件后直接截断。这样会就地修改原对象，原对象的其他引用也可能受到影响。
- 枚举暂存目录并删除全部内容。这样无法区分本次写入的对象与中途出现的未知对象。

## Consequences

确认回收失败时保留无法核验的数据。覆盖与回收限于候选解包阶段，仍依赖完整验证后才发布可启动候选。发布后的短暂共享占用恢复沿用 [Windows 暂存清理决定](2026-11-15-windows-setup-scratch-retry.md)。安装流程与实测归 [Native 发行 owner](../../../../apps/desktop/docs/native-release.md#构建与安装)。
