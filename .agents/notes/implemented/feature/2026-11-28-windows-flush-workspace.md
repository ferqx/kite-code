# Agent Note: Windows 会话工作区贴合工具栏

Status: implemented

## Problem

独立顶栏与三栏工作区之间的色差、圆角切口和淡描边，使会话看起来像放在窗口内的另一个面板。两侧和底部的 6px 留白进一步露出窗口底色。用户要求工作区与顶栏连成同一个平面。

## Decision

[Native 窗口样式](../../../../apps/desktop/src/native-tailwind.css)让 Windows 会话工作区贴齐顶栏和窗口边缘，移除三栏外沿的圆角、描边与阴影。导航和会话分别延续各自底色到正上方的顶栏区域。采用 CSS 锚点跟随真实导航宽度，左侧材质连续绘制一层以避免重复叠色，右侧使用[会话内容主题](../../../../apps/desktop/src/native-content-theme.css)。左栏开合和调宽无需额外同步宽度。左右分隔线、面板裁切和右栏的共同宽度分配继续沿[三栏布局决定](../bug-fix/2026-10-20-session-content-frame.md)。Mica、Acrylic 与实色的选择沿[Windows 材质决定](./2026-11-25-windows-acrylic-layout.md)。

Windows 顶栏同时承载会话标题和操作。会话标题左对齐，按顶栏分隔条和标题槽位置计算内距，左侧导航控件占用空间时从它们之后开始。搜索固定在前进按钮之后，侧栏开合期间也保留同一个搜索入口和焦点恢复目标。顶栏与正文位于不同的定位容器，窗口宿主在尺寸变化时同步标题和下边框的位置。下边框从正文左缘开始，贴着侧栏分隔条右侧。侧栏展开时，顶栏在同一坐标延续正文区的侧栏分隔线，左侧导航背景保持连续。侧栏收起时，顶栏的分隔符和标题回到默认侧栏宽度对应的位置，左侧分隔符复用右侧的居中短竖线样式。侧栏重新展开后，顶栏恢复按实际宽度对齐，正文按实际侧栏宽度重新分配空间。宿主按系统窗口按钮的覆盖区留位，[共享会话页面](../../../../packages/ui/src/desktop/SessionPage.tsx)仍拥有标题、标签及环境信息操作。将现有标题树挂到顶栏，避免维护第二套导航状态、按钮和焦点恢复。正文按零标题高度计算，页脚继续测量实际高度。

## Alternatives considered

- 只移除工作区装饰。透明顶栏和实色会话仍会形成色带，无法得到连续的背景。
- 改用全窗口实色并移除玻璃。统一顶栏与会话底色已经足够，左栏可以继续保留玻璃层级。

## Consequences

三个 Windows 材质分支使用相同的满宽几何，Native View 的布局测量照常读取实际面板尺寸。Windows 工具栏使用实色，系统窗口边缘仍由宿主绘制。当前行为与验证见[桌面手册](../../../../docs/handbook/clients/desktop/README.md#配置编辑交互)和[Desktop owner](../../../../apps/desktop/README.md#windows-原生-mica)。
