# Agent Note: 桌面计划执行进度和回看

Status: implemented

## Problem

用户在实施期间需要知道正在执行的步骤，同时希望聊天正文和输入位置稳定，完成后可以在原轮次核对步骤。

## Decision

在桌面「环境信息」里展示原 Run 当前获批方案的进度。标题定位原计划文档，步骤列表默认收起。当终态结果进入聊天且步骤记录可回看时收起常驻进度。正在展开阅读时，保留到用户收起列表或环境卡。原轮次摘要提供只读回看。

## Alternatives considered

- 在输入框附近常驻步骤会挤占提示词、排队消息和业务审阅的位置。
- 每次进度更新插入一条消息会移动聊天阅读位置。环境卡提供稳定入口，聊天保留原计划正文和结果。
- 用当前计划恢复旧轮次会串入后续版。历史按原轮和已批准的准确计划版本读取。

## Consequences

Run 终态和最终回复分别到达。聊天中原轮的终态结果和可读历史接管实时进度，已经打开的列表可以继续阅读。同一会话暂时读取失败时保留最后一次已确认的进度。后续 Run 复用同一计划版本时，原轮回看使用原批准和已提交的原步骤修订。产品入口见[计划手册](../../../../docs/handbook/features/planning-and-tasks.md)，实现与验证归[Desktop owner](../../../../apps/desktop/README.md#native-计划入口与完整审核)。
