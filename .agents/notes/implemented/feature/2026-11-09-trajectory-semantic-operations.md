# Agent Note: 轨迹以逻辑操作表达对话执行过程

Status: implemented

## Problem

直接把 Model、Tool、Job、child 和 Context 各自映射一行，会把一次模型重连、一条后台命令及一次协作任务拆成多个看似独立的工作。即使加上折叠，用户仍难从提示词、实际模型输入、工具操作读到最终回复。用户确认以有意义的逻辑操作组织主列表，过程与重连放所属详情，完整底层事实继续保留。

本决定部分取代[原工作台决定](2026-11-08-trajectory-workbench.md)的顶部四项过滤及逐对象出行方式，以及[分型详情决定](2026-11-08-trajectory-node-details.md)中默认只看单个对象和压缩两行的展示后果。右侧标签入口、调宽、窄栏覆盖、固定历史位置、原事实独立身份和材料授权仍沿原决定。

## Decision

- 主过程以原Run作为唯一Agent loop，不另加一层loop。用户进一步确认除子Agent外均同级平铺，移除决策包装阶段；原Model保隐藏材料owner和原身份，旧选择／标记定位映射思考阶段。originalParentId保平铺前逻辑父级，原树与operation.members保完整原关系，只有child carrier与其child Run显示嵌套，child内部同样平铺。Run状态只用原Run生命周期，思考、工具和输出保原各自状态。系统、用户上下文、思考和输出是准确材料切片，不是新事实；独立消息优先去重，旧请求上下文不冒充当前唯一用户消息。普通概述去父级和内部绑定ID，关系仍在原始记录。
- 内容详情按阶段区分：系统提示词与当次公开工具目录分别成Tab；输入和回复直接内容，思考与请求信息分开，真实工具参数与结果分开。按用户后续确认移除所有节点的原始内容Tab，原事件、父关系与获准材料继续保存在底层并沿现有导出规则使用；旧raw状态回节点首个合法Tab，不触发原始内容读取。保留准确public request.tools，不用今日registry／内部assembly或截图中的工具名补目录。
- 当前视口最多四个原模型请求获准读准确输入／输出，列表与详情使用独立材料owner；共享交集只在原source／scope／revision和完整target一致时保留，换源、断线、旧版本、迟到与租约关闭约束不变。实际provider名称优先原公开display，旧记录仅从同次已读metadata回退；不把request.modelId的内部绑定当名称。可展示reasoning直接可读，私有和压缩思考不开放。
- 在原完整事实树之后增加纯展示归并。仅准确原 Store／Session／Run 的线性重连前驱链合成一个稳定思考主行，初始请求不算重连。原尝试和各自输入／输出可在详情选择；独立模型决策、同名重新执行及缺关系的记录不凭名称或相邻时间合并。
- Shell 的准确启动 Tool、原 Job 与 read／wait／stop 观察归同一命令。主状态取真正执行者，观察成功不覆写任务结果，停止申请不等于停止终态。子 Agent 的原委派／carrier／child 关联到这次工作，稳定 Agent 的后来新工作不并入旧任务。压缩生成和准确采用归一条展示操作，原事实不改写。
- Run仍按本Run直接范围保存summary，用户后续明确移除主列表轮次行右侧统计及其悬浮文案，展开／折叠／筛选均不常驻显示；轮次详情和准确child内部摘要继续可读。逻辑Agent处理按准确重连链计一次，工具操作按原Shell工作计一次，不冒充实际网络attempt／Tool请求数。子任务、审批和压缩分别统计，用户消息与Agent回复另列、不混执行动作；child内部只计其准确已准入子Run。筛选改变命中小计，局部折叠和子scope加载不改变主Run计数；底层事件与成员不裁剪。默认只在筛选生效时显示一次匹配数量，上界和事实覆盖核验状态由轨迹信息按需查看，祖先数量及时间轴右侧泛化解释不常驻；真实读取失败和legacy材料缺失说明保持。
- 同一真实Run内紧邻两个逻辑请求，仅在准确input均已准入完整available且原system与public tools完全一致时标“沿用系统准备”，确证不同时标“系统准备已更新”。缺材料、部分材料或超预算无法比较不分类，不补看当前配置、不预读全部历史、不留正文或指纹cache。提示不隐藏行、不改38px行高，仍能进入当次准确快照。
- 后续去噪按准确来源而非Provider角色区分：完整已核实请求中当次会话文件清单与准确Run的Planning runtime不再当用户消息；用户粘贴、早期同文历史和图片保留，旧混合材料中性称本次请求上下文。有意义的项目指令、方案与压缩摘要不因角色为user就删除。
- 自动审批checker只有准确原authorization.check Command、同Store／Session及原父Tool／Job共同证明时归一条审批，不造Agent输入／思考／输出阶段；自动批准或拒绝可能根本没有Interaction，因此必须保留其唯一检查结果。有限工作树／浏览器支撑Job仅双方成功且准确同Run父工具已承担结果时省略默认行；运行中和异常保持。没有任一原attempt材料的空切片省略，thinking原状态与旧材料入口继续可达；不依赖正文载入动态删行。
- 第一方闭合 display 只封存原 owner 核实的有限公开操作名、显式 Shell 描述、安全目标、消息摘要与准确关联。消息摘要至多 160 字符，来自原公开正文；没有 inline 正文就不展开私有 checkpoint 补摘要。命令全文、系统提示词、结果全文、权限和 transport 继续在准确材料边界内。Trace schema 与 Service 投影排除 display；默认事件导出可以含有限公开摘要，不能称其完全没有摘录。
- 输出存在性由原事务封存可选第一方 `outputPresence`，只含正文存在性、原工具调用计数、完整性与准确Evidence绑定；Model与canonical assistant Message分别绑定自己的材料。Artifact计数取登记描述符，不用可能为空的preview；不展开正文、不回填旧事实。只有准确同源、完整成功的工具调用独占输出才精简可见输出行，原byId／材料继续可达；生成中无正文由thinking承载，正常正文、空白正文、空完成和未知／异常区分，旧尝试有正文或未知仍保历史入口。思考正文页按用户后续要求移除跨到公开输出的按钮和材料来源编号，直接呈现思考；准确输出仍由对应输出行与历史入口读取。统计和时间轴同步省略同一空消息，原Agent逻辑处理不变。材料载入不影响行结构；真实事实接管仅同源向前且控制未变时按原行和行内偏移保持锚点，不覆盖seek、折叠或返回最新。
- 分型详情按关键指标、可读内容、记录计时组织。思考首页用准确原事件的状态、真实模型和显式Token，0值保留、合计不推算；长思考可局部展开，请求设置仍归request_info。单次原member及所选sequence截止的记录区间不等于Provider生成耗时，也不以重连总span代替；没有首Token时戳不造TTFT、生成时长和吞吐。旧观察概述同样截止状态、退出码及子任务交付，显式不存在的观察不回退最新名字或材料。工具结果按typed类型突出唯一结果，次要成功回执折叠，独有异常诊断主区域可读；只与同一typed正文逐字相同才省重复。明确空正文、未知／部分和MCP null／false／0继续区分，压缩主容量明示本地估算。
- 按用户后续确认，顶栏仅保留时长坐标切换，移除轮次、调用、子调用三个全局展开按钮；轮次与子Agent保局部箭头，历史展开状态继续读取。筛选菜单只保留消息、思考、工具、子 Agent、自动压缩和审批六种类型，工具与子Agent独立控制；旧时长、轮次和层级筛选在Panel归一化为全部，底层Workbench契约不删除。命中路径临时展开，原选择和材料版本继续保留。
- 系统、消息与思考分别使用阶段专属Tab；其内容按实际保存请求分组，不从当前文件或配置重建来源。真实工具保留概述／参数／结果，审批、压缩和子任务等保留适用的概述／预览；不恢复通用生命周期界面。概述默认突出状态、耗时和适用业务结果，来源文案与正文上方重复caption不再展示，记录时间与计时口径在内容下方按需展开，压缩触发与计数口径收进压缩信息；这些按需信息不恢复raw入口。
- 在线展开子任务时，按原 carrier 证明的直接 child Session、准确 Run 和原实体命名空间另读，所有范围固定在父 cursor。仅为展示拼接已获准子投影并命名空间化展示 ID，原身份、事件及材料 owner 不变。关闭／换源／断线取消读取，已读同源 metadata 可保锚点；正文在重连后必须重新准入，不能借父 Snapshot 或无 Run 的子 Snapshot 读取。

- 请求边界按用户纠正与官方参考实现收拢：小圆点放在准备／上下文与模型返回之间的节点间隙（普通请求优先thinking行上沿），不是节点自身标识，不新增树层级或日志行。它选择独立请求owner，概述／选项／用量／计时四Tab沿该请求原Model member、观察截止与准入材料读取；普通思考只保正文与准确历史内容，旧request_info迁移回thinking，不再混请求指标。含准确Model的压缩操作也有一个请求点，仅context采纳／发布不补造请求；重连链仍一个点。线段只表示同准确Run阅读顺序，scope／省略／缺身份处断开，不按邻近请求猜工具因果或后台工作结束。用量与计时不读正文、不累计别的请求或工具数据；结果导航只用准确可见reply／同原身份Message，工具专用空输出不出占位入口。请求选择／Tab／观察是独立展示态，在线离线合并须纳入同reader和同详情门禁，旧回调不能跨模式改写选择或阅读位置。

参考：[DeepSeek 请求分隔与独立选择](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-trajectory/src/client/TrajectoryTable.tsx#L566)、[四Tab](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-trajectory/src/client/TrajectoryTable.tsx#L239)、[压缩请求](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-trajectory/src/client/layout.ts#L355)。仅参考展示语义，原始归属、材料授权与计时口径沿本仓库合同。

## Alternatives considered

- 只隐藏更多事件：保留了一个操作多个主行的问题；需要逻辑归并而不删事实。
- 直接隐藏全部自动审批模型：自动批准和拒绝可能不创建人工Interaction，会删掉用户唯一可读的审批决定；拒绝。改为独立审批一行并保准确请求／结果，检查规则按需展开。
- 按user角色或固定JSON／XML正文清除上下文：会误删用户粘贴、历史复制和真实项目／方案资料；拒绝。仅对当前已核实来源的末次补充项精简展示，原完整材料不动。
- 改原 Projector 合并 Execution：会丢失独立重试、失败和原材料版本，拒绝；仅加展示层。
- 按相同命令、模型名或时间接近去重：会合并真正重新执行和并行工作，拒绝；仅用原 owner 身份关系。
- 预读全部输入／结果补列表与关联：扩大读取和内存成本，拒绝；使用有界第一方索引与当前视口有界材料，选中后读准确详情。
- 正文加载完成后按空字符串删输出行：把未读、生成前缀、失败与完整空输出混为一谈，并导致列表跳动；拒绝。使用原事件封存的准确存在性决定结构，正文只更新行内文案；缺证明保守保留，不为降噪预读全历史。
- 为子调用读取任意最新子会话：不能证明工作归属与历史位置，拒绝；固定 child Run／父 cursor 并重核准入。

## Consequences

主列表统计逻辑操作，底层继续保存各尝试、观察、原父关系和完整事件。旧记录缺 display、前驱或任务关联时保持明确缺失，不迁移补造。展示归并不赋予执行、重跑、审批、子会话或外发权限，协议和工具版本没有递增。

产品预期归[会话手册](../../../../docs/handbook/features/sessions.md#执行轨迹与只读重放)，实现与验证归 [UI](../../../../packages/ui/README.md#执行轨迹展示)、[Native](../../../../apps/desktop/README.md)、[Trajectory](../../../../packages/trajectory/README.md) 和 [Agent trajectory](../../../../packages/agent/src/trajectory/README.md)。纯归并、真实 Store 封存、材料 Hook 和生产编译界面的过程观察分别证明各自范围，不互相替代安装版、真实 Provider 或跨平台资格。
