# Model input history reads

`getModelInputSnapshot` and `listModelInputs` are finite read-only Worker operations. Each uses one BEGIN read snapshot, verifies expected Store before scope, and joins the exact Model, Run, original Command, root-work Command and root group. The original root creator and Command subject must match the host actor; child carrier/session/root-work relations are checked from stored facts. No owner, current selection, pending work or model adapter is required. The returned internal snapshot has the sealed input and original subject; Runtime removes private references/authority from the public DTO after full Artifact validation.

The directory uses existing positive execution rowid as an exact Decimal64 sequence. It filters Session/model and cursor bounds before LIMIT, returns at most 200 finite identities, and freezes the chosen upperSeq independently of the read-time highWaterSeq. Pages do not depend on notification retention. Refresh begins a new directory scan; fixed-upper traversal does not include later rows. Body and result content are excluded; snapshot only extracts the input body receipt hash. Invalid/out-of-range cursors fail without writes.

This introduces no schema migration or new dispatcher behavior. Tests prepare 205 legitimate Model intents through owner/startRun/planExecution, without inventing successful Provider receipts, to exercise directory pagination. Separate actual Core calls verify succeeded inputs, child provenance and actual Provider failure remaining unconfirmed. The only direct SQL mutations are isolated malformed-data/cursor fault probes on those original records; no authorization, obligation or successful Model input is fabricated.
